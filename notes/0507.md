### 解法（math-factor-enumeration）

> [Perfect Number](https://leetcode.com/problems/perfect-number/)<br>
> 法一<br>
> int res = 1;<br>
> for(int i = 2; i * i < sqrt(num); i++) if(num % i == 0) res += i + num / i;<br>
> return res == num;<br>
> 法二<br>
> return num == 6 || num == 28 || num == 496 || num == 8128 || num == 33550336;<br>
