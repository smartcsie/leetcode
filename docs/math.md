> **if (n == INT_MIN) return myPow(x * x, n / 2);** <br>
> **if (n < 0) return 1 / myPow(x, -n);** <br>
> **double half = myPow(x, n / 2);** <br>
> **return n % 2 == 0 ? half * half : half * half * x;** <br>
