# DP Digit 筆記

**核心概念**：不是傳統的「狀態轉移表」DP，而是**逐位分析**——把 n
轉成字串，對每一位固定「前綴是否還跟 n 一樣」，逐位決定這一位可以
填哪些數字，剩下的位數用排列組合公式算出方案數。

| # | 題目 | 求什麼 | 關鍵技巧 |
|---|---|---|---|
| 233 | Number of Digit One | 1~n 裡數字 '1' 出現次數 | 對每個位值單獨用公式計算貢獻，不是逐一數 |
| 902 | Numbers At Most N Given Digit Set | 用給定數字集合能組出幾個 <=n 的數 | 逐位比對，找不到匹配就提早結束 |
| 1012 | Numbers With Repeated Digits | 1~n 裡至少一位重複的數字個數 | 補集轉換：n 減掉「完全不重複」的個數 |
| 2376 | Count Special Integers | 1~n 裡所有位都不重複的整數個數 | 跟 1012 共用同一套排列數計算邏輯 |

## 容易搞混的地方

- **1012 跟 2376 本質是同一個子問題**：2376 直接算「不重複的個數」，
  1012 是它的補集（`n - 不重複的個數`），底層都是「逐位固定前綴，
  枚舉這一位可以填的、還沒用過的數字，用排列數公式算剩下位數的
  方案數」。
- **233 是逐位分析法的特例**：不是枚舉「這一位填什麼」，而是直接
  用公式（`(n/divider)*i + min(max(n%divider-i+1,0),i)`）計算「某個
  位值上 1 出現幾次」，屬於位數分析裡更數學化的一種。
- **1125、1434 曾經被誤放在這個分類**：雖然題目也牽涉到「位元」的
  概念（技能覆蓋範圍、帽子分配），但核心技巧是 Bitmask DP，不是
  逐位分析，已修正到 `dp-bitmask`。
- **902 的「逐位比對」容易漏掉最後的 +1**：如果一路比對到最後一位
  都能完全匹配（matched 全程為 true），代表 n 本身也能用給定數字
  集合拼出來，要額外 +1，這個邊界很容易忘記。
