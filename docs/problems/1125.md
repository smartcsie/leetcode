# 1125. Smallest Sufficient Team

[在 LeetCode 上查看](https://leetcode.com/problems/smallest-sufficient-team/)

**難度:** 🔴 Hard　**標籤:** Dp Digit　**時間:** O(2^M　**空間:** O(2^M)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1125. Smallest Sufficient Team
 * 難度：困難 (Hard)
 * 描述：給定所需技能清單 req_skills 和一組人員 people（每個人擁有的
 * 技能清單），找出人數最少的團隊，讓團隊涵蓋所有必需技能。回傳團隊
 * 成員的索引（任一組最小解即可）。
 *
 * 時間複雜度：O(2^M * N)，M 是技能數量、N 是人數
 * 空間複雜度：O(2^M)
 *
 * 解法思路：
 * （Bitmask DP，這裡的 mask 代表「技能」而不是「人員」，跟前面幾題
 * mask 代表元素本身的用法不同，是這題的關鍵理解點）：
 * 1. 把每個人擁有的技能編碼成一個 bitmask（personMask[i]），第 j 個
 *    bit 代表這個人是否具備第 j 項必需技能。
 * 2. dp[mask] 代表「涵蓋 mask 這些技能」所需的最小團隊，用另一個
 *    bitmask（哪些人被選進團隊）表示。
 * 3. dp[0] = 0（空技能需求，不用任何人）。狀態轉移：對每個已知可達的
 *    技能 mask，嘗試加入第 i 個人：新的技能覆蓋範圍變成
 *    mask | personMask[i]，新團隊是 dp[mask] 加上第 i 個人。如果這個
 *    新狀態還沒被覆蓋過、或是新團隊人數比現有的更少，就更新。
 * 4. 這題不用擔心「同一個人被選兩次」的問題，因為團隊用 bitmask 表示
 *    （每個人只佔一個 bit），OR 操作天然去重。
 * 5. 答案是 dp[所有技能都涵蓋的 mask]，把這個團隊 bitmask 轉換回
 *    索引清單即可。
 */
class Solution {
public:
    vector<int> smallestSufficientTeam(vector<string>& req_skills, vector<vector<string>>& people) {
        int m = req_skills.size();
        unordered_map<string,int> skillIndex;
        for (int i = 0; i < m; ++i) skillIndex[req_skills[i]] = i;

        int n = people.size();
        vector<int> personMask(n, 0);
        for (int i = 0; i < n; ++i) {
            for (auto& skill : people[i]) {
                if (skillIndex.count(skill)) personMask[i] |= (1 << skillIndex[skill]);
            }
        }

        int full = 1 << m;
        vector<long long> dp(full, -1);
        dp[0] = 0;
        for (int mask = 0; mask < full; ++mask) {
            if (dp[mask] == -1) continue;
            for (int i = 0; i < n; ++i) {
                int newMask = mask | personMask[i];
                long long newTeam = dp[mask] | (1LL << i);
                if (dp[newMask] == -1 || __builtin_popcountll(newTeam) < __builtin_popcountll(dp[newMask])) {
                    dp[newMask] = newTeam;
                }
            }
        }

        vector<int> result;
        long long team = dp[full - 1];
        for (int i = 0; i < n; ++i) {
            if (team & (1LL << i)) result.push_back(i);
        }
        return result;
    }
};
```
