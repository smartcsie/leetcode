# 2248. Intersection of Multiple Arrays

[在 LeetCode 上查看](https://leetcode.com/problems/intersection-of-multiple-arrays/)

**難度:** 🟢 Easy　**標籤:** Hash Table　**時間:** O(N*M)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    vector<int> intersection(vector<vector<int>>& nums) {
        vector<int> res;
        map<int, int> count;
        for(const auto& group : nums) {
            for(int num : group) {
                count[num]++;
            }
        }
        int n = nums.size();
        for (const auto& [num, freq] : count) {
            if (freq == n) {
                res.push_back(num);
            }
        }
        return res;
    }
};
```
