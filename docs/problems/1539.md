# 1539. Kth Missing Positive Number

[在 LeetCode 上查看](https://leetcode.com/problems/kth-missing-positive-number)

**難度:** 🟢 Easy　**標籤:** Binary Search Find Right Bound　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🟣 易忘

```cpp
/**
 * 題目：1539. Kth Missing Positive Number (第 k 個缺失的正整數)
 * 難度：簡單 (Easy)
 * 描述：在嚴格遞增的數組中尋找第 k 個缺失的正整數。
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 在數組中，arr[i] 之前的缺失數字數量為 `arr[i] - (i + 1)`。
 * 我們使用 `lower_bound` 找出第一個「缺失數數量 >= k」的索引 `it`。
 * 最終結果為 `(索引位置) + k`。
 */

#include <vector>
#include <algorithm>

class Solution {
public:
    int findKthPositive(std::vector<int>& arr, int k) {
        int left = 0, right = arr.size()-1;
        while(left <= right){
            int mid = left + (right-left)/2;
            if((arr[mid] - mid - 1) < k) left = mid + 1;
            else right = mid - 1; 
        }
        return right + k + 1;
    }
};
```
