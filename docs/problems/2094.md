# 2094. Finding 3-Digit Even Numbers

[在 LeetCode 上查看](https://leetcode.com/problems/finding-3-digit-even-numbers/)

**難度:** 🟢 Easy　**標籤:** Hash Table Uniqueness, Hash Table　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2094. Finding 3-Digit Even Numbers (找出 3 位偶數)
 * 難度：簡單 (Easy)
 * 描述：由輸入的數字陣列 digits 組成所有可能的 3 位偶數，結果需升序回傳。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 資源回溯法：在迴圈中動態扣除並恢復 count，讓判斷邏輯更為簡潔。
 * 2. 順序性：由於迴圈是從小到大遍歷 (hun: 1-9, ten: 0-9, unit: 0-8)，
 * 產生的 res 自動就是排序過的。
 */

#include <vector>

class Solution {
public:
    std::vector<int> findEvenNumbers(std::vector<int>& digits) {
        set<int> ans;
        int n = digits.size();
        for(int i = 0; i < n; i++) {
            if(digits[i] == 0) continue;
            for(int j = 0; j < n; j++) {
                for(int k = 0; k < n; k++) {
                    if(i == j || j == k || i==k) continue;
                    if(digits[k] % 2) continue;
                    int num = digits[i] * 100 + digits[j] * 10 + digits[k];
                    ans.insert(num);
                }
            } 
        }
        return vector(ans.begin(), ans.end());
    }
};
```
