/*
 * 題目：1252. Cells with Odd Values in a Matrix
 * 難度：Easy
 * 描述：給定 m × n 的全 0 矩陣與 indices，每個 [r, c] 代表「第 r 列所有格子 +1」且「第 c 欄所有格子 +1」。全部操作完後，回傳值為奇數的格子數量。
 * 分類主題：bit-manipulation-xor
 * 技巧：奇偶性, XOR 翻轉, 行列獨立計數, 固定大小 array
 * 時間複雜度：O(L + m × n)，L 為 indices 長度
 * 空間複雜度：O(1)（rows、cols 為固定大小 51，對應限制 m、n ≤ 50；一般化則為 O(m + n)）
 * 解法思路：
 *   1. 格子 (i, j) 的值 = 第 i 列被操作的次數 + 第 j 欄被操作的次數
 *   2. 只關心奇偶，所以每列、每欄只需記錄「被操作次數的奇偶」，用 ^= 1 翻轉即可
 *   3. 格子為奇數 ⇔ rows[i] 與 cols[j] 奇偶不同 ⇔ rows[i] ^ cols[j] == 1
 *   4. 掃過所有格子，把 rows[i] ^ cols[j] 累加起來就是答案
 *   5. 進階：設奇數列有 r 條、奇數欄有 c 條，答案為 r × n + c × m - 2 × r × c，可省掉 m × n 的雙迴圈，時間降為 O(L + m + n)
 */
