# 1524. Number of Sub-arrays With Odd Sum

[在 LeetCode 上查看](https://leetcode.com/problems/number-of-sub-arrays-with-odd-sum/)

**難度:** 🟡 Medium　**標籤:** Math, Prefix Sum, Combinatorics　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1524. Number of Sub-arrays With Odd Sum (奇數和子陣列數目)
 * 難度：中等 (Medium)
 * 描述：給定整數陣列 arr，回傳陣列中「元素和為奇數」的非空子陣列數目，答案需對 10^9 + 7 取模。
 *
 * 時間複雜度：O(N) - 只需線性掃描一次陣列，累加前綴和並統計奇偶次數。
 * 空間複雜度：O(1) - 只使用常數個變數（odds, prefix, evens），不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 前綴和的奇偶性 (Prefix Sum Parity)：
 *    - 子陣列 [i+1, j] 的和等於 prefix[j] - prefix[i]，其和為奇數的條件是
 *      prefix[j] 與 prefix[i] 兩者奇偶性不同（一奇一偶）。
 * 2. 統計奇數前綴的數量：
 *    - 掃描陣列時累加 prefix，同時用 odds 統計目前為止「前綴和為奇數」的次數，
 *      evens 則為總長度扣掉 odds（代表前綴和為偶數的次數）。
 * 3. 組合計數公式 (Combinatorics)：
 *    - 「以索引 0 為起點的子陣列本身」若前綴為奇數，直接貢獻 odds 種合法子陣列。
 *    - 另外，任兩個不同前綴（一奇一偶）配對，可以組成 odds * evens 種合法子陣列。
 *    - 兩者相加並對 MOD 取餘數即為最終答案。
 */
class Solution {
public:
    int numOfSubarrays(vector<int>& arr) {
        constexpr int MOD = 1e9 + 7;
        int n = arr.size();
        int odds = 0, prefix = 0;
        for (const int& num : arr) {
            prefix += num;
            odds += prefix & 1;
        }
        int evens = n - odds;
        int ans = (odds + 1LL * odds * evens) % MOD;
        return ans;
    }
};
```
