# 455. Assign Cookies

[在 LeetCode 上查看](https://leetcode.com/problems/assign-cookies/)

**難度:** 🟢 Easy　**標籤:** Greedy Fractional Knapsack　**時間:** O(N log N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：455. Assign Cookies
 * 難度：簡單 (Easy)
 * 描述：給定每個小孩的胃口值 g（至少要吃到這麼大的餅乾才滿足）和每塊
 * 餅乾的大小 s，一個小孩最多分一塊餅乾，求最多能滿足幾個小孩。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （Fractional Knapsack 分類裡最入門的一題，排序 + 雙指標貪心，跟
 * 「用最小的資源滿足最多需求」這種分配問題是同一種思路）：
 * 1. 把小孩的胃口值 g 和餅乾大小 s 都由小到大排序。
 * 2. 用雙指標 i（指向目前要滿足的小孩）、j（指向目前嘗試的餅乾）
 *    同時往前走：
 *    - 如果 s[j] >= g[i]（這塊餅乾夠滿足目前這個小孩）：滿足他，
 *      count++，兩個指標都前進。
 *    - 否則（餅乾太小）：這塊餅乾對誰都不夠用（因為 g 已排序，比
 *      目前這個小孩胃口更大的小孩更不可能被滿足），直接丟棄，只有
 *      j 前進，換下一塊更大的餅乾試試看。
 * 3. 貪心的正確性：優先用「剛好夠用、不會太浪費」的餅乾去滿足「胃口
 *    最小」的小孩，才能把大餅乾留給胃口更大的小孩，讓整體滿足人數
 *    最大化。
 */
class Solution {
public:
    int findContentChildren(vector<int>& g, vector<int>& s) {
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());
        int i = 0, j = 0;
        int count = 0;
        while (i < (int)g.size() && j < (int)s.size()) {
            if (s[j] >= g[i]) {
                count++;
                i++;
            }
            j++;
        }
        return count;
    }
};
```
