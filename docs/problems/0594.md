# 594. Longest Harmonious Subsequence

[在 LeetCode 上查看](https://leetcode.com/problems/longest-harmonious-subsequence/)

**難度:** 🟢 Easy　**標籤:** Hash Table Existence　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：594. Longest Harmonious Subsequence
 * 難度：簡單 (Easy)
 * 描述：給定一個整數陣列 nums，找出其中最長的「和諧子序列」的長度。
 * 和諧子序列的定義是：子序列中最大值與最小值恰好相差 1。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （雜湊表計數 + 檢查相鄰數字）：
 * 1. 用 unordered_map 統計每個數字出現的次數。
 * 2. 遍歷每個相異數字 x：
 * - 如果 x - 1 也存在，代表 [x-1, x] 這對數字可以組成一個和諧子序列，
 *   長度為 counts[x-1] + counts[x]，更新答案。
 * - 如果 x + 1 也存在，代表 [x, x+1] 這對數字可以組成一個和諧子序列，
 *   長度為 counts[x] + counts[x+1]，更新答案。
 * 3. 因為只需要看「差 1」的相鄰數字對，不需要排序，用雜湊表一次遍歷
 *   就能找出最長的和諧子序列長度。
 */
class Solution {
public:
    int findLHS(vector<int>& nums) {
        unordered_map<int, int> counts;
        for(const int& x : nums) counts[x]++;
        int ans = 0;
        for(const auto& [x, count] : counts) {
            if(counts.contains(x - 1)) ans = max(ans, counts[x - 1] + counts[x]);
            if(counts.contains(x + 1)) ans = max(ans, counts[x + 1] + counts[x]);
        }
        return ans;
    }
};
```
