# 112. Path Sum

[在 LeetCode 上查看](https://leetcode.com/problems/path-sum/)

**難度:** 🟢 Easy　**標籤:** Tree, DFS　**時間:** O(n)　**空間:** O(h)

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) {
            return false;
        }
        if (root->left == nullptr && root->right == nullptr &&
            root->val == targetSum) {
            return true;
        }

        return hasPathSum(root->left, targetSum - root->val) ||
               hasPathSum(root->right, targetSum - root->val);
    }
};
```
