# 3227. Vowels Game in a String

[在 LeetCode 上查看](https://leetcode.com/problems/vowels-game-in-a-string/)

**難度:** 🟡 Medium　**標籤:** Greedy, Game Theory　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：3227. Vowels Game in a String (字串中的母音遊戲)
 * 難度：中等 (Medium)
 * 描述：Alice 和 Bob 輪流從字串 s 中刪除一個非空子字串進行遊戲，
 *       Alice 先手，若刪除的子字串中母音數量為奇數則合法，Bob 則要求偶數（含 0）。
 *       任一方無法合法操作即輸掉遊戲，請判斷 Alice 是否必勝。
 *
 * 時間複雜度：O(N) - 只需線性掃描字串一次，檢查每個字元是否為母音。
 * 空間複雜度：O(1) - 只使用一個常數大小的位元遮罩，不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 賽局結論 (Game Theory Conclusion)：
 *    - 本題結論為：只要字串 s 中存在至少一個母音字元，Alice 就必勝；若完全沒有母音，則 Alice 必敗。
 *    - 因此問題化簡為「檢查字串裡是否至少出現一個母音」。
 * 2. 位元遮罩快速判斷母音 (Bitmask Vowel Check)：
 *    - 0x104111 這個常數，其二進位表示中，恰好在 'a','e','i','o','u' 對應的位元位置（以 'a' 為第 0 位）上為 1。
 *    - 對每個字元 c，計算 (0x104111 >> (c - 'a')) & 1，若結果為 1 代表 c 是母音。
 * 3. 提前返回 (Early Return)：
 *    - 一旦掃描到任何一個母音字元，立刻回傳 true，不需要繼續掃描剩餘字元。
 */
class Solution {
public:
    bool doesAliceWin(string s) {
        for(const char& c : s) {
            if((0x104111 >> (c - 'a')) & 1) return true;
        }
        return false;
    }
};
```
