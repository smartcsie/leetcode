# 993. Cousins in Binary Tree

[在 LeetCode 上查看](https://leetcode.com/problems/cousins-in-binary-tree/)

**難度:** 🟢 Easy　**標籤:** Tree, BFS　**時間:** O(N)　**空間:** O(W)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：993. Cousins in Binary Tree (二元樹的堂兄弟節點)
 * 難度：簡單 (Easy)
 * 描述：判斷兩個數值 x 和 y 的節點是否為「堂兄弟」（同一層但父節點不同）。
 *
 * 時間複雜度：O(N) - N 為節點總數。
 * 空間複雜度：O(W) - W 為樹的寬度。
 *
 * 解法思路：
 * 1. 結構精簡：統一 BFS 的處理邏輯，並確保在找到兩個節點後立即比對。
 * 2. 變數命名：提高可讀性，明確區分層數與父節點資訊。
 */

class Solution {
public:
    bool isCousins(TreeNode* root, int x, int y) {
        if(!root) return false;
        queue<pair<TreeNode*, TreeNode*>> q;
        q.push({nullptr, root});
        pair<TreeNode*, int> pairX({nullptr, -1});
        pair<TreeNode*, int> pairY({nullptr, -1});
        int depth = 0;
        while(!q.empty()) {
            for(int i = q.size() - 1; i >= 0; i--) {
                auto[parent, node] = q.front();
                q.pop();
                if(node->val == x) pairX = {parent, depth};
                if(node->val == y) pairY = {parent, depth};
                if(node->left) q.push({node, node->left}); 
                if(node->right) q.push({node, node->right}); 
            }
            if(pairX.second != -1 || pairY.second != -1)
                return pairX.first != pairY.first && pairX.second == pairY.second;
            depth++;
        }
        return false;
    }
};
```
