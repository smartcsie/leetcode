# 961. N-Repeated Element

[在 LeetCode 上查看](https://leetcode.com/problems/n-repeated-element-in-size-2n-array/)

## 解法：greedy

**難度:** 🟢 Easy　**標籤:** Math, Greedy　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：961. N-Repeated Element in Size 2N Array
 * 難度：簡單 (Easy)
 * 描述：在 2N 長度的陣列中找出出現 N 次的元素。
 * 優化重點：
 * 1. 空間複雜度 O(1)：移除 unordered_set，不再需要額外記憶體。
 * 2. 機率/數學性質：因為重複元素出現 N 次（佔總長度的一半），它們很有可能在短距離內重複。
 *
 * 時間複雜度：O(N) - 檢查間距 1、2、3 的相鄰元素是否相同。
 * 空間複雜度：O(1) - 僅使用常數空間。
 */

class Solution {
public:
    int repeatedNTimes(vector<int>& nums) {
        int n = nums.size();
        // 數學性質：重複元素出現 N 次，若隨機抽樣或檢查小距離，
        // 很快就能發現重複。此處檢查距離 1, 2, 3 的位置。
        for (int i = 0; i < n; ++i) {
            if (i + 1 < n && nums[i] == nums[i + 1]) return nums[i];
            if (i + 2 < n && nums[i] == nums[i + 2]) return nums[i];
            if (i + 3 < n && nums[i] == nums[i + 3]) return nums[i];
        }
        return -1;
    }
};
```

## 解法：hash-table-uniqueness

**難度:** 🟢 Easy　**標籤:** Hash Table Uniqueness　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
class Solution {
public:
    int repeatedNTimes(vector<int>& nums) {
        unordered_set<int> sets;
        for(const int& x : nums) {
            if(!sets.insert(x).second)  return x;
        }
        return -1;
    }
};
```
