# 2785. Sort Vowels in a String

[在 LeetCode 上查看](https://leetcode.com/problems/sort-vowels-in-a-string/)

## 解法：sorting

**難度:** 🟡 Medium　**標籤:** Sorting, Counting Sort　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：2785. Sort Vowels in a String (重排字串中的元音)
 * 難度：中等 (Medium)
 * 描述：將字串中的所有元音依據 ASCII 值排序，非元音位置保持不動。
 *
 * 時間複雜度：O(N) - 遍歷兩次字串。
 * 空間複雜度：O(1) - 使用固定大小的陣列與查找表。
 *
 * 解法思路：
 * 1. 查找表：使用靜態 bool 陣列判斷元音，取代字串搜尋。
 * 2. 計數排序：直接統計元音 ASCII 頻率，免去顯式排序。
 */

class Solution {
public:
    string sortVowels(string s) {
        vector<int> counts(128, 0);
        for(const char& c : s) {
            if((0x104111 >> ((c | 32) - 'a')) & 1) counts[c]++;
        }
        string vowels = "AEIOUaeiou";
        int idx = 0;
        for(char& c : s) {
            if((0x104111 >> ((c | 32) - 'a')) & 1) {
                while(idx < vowels.size() && !counts[vowels[idx]]) idx++;
                c = vowels[idx];
                counts[c]--;
            }
        }
        return s;
    }
};
```

## 解法：sorting

**難度:** 🟡 Medium　**標籤:** Sorting　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟢 熟練

```cpp
class Solution {
public:
    string sortVowels(string s) {
        vector<char> vowels;
        for(const char& c : s) {
            if( (0x104111 >> (c | 32) - 'a') & 1) vowels.push_back(c);
        }
        sort(vowels.begin(), vowels.end());
        int idx = 0;
        for(char& c : s) {
            if( (0x104111 >> (c | 32) - 'a') & 1) c = vowels[idx++];
        }
        return s;
    }
};
```
