# 1425. Constrained Subsequence Sum

[在 LeetCode 上查看](https://leetcode.com/problems/constrained-subsequence-sum/)

**難度:** 🔴 Hard　**標籤:** Dp Subsequences　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1425. Constrained Subsequence Sum
 * 難度：困難 (Hard)
 * 描述：給定一個整數陣列 nums 和一個整數 k，找一個子序列（可以是空的
 * 也可以只有一個元素），使得子序列裡任兩個相鄰選中元素的原始索引差
 * 不超過 k，求這個子序列元素總和的最大值。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （DP on Subsequences + 單調隊列優化，dp[i] 代表「以 nums[i] 結尾」
 * 的子序列最大和）：
 * 1. dp[i] = nums[i] + max(0, dp[i-k], dp[i-k+1], ..., dp[i-1])。
 *    也就是：往前看最近 k 個位置的 dp 值，選最大的接上來（如果最大值
 *    是負的，寧可不接，單獨自己成一段，所以要跟 0 取 max）。
 * 2. 如果每個 i 都暴力往前掃 k 個位置找最大值，時間複雜度是 O(N*K)，
 *    可能會超時。這題的優化技巧是用「單調遞減佇列」維護一個滑動視窗
 *    最大值（跟 239 Sliding Window Maximum 是同樣的技巧）：
 *    - 佇列裡存的是索引，維護 dp 值從隊首到隊尾遞減。
 *    - 每次要算 dp[i] 前，先把「超出視窗範圍」（索引 < i-k）的隊首
 *      彈出。
 *    - 隊首（如果存在）就是目前視窗內 dp 值最大的位置，跟 0 取 max
 *      當作這次的 best。
 *    - 算完 dp[i] 後，把隊尾所有「dp 值 <= dp[i]」的元素都彈出（它們
 *      以後不可能是最大值了，因為 dp[i] 比它們晚出現、視窗又比它們
 *      新，還比它們大），再把 i 加入隊尾，維持遞減性質。
 * 3. 過程中同步記錄看過的最大 dp 值，就是最終答案（子序列不一定要
 *    以最後一個元素結尾，所以要對所有 dp[i] 取最大值，不能只看 dp[n-1]）。
 */
class Solution {
public:
    int constrainedSubsetSum(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> dp(n);
        deque<int> dq;
        int ans = INT_MIN;
        for (int i = 0; i < n; ++i) {
            while (!dq.empty() && dq.front() < i - k) dq.pop_front();
            int best = dq.empty() ? 0 : max(0, dp[dq.front()]);
            dp[i] = nums[i] + best;
            ans = max(ans, dp[i]);
            while (!dq.empty() && dp[dq.back()] <= dp[i]) dq.pop_back();
            dq.push_back(i);
        }
        return ans;
    }
};
```
