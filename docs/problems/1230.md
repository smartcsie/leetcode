# 1230. Toss Strange Coins

[在 LeetCode 上查看](https://leetcode.com/problems/toss-strange-coins/)

**難度:** 🟡 Medium　**標籤:** Dp Probability　**時間:** O(N　**空間:** O(target)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1230. Toss Strange Coins
 * 難度：中等 (Medium)
 * 描述：給定 n 個不公正硬幣，prob[i] 是第 i 個硬幣拋出正面的機率，
 * 全部拋一次，求恰好出現 target 個正面的機率。
 *
 * 時間複雜度：O(N * target)
 * 空間複雜度：O(target)
 *
 * 解法思路：
 * （Probability DP，dp[j] 代表「考慮到目前這枚硬幣為止，恰好出現 j
 * 個正面」的機率，一維滾動陣列）：
 * 1. dp[0] = 1.0（還沒拋任何硬幣，出現 0 個正面的機率是 100%）。
 * 2. 狀態轉移：每處理一枚硬幣 i，要嘛這枚是反面（機率 1-prob[i]，
 *    正面數不變）、要嘛是正面（機率 prob[i]，正面數 +1）：
 *    dp[j] = 舊dp[j] * (1-prob[i]) + 舊dp[j-1] * prob[i]
 * 3. 這裡用一維陣列原地更新（滾動陣列省空間），要注意更新順序：
 *    j 要「從大到小」遞減更新（`for j = min(i+1,target) downto 0`），
 *    因為 dp[j] 的新值依賴 dp[j-1] 的「舊值」（還沒被這一輪更新過），
 *    如果從小到大更新，dp[j-1] 會提前被這一輪的新值覆蓋，導致算 dp[j]
 *    時用到錯誤的（已經是這一輪更新後的）值。
 * 4. 處理完所有 n 枚硬幣後，答案是 dp[target]。
 */
class Solution {
public:
    double probabilityOfHeads(vector<double>& prob, int target) {
        int n = prob.size();
        vector<double> dp(target + 1, 0.0);
        dp[0] = 1.0;
        for (int i = 0; i < n; ++i) {
            for (int j = min(i + 1, target); j >= 0; --j) {
                double withoutHead = dp[j] * (1 - prob[i]);
                double withHead = (j > 0) ? dp[j - 1] * prob[i] : 0.0;
                dp[j] = withoutHead + withHead;
            }
        }
        return dp[target];
    }
};
```
