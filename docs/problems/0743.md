# 743. Network Delay Time

[在 LeetCode 上查看](https://leetcode.com/problems/network-delay-time/)

**難度:** 🟡 Medium　**標籤:** Graph Shortest Path　**時間:** O(E·logV)　**空間:** O(V+E)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：743. Network Delay Time
 * 難度：中等 (Medium)
 * 描述：有 n 個節點（編號 1 ~ n）構成一個網路，times[i] = [u, v, w] 代表
 * 節點 u 到節點 v 傳送訊號需要 w 時間。從節點 k 開始送訊號，請問所有節點
 * 都收到訊號最少需要多少時間；若無法讓所有節點都收到，回傳 -1。
 *
 * 時間複雜度：O(E·logV) - V 為節點數、E 為邊數；每條邊最多被 relax 一次
 *             並推進優先佇列，優先佇列操作為 O(logV)。
 * 空間複雜度：O(V+E) - 鄰接串列 graph 儲存所有邊需 O(E)，
 *             dist 陣列與 minHeap 需 O(V)。
 *
 * 解法思路：
 * （Dijkstra 單源最短路徑，優先佇列實作）：
 * 1. 建立帶權鄰接串列：
 * - 題目節點編號從 1 開始，先轉成 0-index（u、v 各減 1），
 *   graph[u] 存 (v, w) 代表 u 到 v 的邊權重為 w。
 * 2. 初始化距離陣列：
 * - dist 全部初始化為 INT_MAX（代表尚未到達），起點 src 的 dist 設為 0，
 *   並將 (0, src) 放入 min-heap（以距離由小到大取出）。
 * 3. 貪心取出目前距離最小的節點：
 * - 每次從 minHeap 取出目前累積距離最短的節點 u；若取出的距離 d 已經比
 *   目前紀錄的 dist[u] 還大，代表是過期的舊紀錄，直接跳過（懶惰刪除）。
 * 4. 鬆弛（Relax）相鄰邊：
 * - 對 u 的每個鄰居 v，如果經過 u 到 v 的距離 d + w 比目前 dist[v] 更短，
 *   就更新 dist[v] 並把新的 (dist[v], v) 推進 minHeap。
 * 5. 統計答案：
 * - 走訪完成後，dist 陣列裡的最大值即為「所有節點都收到訊號」所需時間；
 *   若其中仍有 INT_MAX（代表有節點永遠收不到），回傳 -1。
 */
class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<vector<pair<int, int>>> graph(n);

        for (const vector<int>& time : times) {
            const int u = time[0] - 1;
            const int v = time[1] - 1;
            const int w = time[2];
            graph[u].emplace_back(v, w);
        }
        return dijkstra(graph, k - 1);
    }

 private:
    int dijkstra(const vector<vector<pair<int, int>>>& graph, int src) {
        vector<int> dist(graph.size(), INT_MAX);

        dist[src] = 0;
        using P = pair<int, int>;  // (d, u)
        priority_queue<P, vector<P>, greater<>> minHeap;
        minHeap.emplace(dist[src], src);

        while (!minHeap.empty()) {
            const auto [d, u] = minHeap.top();
            minHeap.pop();
            if (d > dist[u])
                continue;
            for (const auto& [v, w] : graph[u])
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    minHeap.emplace(dist[v], v);
                }
        }

        const int maxDist = ranges::max(dist);
        return maxDist == INT_MAX ? -1 : maxDist;
    }
};
```
