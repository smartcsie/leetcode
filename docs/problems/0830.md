# 830. Positions of Large Groups

[在 LeetCode 上查看](https://leetcode.com/problems/positions-of-large-groups/)

**難度:** 🟢 Easy　**標籤:** Array, String, Two Pointers　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：830. Positions of Large Groups (較大分組的位置)
 * 難度：簡單 (Easy)
 * 描述：字串 s 中連續相同字元組成的區間稱為一個分組。若某個分組的長度大於等於 3，
 *       則稱為「較大分組」。請找出所有較大分組的起始與結束索引，依序回傳。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 雙指標劃分分組區間 (Two Pointers for Grouping)：
 *    - i 代表目前分組的起始位置，j 從 i 開始往後延伸，只要字元與 s[i] 相同就持續前進，
 *      找出這個分組的結束位置。
 * 2. 判斷是否為較大分組：
 *    - 當 j 停下來時，[i, j-1] 就是目前這個分組的完整區間，
 *      若長度 (j - i) 大於等於 3，則將起訖索引 {i, j-1} 加入答案。
 * 3. 跳到下一個分組繼續處理：
 *    - 外層迴圈透過 i = j 跳到下一個分組的起始位置，重複上述過程直到整個字串掃描完畢。
 * 4. 邊界安全性：
 *    - while 迴圈的比較 s[i] == s[j] 在 j 到達 s.size() 時，
 *      能安全利用 std::string 保證的結尾空字元（'\0'）進行比較而不會真正越界。
 */
class Solution {
public:
    vector<vector<int>> largeGroupPositions(string s) {
        int count = 1;
        vector<vector<int>> ans;
        int i ;
        for(i = 1; i < s.size(); i++) {
            if(s[i] == s[i - 1]) {
                count++;
            } else {
                if(count >= 3) ans.push_back( {i - count, i - 1});
                count = 1;
            }
        }
        if(count >= 3) ans.push_back( {i - count, i - 1});
        return ans;
    }
};
```
