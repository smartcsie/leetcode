# 539. Minimum Time Difference

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-time-difference/)

**難度:** 🟡 Medium　**標籤:** Greedy Sorting Decision, Sorting　**時間:** O(NlogN)　**空間:** O(N)　**熟悉度:** 🟡 練習過

**技巧:** time

```cpp
/**
 * 題目：539. Minimum Time Difference (最小時間差)
 * 難度：中等 (Medium)
 * 描述：計算給定時間點列表中，任意兩個時間點之間的最小分鐘差。
 *
 * 時間複雜度：O(NlogN)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * 1. 鴿籠原理：若時間點數量 > 1440，必定有重複時間，最小差必為 0。
 * 2. 記憶體預分配：使用 reserve 減少 vector 動態擴容開銷。
 */

class Solution {
private:
    int getTimeSec(string tp) {
        int m = (tp[0] - '0') * 10 + (tp[1] - '0') ;
        int s = (tp[3] - '0') * 10 + (tp[4] - '0');
        return m * 60 + s;
    }
public:
    int findMinDifference(vector<string>& timePoints) {
        vector<string>& tps = timePoints;
        int n = tps.size();
        if(n > 1440) return 0;
        vector<int> times(n);
        for(int i = 0; i < n ;i++) {
            times[i] = getTimeSec(tps[i]);
        }
        sort(times.begin(), times.end());
        int mn = INT_MAX;
        for(int i = 1; i < n ;i++) {
            mn = min(mn, times[i] - times[i - 1]);
        }
        return min(mn, 1440 - (times.back() - times.front()));
    }
};
```

> **最後要處理頭尾**<br>
> **return min(mn, 1440 - (times.back() - times.front()));**<br>
