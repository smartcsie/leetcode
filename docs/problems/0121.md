# 121. Best Time to Buy and Sell Stock

[在 LeetCode 上查看](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

**難度:** 🟢 Easy　**標籤:** Dp State Machine, Dynamic Programming State Machine　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：121. Best Time to Buy and Sell Stock
 * 難度：待補充
 * 描述：在給定的價格陣列中，找出一筆買賣的最大利潤。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * (狀態機 DP)：
 * 1. 定義兩個變數來記錄狀態：
 * - holdOne: 持有一支股票時的最大利潤（由於只能買一次，所以買入價即為負的 cost）。
 * - sellOne: 賣出一支股票後的最大利潤（即為最終利潤）。
 * 2. 遍歷價格：
 * - 更新 sellOne: 比較「維持原樣」或「在今天賣掉」。
 * - 更新 holdOne: 比較「維持原樣」或「在今天買入」。
 */

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int buy = INT_MIN;
        int profit = 0;
        for(const int& price : prices) {
            profit = max(profit, buy + price);
            buy = max(buy, -price);
        }
        return  profit;
    }
};
```

> **buy = max(buy, -price);profit = max(profit, price);**<br>
> **return buy + profit，不能這樣是因為要有先買後賣的順序**<br>
> **buy keep 買進最小值，abs(buy)最小**<br>
> **profit keep 先買後賣利潤最大**<br>
