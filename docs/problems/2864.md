# 2864. Maximum Odd Binary Number

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-odd-binary-number/)

## 解法：greedy-string-construction

**難度:** 🟢 Easy　**標籤:** Greedy, String　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2864. Maximum Odd Binary Number
 * 難度：簡單 (Easy)
 * 描述：重新排列二進位字串，使其成為最大的奇數。
 * 優化重點：
 * 1. 貪婪法則：最末位保留一個 1，其餘 1 全部移至最左側。
 * 2. 效率：僅需統計 1 的數量並重組字串，線性時間 O(N)。
 *
 * 時間複雜度：O(N) - 統計 1 的個數，最後一位放一個 1，其餘放前面。
 * 空間複雜度：O(1) - 僅使用常數空間。
 */

class Solution {
public:
    string maximumOddBinaryNumber(string s) {
        int ones = count(s.begin(), s.end(), '1');
        int zeros = s.size() - ones;
        int idx = 0;
        for(int i = 1; i <= ones -1; i++) s[idx++] = '1';
        for(int i = 1; i <= zeros; i++) s[idx++] = '0';
        s[s.size() - 1] = '1';
        return s;
    }
};
```

## 解法：two-pointers-same

**難度:** 🟢 Easy　**標籤:** Two Pointers Same　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
class Solution {
public:
    string maximumOddBinaryNumber(string s) {
        if(s.back() == '0') {
            int right = s.size() -1;
            while(right >=0 && s[right] == '0') right--;
            if(right >= 0) swap(s[right], s[s.size() -1]);
        }
        for(int i = 0, j = 0; i < s.size() -1 && j < s.size() -1 ; i++) {
                if(s[i] == '1') swap(s[i],s[j++]);
        }
        return s;
    }
};
```
