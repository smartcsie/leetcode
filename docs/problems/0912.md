# 912. Sort an Array

[在 LeetCode 上查看](https://leetcode.com/problems/sort-an-array)

**難度:** 🟡 Medium　**標籤:** Sorting Implementation, Divide and Conquer, Sorting　**時間:** O(NlogN)　**空間:** O(logN)　**熟悉度:** 🟣 易忘

```cpp
/**
 * 題目：912. Sort an Array
 * 難度：中等 (Medium)
 * 分類主題：sorting-implementation
 * 描述：給定一個整數陣列 nums，把它由小到大排序後回傳，不能直接呼叫
 * 內建的排序函式（考的是手刻排序演算法本身）。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Merge Sort，經典的分治法（Divide and Conquer）三步驟：切、遞迴
 * 排序、合併）：
 * 1. **切（Divide）**：把陣列從中間切成左右兩半 [left, mid] 和
 *    [mid+1, right]。
 * 2. **遞迴排序（Conquer）**：分別對左半、右半遞迴呼叫 mergeSort，
 *    直到子陣列只剩 0 或 1 個元素（`left >= right`）為止——這是遞迴
 *    的 base case，因為長度 <= 1 的陣列本身就已經是排序好的，不用
 *    再處理。
 * 3. **合併（Merge）**：兩個已經各自排序好的子陣列，用雙指標
 *    （i 指向左半、j 指向右半）逐一比較兩邊目前最小的元素，較小的
 *    先放進暫存陣列 temp，直到其中一邊耗盡；另一邊剩下的元素（本身
 *    已經是排序好的）直接整段接到 temp 後面。
 * 4. 合併完成後，把 temp 裡這一段區間的內容複製回原陣列對應的位置。
 * 5. **為什麼要額外開一個 temp 陣列**：合併兩個已排序區段時，如果
 *    直接在原陣列上原地覆蓋，會把「還沒讀取、但即將被覆蓋」的資料
 *    弄壞（例如覆蓋了 j 指標之後還沒讀到的元素），所以需要一塊獨立
 *    的暫存空間先把合併結果算好，再整批寫回去。把 temp 陣列宣告在
 *    最外層、遞迴時共用同一份，可以避免每次遞迴呼叫都重新配置記憶體
 *    （只需要配置一次，重複使用）。
 * 6. 這是這題「手刻排序演算法」練習的標準答案之一，另一個常見版本
 *    是 Quick Sort（快速排序），兩者的時間複雜度都是平均 O(N log N)，
 *    但 Merge Sort 是穩定排序、且最壞情況也保證 O(N log N)（Quick
 *    Sort 最壞情況會退化成 O(N²)，除非搭配隨機化選取基準值）。
 */
class Solution {
    void merge(vector<int>& nums, int left, int mid, int right, vector<int>& temp) {
        int i = left, j = mid + 1, k = left;

        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) temp[k++] = nums[i++];
            else temp[k++] = nums[j++];
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= right) temp[k++] = nums[j++];

        for (int p = left; p <= right; ++p) nums[p] = temp[p];
    }

    void mergeSort(vector<int>& nums, int left, int right, vector<int>& temp) {
        if (left >= right) return;

        int mid = left + (right - left) / 2;
        mergeSort(nums, left, mid, temp);
        mergeSort(nums, mid + 1, right, temp);
        merge(nums, left, mid, right, temp);
    }

public:
    vector<int> sortArray(vector<int>& nums) {
        vector<int> temp(nums.size());
        mergeSort(nums, 0, nums.size() - 1, temp);
        return nums;
    }
};
```
