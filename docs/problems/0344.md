# 344. Reverse String

[在 LeetCode 上查看](https://leetcode.com/problems/reverse-string)

**難度:** 🟢 Easy　**標籤:** Two Pointers　**時間:** O(n)　**空間:** O(1)

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    void reverseString(vector<char>& s) {
        int n = s.size();
        for(int i =0; i< n/2; i++) {
            swap(s[i],s[n-1-i]);
        }
    }
};
```
