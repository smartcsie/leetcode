```cpp
/**
 * 題目：2544. Alternating Digit Sum (交替數位和)
 * 難度：簡單 (Easy)
 * 描述：計算數字中各位數的交替和（第一位為正，第二位為負，以此類推）。
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 無字串轉換：直接進行數學運算，消除了動態記憶體配置 (malloc/free)。
 * 2. 算術提取：透過取餘與除法直接取得每一位數字。
 */

class Solution {
public:
    int alternateDigitSum(int n) {
        int sign = 1;
        int sum = 0;
        while(n > 0) {
            sum += sign * (n % 10);
            n /= 10;
            sign = -sign;
        }
        return -sign * sum;
    }
};
```

> **用sign判斷最後是否要*(-1)，如果sign最後是正的，要多*(-1)**。<br>
