```cpp
/**
 * 題目：2544. Alternating Digit Sum (交替數位和)
 * 難度：簡單 (Easy)
 * 描述：計算數字中各位數的交替和（第一位為正，第二位為負，以此類推）。
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 無字串轉換：直接進行數學運算，消除了動態記憶體配置 (malloc/free)。
 * 2. 算術提取：透過取餘與除法直接取得每一位數字。
 */

class Solution {
public:
    int alternateDigitSum(int n) {
        int sign = 1;
        int ans = 0;
        int count = 0;
        while(n > 0) {
            ans += (n % 10) * sign;
            sign = -sign;
            count++;
            n /= 10;
        }
        return count % 2 == 0 ? -ans : ans;
    }
};
```

> **sign=1，每一次加sign*(n % 10)後，sign*=-1，count++計算digit個數，最後出迴圈，count如果是偶數，sum多一個負號**。<br>
