# 847. Shortest Path Visiting All Nodes

[在 LeetCode 上查看](https://leetcode.com/problems/shortest-path-visiting-all-nodes/)

**難度:** 🔴 Hard　**標籤:** Dp Bitmask　**時間:** O(N²　**空間:** O(N　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：847. Shortest Path Visiting All Nodes
 * 難度：困難 (Hard)
 * 描述：給定一個無向連通圖 graph，可以從任一節點出發、重複經過節點和
 * 邊，求走過「所有節點至少一次」所需的最短路徑長度。
 *
 * 時間複雜度：O(N² * 2^N)
 * 空間複雜度：O(N * 2^N)
 *
 * 解法思路：
 * （Bitmask BFS，狀態是「目前在哪個節點」+「已經走過哪些節點」，因為
 * 邊權重都是 1，用 BFS 找最短路徑最自然，不需要真的寫 dp 轉移式）：
 * 1. 狀態定義為 (node, mask)：目前站在 node，mask 記錄「已經拜訪過
 *    哪些節點」。因為可以走回頭路，圖上的最短路徑問題天然適合 BFS
 *    （逐層擴展，第一次到達某狀態的距離就是最短距離）。
 * 2. 初始化：因為可以從任一節點出發，把所有 (i, 只有第i個bit為1) 這種
 *    狀態都當作起點，同時塞進 BFS 佇列，距離都是 0。
 * 3. BFS 展開：從目前狀態 (node, mask) 走到鄰居 next，新狀態變成
 *    (next, mask | (1 << next))，如果這個新狀態沒被拜訪過，就加入
 *    佇列，距離 +1。
 * 4. 用 visited[node][mask] 避免重複展開同一個狀態。
 * 5. 只要某個狀態的 mask 已經等於 full（所有節點都拜訪過的 bitmask），
 *    當下的距離就是答案（BFS 保證第一次達到的距離就是最短的）。
 */
class Solution {
public:
    int shortestPathLength(vector<vector<int>>& graph) {
        int n = graph.size();
        int full = (1 << n) - 1;
        queue<tuple<int,int,int>> q;
        vector<vector<bool>> visited(n, vector<bool>(1 << n, false));
        for (int i = 0; i < n; ++i) {
            q.push({i, 1 << i, 0});
            visited[i][1 << i] = true;
        }
        while (!q.empty()) {
            auto [node, mask, dist] = q.front(); q.pop();
            if (mask == full) return dist;
            for (int next : graph[node]) {
                int newMask = mask | (1 << next);
                if (!visited[next][newMask]) {
                    visited[next][newMask] = true;
                    q.push({next, newMask, dist + 1});
                }
            }
        }
        return -1;
    }
};
```
