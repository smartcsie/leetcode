# 747. Largest Number At Least Twice of Others

[在 LeetCode 上查看](https://leetcode.com/problems/largest-number-at-least-twice-of-others/)

**難度:** 🟢 Easy　**標籤:** Array Min Max, Linear Scan　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練　🏆 **最佳解**

```cpp
/**
 * 題目：747. Largest Number At Least Twice of Others (至少是其他數字兩倍的最大數)
 * 難度：簡單 (Easy)
 * 描述：給定整數陣列 nums（保證最大值唯一），判斷最大值是否至少是陣列中
 *       其他所有數字的兩倍。若是，回傳最大值的索引；否則回傳 -1。
 *
 * 時間複雜度：O(N) - 只需常數次線性掃描（找最大值 + partial_sort 找次大值，
 *             partial_sort 挑 2 個元素的成本仍是 O(N)）。
 * 空間複雜度：O(1) - 只使用常數個額外變數。
 *
 * 解法思路：
 * 1. 邊界情況：陣列只有一個元素 (Single Element Edge Case)：
 *    - 官方測資明確包含 nums = [1] 這種情況，此時沒有其他數字可比較，
 *      直接回傳索引 0（唯一元素天然「至少是其他數字的兩倍」，因為根本沒有其他數字）。
 *    - ⚠️ 若省略這個判斷，直接呼叫 partial_sort(begin, begin+2, end)，
 *      當陣列長度為 1 時，中間迭代器 begin+2 會超出 end()，屬於未定義行為，
 *      經 AddressSanitizer 驗證會產生 heap-buffer-overflow。
 * 2. 先記錄最大值的原始索引 (Capture Index Before Reordering)：
 *    - 用 std::max_element 找到最大值的位置，並在還沒打亂陣列順序之前，
 *      先把它的索引記錄下來。
 * 3. 用 partial_sort 找出最大與次大值 (Partial Sort for Top-2)：
 *    - partial_sort(begin, begin+2, end, greater<int>()) 只需要保證
 *      前兩個位置是「最大」與「次大」值，不需要對整個陣列完全排序，
 *      比呼叫完整 sort 更省成本。
 * 4. 判斷「至少兩倍」的條件：
 *    - 若次大值的兩倍仍小於等於最大值（nums[1]*2 <= nums[0]），
 *      代表最大值確實至少是所有其他數字的兩倍，回傳先前記錄的索引；否則回傳 -1。
 */
class Solution {
public:
    int dominantIndex(vector<int>& nums) {
        int first = INT_MIN;
        int second = INT_MIN;
        int maxIdx = -1;
        for(int i = 0; i < nums.size(); i++) {
            if(nums[i] > first) {
                second = first;
                first = nums[i]; 
                maxIdx = i;
            } else if(nums[i] > second) {
                second = nums[i]; 
            }
        }
        return first >= 2 * second ? maxIdx : -1;
    }
};
```
