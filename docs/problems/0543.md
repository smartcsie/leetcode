# 543. Diameter of Binary Tree

[在 LeetCode 上查看](https://leetcode.com/problems/diameter-of-binary-tree/)

**難度:** 🟢 Easy　**標籤:** Tree, DFS　**時間:** O(N)　**空間:** O(H)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        int diameter = 0;
        auto dfs = [&](this auto&& dfs, TreeNode* root) -> int {
            if(!root) return 0;
            int l = dfs(root->left);
            int r = dfs(root->right);
            diameter = max (diameter, l + r);
            return 1 + max(l , r);
        };
        dfs(root);
        return diameter;
    }
};
```
