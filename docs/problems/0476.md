# 476. Number Complement

[在 LeetCode 上查看](https://leetcode.com/problems/number-complement)

**難度:** 🟢 Easy　**標籤:** Bit Manipulation　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：476. Number Complement (數字的補數)
 * 難度：簡單 (Easy)
 * 描述：給定一個正整數，將其二進位表示中的所有位元反轉（不包含前導零）。
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 *
 * 設計思路：
 * 1. 1. 建立一個與 num 等長的 Mask，其位元皆為 1。
 * 2. 2. num ^ Mask 即為反轉後的結果。
 */

class Solution {
public:
    int findComplement(int num) {
        int mask = 0;
        int temp = num;
        while(temp > 0) {
            mask = (mask << 1) | 1;
            temp >>= 1;
        }
        return num ^ mask;
    }
};
```
