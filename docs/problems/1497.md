# 1497. Check If Array Pairs Are Divisible by k

[在 LeetCode 上查看](https://leetcode.com/problems/check-if-array-pairs-are-divisible-by-k/)

**難度:** 🟡 Medium　**標籤:** Hash Table, Remainder Counting　**時間:** O(N+K)　**空間:** O(K)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1497. Check If Array Pairs Are Divisible by k
 * 難度：待補充
 * 描述：給你一個整數陣列 arr 和一個整數 k。其中 arr 的長度是偶數。
 * 請你判斷是否可以將 arr 中的元素分成 n / 2 個對，使得每對元素的和都能被 k 整除。
 * 如果可以，返回 true；否則，返回 false。
 *
 * 時間複雜度：O(N+K) - 統計模 K 的餘數，配對互補餘數。
 * 空間複雜度：O(K) - 計數陣列大小為 K。
 *
 * 解法思路：
 * （餘數頻率統計 Remainder Modulo Counting）：
 * 1. 餘數正規化：
 * - 數字對 $k$ 取餘數時，C++ 的負數取餘可能會得到負值（例如 `-3 % 5 = -3`）。
 * - 透過 `num %= k` 後接著 `if (num < 0) num += k;`，將所有餘數統一對齊到 $[0, k-1]$ 的正整數區間。
 * 2. 統計各餘數頻率：
 * - 建立大小為 $k$ 的計數陣列 `counts`，記錄每個餘數出現的次數。
 * 3. 檢查配對條件：
 * - 餘數為 `0` 的數字個數必須是偶數（因為必須兩兩相加被 $k$ 整除）。
 * - 對於任意餘數 `i`（$1 \le i \le k/2$），其對應的補數餘數 `k - i` 的出現次數必須與 `i` 相同（即 `counts[i] == counts[k - i]`）。當 $i = k - i$（即剛好是 $k$ 的一半時，這會在下一輪或邊界條件正確處理，特別是當 $k$ 為偶數時 $k/2$ 的頻率需為偶數，而本邏輯中若 $i == k - i$ 則 `counts[i] != counts[k - i]` 不會成立，且在前面正規化時餘數最大為 $k-1$）。
 */

class Solution {
public:
    bool canArrange(std::vector<int>& arr, int k) {
        std::vector<int> counts(k, 0);
        // 正規化並統計所有數字除以 k 的餘數頻率
        for (int& num : arr) {
            num %= k;
            if (num < 0) num += k;
            counts[num]++;
        }
        // 餘數 0 的總個數必須為偶數
        if (counts[0] & 1) return false;
        // 檢查其餘互補的餘數對 (i, k - i) 數量是否相等
        for (int i = 1; i <= k / 2; i++) {
            if (counts[i] != counts[k - i]) {
                return false;
            }
        }
        return true;
    }
};
```
