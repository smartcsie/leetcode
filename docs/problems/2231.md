# 2231. Largest Number After Digit Swaps by Parity

[在 LeetCode 上查看](https://leetcode.com/problems/largest-number-after-digit-swaps-by-parity/)

**難度:** 🟢 Easy　**標籤:** Greedy Sorting Decision, Partition by Parity　**時間:** O(DlogD)　**空間:** O(D)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：2231. Largest Number After Digit Swaps by Parity
 * 難度：簡單 (Easy)
 * 描述：允許交換 num 中奇偶性相同的數位任意次，求交換後能得到的最大整數。
 * 核心概念：
 * - 奇偶性相同的數位可以任意重排，奇偶性不同則位置固定不變。
 * - 依奇偶性將字元分成兩組，各自由大到小排序。
 * - 依照原字串每個位置的奇偶性，貪心地依序填入該組中最大的字元。
 *
 * 時間複雜度：O(DlogD)
 * 空間複雜度：O(D)
 */

class Solution {
public:
    int largestInteger(int num) {
        string s = to_string(num);
        vector<vector<char>> chs(2);
        for(const char& c : s) {
            chs[c & 1].push_back(c);
        }
        sort(chs[0].begin(), chs[0].end(), greater<>());
        sort(chs[1].begin(), chs[1].end(), greater<>());
        vector<int> idx(2, 0);
        for(char& c : s) {
            c = chs[c & 1][idx[c & 1]++];
        }
        return stoi(s);
    }
};
```

> 初始化 vector<vector<char>> chs(2);，travsal char，分成奇數，偶數<br>
> 把char分到bucket，for(const char& c : s) buckets[c & 1].push_back(c); <br>
> 兩組bucket直接排序，由大到小 <br>
> 擺回s，for(char& c : s)  c = buckets[c & 1][index[c & 1]++];<br>
