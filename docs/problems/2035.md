# 2035. Partition Array Into Two Arrays to Minimize Sum Difference

[在 LeetCode 上查看](https://leetcode.com/problems/partition-array-into-two-arrays-to-minimize-sum-difference/)

**難度:** 🔴 Hard　**標籤:** Dp Knapsack　**時間:** O(N　**空間:** O(2^(N/2))　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：2035. Partition Array Into Two Arrays to Minimize Sum Difference
 * 難度：困難 (Hard)
 * 描述：給定一個長度為 2n 的陣列 nums，把它切成兩個長度都是 n 的陣列，
 * 求兩個陣列元素總和的差的絕對值最小是多少。
 *
 * 時間複雜度：O(N * 2^(N/2))
 * 空間複雜度：O(2^(N/2))
 *
 * 解法思路：
 * （Meet in the Middle，折半枚舉 + 二分搜尋）：
 * 1. 這題如果直接用標準 0/1 knapsack DP，狀態是「選幾個數字、和是多少」，
 *    但總和可能是負數（陣列元素可以是負的），值域太大做不了 dp 陣列，
 *    所以改用折半枚舉：把陣列從中間切成左右兩半 lNums、rNums。
 * 2. 對左右兩半各自用 dfs 窮舉所有子集合，依照「選了幾個元素」分組，
 *    存進 lSums[count] / rSums[count]（例如 lSums[3] 存左半邊選 3 個
 *    元素的所有可能總和）。
 * 3. 因為最終要把陣列切成左右各 n 個元素，所以左半選 lCount 個、右半就
 *    一定要選 n - lCount 個才會湊滿 n 個。對每個 lCount，把對應的
 *    rSums[n - lCount] 排序，這樣就能對每個左半的和 lSum，二分搜尋右半
 *    有沒有一個和 rSum 使得 lSum + rSum 最接近 goal（總和的一半），
 *    這樣兩邊差距就會最小。
 * 4. 對每個候選的二分搜尋結果（包含 lower_bound 前後兩個候選），計算切出來
 *    的兩個部分（大小都是 n）的和的差，更新最小值。
 * 5. 之所以能用折半枚舉優化：n 最多到 15，直接窮舉全部 2n 個元素的子集合
 *    是 O(2^30) 做不了，但拆成兩半各自窮舉只要 O(2^15)，再靠排序 +
 *    二分搜尋合併兩邊結果。
 */
class Solution {
private:
    void dfs(const vector<int>& arr, int i, int count, int path, vector<vector<int>>& sums) {
        if (i == arr.size()) {
            sums[count].push_back(path);
            return;
        }
        dfs(arr, i + 1, count + 1, path + arr[i], sums);
        dfs(arr, i + 1, count, path, sums);
    }
    int firstGreaterEqual(const vector<int>& arr, int target) {
        return ranges::lower_bound(arr, target) - arr.begin();
    }
 public:
    int minimumDifference(vector<int>& nums) {
        const int n = nums.size() / 2;
        const int sum = accumulate(nums.begin(), nums.end(), 0);
        const int goal = sum / 2;
        const vector<int> lNums(nums.begin(), nums.begin() + n);
        const vector<int> rNums(nums.begin() + n, nums.end());
        int ans = INT_MAX;
        vector<vector<int>> lSums(n + 1);
        vector<vector<int>> rSums(n + 1);
        dfs(lNums, 0, 0, 0, lSums);
        dfs(rNums, 0, 0, 0, rSums);
        for (int lCount = 0; lCount <= n; ++lCount) {
            auto& l = lSums[lCount];
            auto& r = rSums[n - lCount];
            ranges::sort(r);
            for (const int lSum : l) {
                const int i = firstGreaterEqual(r, goal - lSum);
                if (i < r.size()) {
                    const int sumPartOne = sum - lSum - r[i];
                    const int sumPartTwo = sum - sumPartOne;
                    ans = min(ans, abs(sumPartOne - sumPartTwo));
                }
                if (i > 0) {
                    const int sumPartOne = sum - lSum - r[i - 1];
                    const int sumPartTwo = sum - sumPartOne;
                    ans = min(ans, abs(sumPartOne - sumPartTwo));
                }
            }
        }
        return ans;
    }
};
```
