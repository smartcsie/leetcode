# 80. Remove Duplicates from Sorted Array II

[在 LeetCode 上查看](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/)

**難度:** 🟡 Medium　**標籤:** Fast Slow Pointers, Fast-Slow Pointers　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟣 易忘

```cpp
/**
 * 題目：80. Remove Duplicates from Sorted Array II (刪除有序陣列中的重複項 II)
 * 難度：中等 (Medium)
 * 描述：給你一個有序陣列 nums ，請你原地刪除重複出現的元素，使得出現次數超過兩次的元素只出現兩次。
 * 返回刪除後陣列的新長度。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 使用變數 `count` (慢指標) 紀錄下一個有效元素該存放的位置。
 * 2. 使用 `i` (快指標) 遍歷整個陣列。
 * 3. 核心判定條件：
 * - 如果 `count < 2`，代表目前的結果陣列長度不足 2，任何元素都可以直接放入。
 * - 如果 `nums[i] > nums[count - 2]`，代表當前元素與結果陣列中「倒數第二個」元素不同。
 * 由於陣列是有序的，這保證了同一個數字最多只會被存入兩次。
 */

class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int slow = 0;
        for(int fast = 0; fast < nums.size(); fast++) {
            if(fast < 2 || nums[fast] > nums[slow - 2]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        return slow;
    }
};
```
