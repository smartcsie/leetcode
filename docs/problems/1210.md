# 1210. Minimum Moves to Reach Target With Rotations

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-moves-to-reach-target-with-rotations/)

**難度:** 🔴 Hard　**標籤:** Greedy Coin Change　**時間:** O(N²)　**空間:** O(N²)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1210. Minimum Moves to Reach Target With Rotations
 * 難度：困難 (Hard)
 * 描述：n×n 網格裡有一條佔據兩格的蛇，從左上角 (0,0)-(0,1)（水平）
 * 出發，目標是移動到右下角 (n-1,n-2)-(n-1,n-1)（水平）。蛇可以往右
 * 移、往下移、或旋轉（水平轉直立/直立轉水平），障礙格不能經過，求
 * 最少移動次數。
 *
 * 時間複雜度：O(N²)
 * 空間複雜度：O(N²)
 *
 * 解法思路：
 * （BFS 最短路徑，狀態是「蛇尾座標 + 蛇的方向（水平/直立）」，這題
 * 分類在 Greedy 底下，但實際解法是圖論 BFS，貼近程度沒有很高，先
 * 列出正確解法讓你先收進去）：
 * 1. 狀態編碼：(row, col, horiz)，(row, col) 是蛇尾座標，horiz 代表
 *    蛇目前是水平還是直立。水平時蛇頭在 (row, col+1)；直立時蛇頭在
 *    (row+1, col)。
 * 2. 從起點 (0, 0, 水平) 開始 BFS，四種可能的移動：
 *    - 水平向右移：蛇頭要能踏進的新格子 (row, col+2) 必須空。
 *    - 水平向下移：蛇身整個往下平移一格，(row+1, col) 跟
 *      (row+1, col+1) 都要空。
 *    - 順時鐘旋轉（水平→直立）：條件跟「水平向下移」一樣（兩個下方
 *      格子都要空），旋轉後蛇尾留在原地，蛇頭變成 (row+1, col)。
 *    - 直立的三種移動同理，方向相反（向下移、向右移、逆時鐘旋轉）。
 * 3. **重要的邊界細節（也是這題容易寫錯的地方）**：目標終點固定是
 *    「水平」佔據 (n-1, n-2) 和 (n-1, n-1)，**沒有「直立達標」這種
 *    情況**——因為題目定義的終點座標就是同一列的兩個相鄰格子，只有
 *    水平方向能對得上。曾經誤加一個「直立也能算到達終點」的判斷式，
 *    用構造測資驗證後發現這個判斷式會讓 BFS 找到一條「提早停在直立
 *    狀態、但實際上根本沒有真正抵達終點格子」的假捷徑，導致算出比
 *    正確答案更短（也更錯誤）的步數。拿掉這個誤加的判斷後，兩組官方
 *    範例才吻合（11 和 9）。
 * 4. 用 BFS 保證第一次到達終點狀態時的步數就是最短路徑。
 */
class Solution {
public:
    int minimumMoves(vector<vector<int>>& grid) {
        int n = grid.size();
        auto encode = [&](int r, int c, int horiz) {
            return (r * n + c) * 2 + horiz;
        };
        vector<bool> visited(n * n * 2, false);
        queue<tuple<int,int,int,int>> q;

        q.push({0, 0, 1, 0});
        visited[encode(0, 0, 1)] = true;

        auto isFree = [&](int r, int c) {
            return r >= 0 && r < n && c >= 0 && c < n && grid[r][c] == 0;
        };

        while (!q.empty()) {
            auto [r, c, horiz, dist] = q.front(); q.pop();

            if (horiz && r == n - 1 && c == n - 2) return dist;

            vector<tuple<int,int,int>> next;

            if (horiz) {
                if (isFree(r, c + 2)) next.push_back({r, c + 1, 1});
                if (r + 1 < n && isFree(r + 1, c) && isFree(r + 1, c + 1)) {
                    next.push_back({r + 1, c, 1});
                    next.push_back({r, c, 0});
                }
            } else {
                if (isFree(r + 2, c)) next.push_back({r + 1, c, 0});
                if (c + 1 < n && isFree(r, c + 1) && isFree(r + 1, c + 1)) {
                    next.push_back({r, c + 1, 0});
                    next.push_back({r, c, 1});
                }
            }

            for (auto& [nr, nc, nh] : next) {
                int key = encode(nr, nc, nh);
                if (!visited[key]) {
                    visited[key] = true;
                    q.push({nr, nc, nh, dist + 1});
                }
            }
        }
        return -1;
    }
};
```
