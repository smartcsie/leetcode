# 2023. Number of Pairs of Strings With Concatenation Equal to Target

[在 LeetCode 上查看](https://leetcode.com/problems/number-of-pairs-of-strings-with-concatenation-equal-to-target/)

**難度:** 🟡 Medium　**標籤:** Hash Table, String, Single-Pass　**時間:** O(N*L)　**空間:** 　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：2023. Number of Pairs of Strings With Concatenation Equal to Target
 * 難度：待補充
 * 描述：給你一個字串陣列 nums 和一個目標字串 target，請你返回滿足 nums[i] + nums[j] == target
 * 且下標 i 和 j 不同的數對 (i, j) 的數量。
 *
 * 時間複雜度：O(N*L)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * 1. 單次走訪與動態累積（Single-Pass & Dynamic Accumulation）：
 * - 我們不需要預先將所有字串建構雜湊表。在迴圈掃描 `nums` 時，`count` 內只會存放「在當前元素之前出現過的字串」。
 * 2. 剪枝優化（Early Pruning）：
 * - 若當前字串的長度 `k` 大於或等於 `target` 的長度 `n`，它絕對無法組合成 target，直接用 `continue` 跳過。
 * 3. 前綴與後綴雙向匹配（Prefix & Suffix Check）：
 * - 若當前字串符合 `target` 的前綴，則去尋找先前出現過的對應後綴（`target.substr(k)`）。
 * - 若當前字串符合 `target` 的後綴，則去尋找先前出現過的對應前綴（`target.substr(0, n - k)`）。
 * 4. 自我更新：
 * - 查詢完畢後，將當前字串加入 `count` 統計中，自然避開了同下標自我配對的問題。
 */

class Solution {
public:
    int numOfPairs(std::vector<std::string>& nums, std::string target) {
        const int n = target.length();
        int ans = 0;
        std::unordered_map<std::string, int> count;

        for (const std::string& num : nums) {
            const int k = num.length();
            
            // 剪枝：字串長度大於或等於 target 時不可能組成 target
            if (k >= n) {
                continue;
            }
            
            // 檢查當前字串是否為 target 的前綴，若是則累加其對應後綴過去出現的次數
            if (target.substr(0, k) == num) {
                ans += count[target.substr(k)];
            }
            
            // 檢查當前字串是否為 target 的後綴，若是則累加其對應前綴過去出現的次數
            if (target.substr(n - k) == num) {
                ans += count[target.substr(0, n - k)];
            }
            
            // 將當前字串納入歷史統計中
            ++count[num];
        }

        return ans;
    }
};
```
