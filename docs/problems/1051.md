# 1051. Height Checker

[在 LeetCode 上查看](https://leetcode.com/problems/height-checker/)

**難度:** 🟢 Easy　**標籤:** Sorting Counting Sort, Counting Sort　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：1051. Height Checker (高度檢查器)
 * 難度：簡單 (Easy)
 * 描述：統計與非遞減排序後陣列不相符的索引數量。
 *
 * 時間複雜度：O(N) - 遍歷數次陣列，無須完整排序。
 * 空間複雜度：O(K) - K 為高度範圍 (通常為 100)，即 O(1) 空間。
 *
 * 解法思路：
 * (Counting Sort)：
 * 由於身高範圍有限 (1-100)，我們不需進行 O(N log N) 的排序。
 * 建立一個頻率陣列紀錄每個高度出現次數，再依序比對即可。
 */

class Solution {
public:
    int heightChecker(vector<int>& heights) {
        vector<int>& h = heights;
        vector<int> counts(101, 0);
        for(const int& x : h) counts[x]++;
        int ans = 0;
        int y = 0;
        for(const int& x : h) {
            while(y < 101 && !counts[y]) y++;
            if(x != y) ans++;
            counts[y]--;
        }
        return ans;
    }
};
```
