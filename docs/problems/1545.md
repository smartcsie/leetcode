```cpp
/**
 * 題目：1545. Find Kth Bit in Nth Binary String
 * 難度：中等 (Medium)
 * 描述：定義二進位字串序列 S1="0"，Sn = Sn-1 + "1" + reverse(invert(Sn-1))，
 * 求第 n 個字串的第 k 個位元（1-indexed）。
 *
 * 時間複雜度：O(1)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （位元運算數學推導）：
 * 觀察 Sn 的結構，第 k 個位元由兩個因素決定：
 *
 * 1. 基準位元（原始值）：
 *    k 為偶數 → 位於後半段（翻轉區），基準為 1
 *    k 為奇數 → 位於前半段，基準為 0
 *    即 (k & 1) == 0 → 基準為 1，否則為 0
 *
 * 2. 是否需要翻轉：
 *    k / (k & -k) 去掉 k 的最低位 1 後右移一位，
 *    若結果為奇數則需翻轉，偶數則不翻轉。
 *    即 ((k / (k & -k)) >> 1) & 1
 *
 * 3. 最終結果：兩者 XOR
 *    基準為 1 且需翻轉 → 0
 *    基準為 1 且不翻轉 → 1
 *    基準為 0 且需翻轉 → 1
 *    基準為 0 且不翻轉 → 0
 *
 * 注意：此解法不依賴 n，直接由 k 推導，O(1) 時間空間。
 */
class Solution {
public:
    char findKthBit(int n, int k) {
        return '0' + (((k & 1) == 0) ^ (((k / (k & -k)) >> 1) & 1));
    }
};
```
