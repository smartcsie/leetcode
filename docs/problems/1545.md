# 1545. Find Kth Bit in Nth Binary String

[在 LeetCode 上查看](https://leetcode.com/problems/find-kth-bit-in-nth-binary-string/)

**難度:** 🟡 Medium　**標籤:** Backtracking Permutation, Recursion, Divide and Conquer　**時間:** O(N)　**空間:** O(N)

```cpp
/**
 * 題目：1545. Find Kth Bit in Nth Binary String (找出第 N 個二進位字串的第 K 個位元)
 * 難度：中等 (Medium)
 * 描述：定義字串 S1 = "0"，Sᵢ = S(i-1) + "1" + reverse(invert(S(i-1)))。
 *       給定 n 與 k，回傳字串 Sₙ 中第 k 個位元（1-indexed）。
 *
 * 時間複雜度：O(N) - 每次遞迴呼叫將 n 減 1，最多遞迴 N 層。
 * 空間複雜度：O(N) - 遞迴呼叫堆疊（Call Stack）深度最多為 N。
 *
 * 解法思路：
 * 1. 遞迴邊界 (Base Case)：
 *    - 當 n == 1 時，字串固定是 "0"，直接回傳 '0'。
 * 2. 定位中間點 (Middle Index)：
 *    - 字串 Sₙ 長度為 2ⁿ - 1，其正中間的位置（1-indexed）恰好是 2^(n-1)，
 *      該位置固定是組成過程中插入的 '1'。
 * 3. 三種情況遞迴處理：
 *    - 若 k 剛好等於中間位置，直接回傳 '1'。
 *    - 若 k 小於中間位置，代表落在左半部（即 S(n-1) 本身），直接遞迴 findKthBit(n-1, k)。
 *    - 若 k 大於中間位置，代表落在右半部（reverse(invert(S(n-1)))），
 *      利用對稱性換算成左半部對應的索引 midIndex * 2 - k，
 *      並將遞迴結果反轉（0 變 1、1 變 0），因為右半部是「反轉」後「取反」的結果。
 */
class Solution {
public:
    char findKthBit(int n, int k) {
        if (n == 1)
            return '0';
        const int midIndex = pow(2, n - 1);  // 1-indexed
        if (k == midIndex)
            return '1';
        if (k < midIndex)
            return findKthBit(n - 1, k);
        return findKthBit(n - 1, midIndex * 2 - k) == '0' ? '1' : '0';
    }
};
```
