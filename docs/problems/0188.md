# 188. Best Time to Buy and Sell Stock IV

[在 LeetCode 上查看](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iv/)

**難度:** 🔴 Hard　**標籤:** Dp State Machine　**時間:** O(N　**空間:** O(K)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：188. Best Time to Buy and Sell Stock IV
 * 難度：困難 (Hard)
 * 描述：給定每天的股價 prices 和一個整數 k，最多可以進行 k 次交易，求
 * 最大總利潤。
 *
 * 時間複雜度：O(N*K)
 * 空間複雜度：O(K)
 *
 * 解法思路：
 * （State Machine DP，123 題的直接推廣，把固定的 4 個變數換成陣列，
 * 支援任意 k 次交易）：
 * 1. buy[i]、sell[i] 分別代表「完成第 i 次買進」「完成第 i 次交易」
 *    之後的最大利潤，i 從 1 到 k。
 * 2. 初始化：buy[i] = -∞（還沒真的買過），sell[0] = 0（完成 0 次交易，
 *    利潤是 0，當作第 1 次買進的本錢起點）。
 * 3. 狀態轉移，每天依序對 i = 1 到 k 更新（順序要由小到大，因為
 *    buy[i] 依賴同一天的 sell[i-1]）：
 *    buy[i] = max(buy[i], sell[i-1] - price)
 *    sell[i] = max(sell[i], buy[i] + price)
 * 4. 答案是 sell[k]（完成最多 k 次交易後的最大利潤；如果 k 次交易不是
 *    最優，sell[k] 也會自然等於用更少次交易達到的最大值，因為
 *    「不交易」這個選項已經隱含在 max 裡）。
 * 5. 跟 123 的關係：123 就是這題 k = 2 的特例；k 很大（>= n/2）時，
 *    這題會退化成 122（次數限制形同虛設），實務上可以加一個判斷直接
 *    走 122 的邏輯省時間，但這版為了跟同分類模板一致，統一用 O(N*K)
 *    的陣列版本。
 */
class Solution {
public:
    int maxProfit(int k, vector<int>& prices) {
        int n = prices.size();
        if (n == 0 || k == 0) return 0;
        vector<int> buy(k + 1, INT_MIN), sell(k + 1, 0);
        for (int price : prices) {
            for (int i = 1; i <= k; ++i) {
                buy[i] = max(buy[i], sell[i - 1] - price);
                sell[i] = max(sell[i], buy[i] + price);
            }
        }
        return sell[k];
    }
};
```
