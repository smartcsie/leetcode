# 2243. Calculate Digit Sum of a String

[在 LeetCode 上查看](https://leetcode.com/problems/calculate-digit-sum-of-a-string/)

**難度:** 🟢 Easy　**標籤:** String, Simulation　**時間:** O(N*logN)　**空間:** O(N)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：2243. Calculate Digit Sum of a String
 * 難度：簡單 (Easy)
 * 描述：重複將長度大於 k 的字串分組並替換為各組數位和的字串形式。
 * 優化重點：
 * 1. 外層迴圈：使用 while 循環持續檢查長度是否大於 k。
 * 2. 分組處理：使用步進式 for 迴圈 (i += k) 進行分組。
 * 3. 類型轉換：透過 str[j] - '0' 取得整數，並用 to_string 將和轉回字串。
 *
 * 時間複雜度：O(N*logN)
 * 空間複雜度：O(N)
 */

#include <string>

class Solution {
public:
    std::string digitSum(std::string s, int k) {
        string t = s;
        while(t.size() > k) {
            string next;
            for(int i = 0; i < t.size(); i += k) {
                int sum = 0;
                for(int j = i; j < i + k && j < t.size(); j++) {
                    sum += t[j] - '0';
                }
                next += to_string(sum);
            }
            t = next;
        }
        return t;
    }
};
```
