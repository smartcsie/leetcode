# 103. Binary Tree Zigzag Level Order Traversal

[在 LeetCode 上查看](https://leetcode.com/problems/binary-zigzag-level-order-traversal/)

## 解法：tree-bfs-level-order

**難度:** 🟡 Medium　**標籤:** Tree Bfs Level Order, BFS　**時間:** O(N)　**空間:** O(W)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：103. Binary Tree Zigzag Level Order Traversal (二元樹 Z 字型層次遍歷)
 * 難度：中等 (Medium)
 * 描述：以 Z 字型順序遍歷二元樹。
 *
 * 時間複雜度：O(N) - 每個節點僅被存取一次。
 * 空間複雜度：O(W) - W 為樹的最大寬度，用於儲存隊列與當前層節點。
 *
 * 解法思路：
 * 1. 使用 `std::deque` 可以在 O(1) 時間內進行雙端插入，避免 `reverse()` 操作帶來的 O(K) 額外開銷。
 * 2. 透過 `res.reserve(N)` 與 `oneLevel.reserve(width)` 預分配記憶體，提升效能。
 */

class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        if(!root) return {};
        deque<TreeNode*> q({root});
        vector<vector<int>> ans;
        bool leftToRight = true;
        while(!q.empty()) {
            vector<int> row;
            for(int i = q.size() - 1; i >= 0; i--) {
                 TreeNode* node;
                if(leftToRight) {
                    node= q.front();
                    q.pop_front();
                    row.push_back(node->val);
                    if(node->left) q.push_back(node->left);
                    if(node->right) q.push_back(node->right);
                } else {
                    node = q.back();
                    q.pop_back();
                    row.push_back(node->val);
                    if(node->right) q.push_front(node->right);
                    if(node->left) q.push_front(node->left);
                }
            }
            leftToRight = !leftToRight;
            ans.push_back(row);
        }
        return ans;
    }
};
```

## 解法：tree-bfs-level-order

**難度:** 🟡 Medium　**標籤:** Tree Bfs Level Order　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：103. Binary Tree Zigzag Level Order Traversal
 * 難度：中等 (Medium)
 * 分類主題：tree-bfs-level-order
 * 描述：給定一棵二元樹，回傳「之字形」層序走訪結果：第一層由左到右，
 * 第二層由右到左，第三層再由左到右，依此類推交替。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （標準 BFS + queue，用「鏡射索引」取代真正的反轉操作，這是用純
 * queue 解這題的關鍵技巧——跟用 deque 從頭插入模擬反向是不同的
 * 做法）：
 * 1. 用普通的 `queue`（先進先出，只能從尾端加入、從前端取出），
 *    跟 102 的 BFS 框架完全一樣，先記錄這一層節點數 size，用固定
 *    次數的內層迴圈只處理這一層。
 * 2. **這題唯一的差異，也是不用 deque 也能做到反向的訣竅**：不是
 *    處理完這一層再整個 reverse 一次，而是在填入 level 陣列的當下，
 *    就直接決定「這個節點該放在陣列的哪個位置」：
 *    - 由左到右的層：照正常順序放，`idx = i`。
 *    - 由右到左的層：放在「鏡射」位置，`idx = size - 1 - i`（第一個
 *      處理到的節點放在陣列最後面，最後一個處理到的放在最前面，
 *      效果等同於整層反過來排列）。
 * 3. 因為 level 陣列是先用 `size` 開好固定大小（不是用 push_back
 *    累加），才能直接用索引 `level[idx] = ...` 隨意填值，不用等
 *    整層蒐集完再反轉。
 * 4. 每處理完一層，用一個布林旗標 `leftToRight` 切換方向，交替
 *    進行到佇列清空為止。
 * 5. 這版完全不需要 deque 的「雙端插入」特性，因為方向的切換是用
 *    「填入位置」的巧思處理掉了，而不是真的去改變資料結構的存取
 *    方向——這也是這題「queue 版」跟某些教學會寫的「deque 版」
 *    （利用 push_front 讓某層由右到左疊出來）思路上的差別。
 */
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        if(!root) return {};
        queue<TreeNode*> q({root});
        vector<vector<int>> ans;
        bool leftToRight = true;
        while(!q.empty()) {
            int n = q.size();
            vector<int> level(n);
            for(int i = 0; i < n; i++) {
                TreeNode* node = q.front();
                q.pop();
                int idx = leftToRight ? i : n - i - 1;
                level[idx] = node->val;
                if(node->left) q.push(node->left);
                if(node->right) q.push(node->right);
            }
            ans.push_back(level);
            leftToRight = !leftToRight;
        }
        return ans;
    }
};
```
