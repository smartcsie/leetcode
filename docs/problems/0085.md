# 85. Maximal Rectangle

[在 LeetCode 上查看](https://leetcode.com/problems/maximal-rectangle/)

**難度:** 🔴 Hard　**標籤:** Dp Grid Path　**時間:** O(M　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：85. Maximal Rectangle
 * 難度：困難 (Hard)
 * 描述：給定一個只由 '0' 和 '1' 組成的二維矩陣 matrix，找出只包含 '1' 的
 * 最大矩形區域，回傳它的面積。
 *
 * 時間複雜度：O(M*N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （逐行轉成直方圖 + Largest Rectangle in Histogram，單調堆疊）：
 * 1. 這題可以拆解成「這一列以上，每一欄連續 1 的高度」，逐行累積成一個
 *    直方圖：heights[j] 代表「這一欄從目前這一列往上數，連續幾個 1」，
 *    遇到 '0' 就重置為 0，遇到 '1' 就 +1。
 * 2. 每處理完一列，就用「Largest Rectangle in Histogram」（84 題）的
 *    單調遞增堆疊解法，算出目前這個直方圖能圍出的最大矩形面積，跟全域
 *    最大值取 max。
 * 3. 單調堆疊的邏輯：堆疊裡存的是「高度遞增」的欄位索引，遇到比堆疊頂端
 *    矮的高度時，代表堆疊頂端那根柱子的矩形範圍到此為止，彈出並計算
 *    「這根柱子的高度 × 它能延伸的寬度」，寬度由目前位置跟彈出後新的
 *    堆疊頂端決定。
 * 4. 遍歷完所有列之後，best 就是整個矩陣裡最大的矩形面積。
 * 5. 之所以能用這個技巧：把二維問題拆成「每一列都跑一次一維的直方圖
 *    最大矩形」，逐列更新直方圖高度，就把二維問題降維成 M 次一維問題。
 */
class Solution {
public:
    int maximalRectangle(vector<vector<char>>& matrix) {
        if (matrix.empty()) return 0;
        int n = matrix[0].size();
        vector<int> heights(n, 0);
        int best = 0;
        for (auto& row : matrix) {
            for (int j = 0; j < n; ++j) {
                heights[j] = (row[j] == '1') ? heights[j] + 1 : 0;
            }
            best = max(best, largestRectangleArea(heights));
        }
        return best;
    }

private:
    int largestRectangleArea(vector<int>& heights) {
        stack<int> st;
        int n = heights.size();
        int best = 0;
        for (int i = 0; i <= n; ++i) {
            int h = (i == n) ? 0 : heights[i];
            while (!st.empty() && heights[st.top()] >= h) {
                int height = heights[st.top()];
                st.pop();
                int width = st.empty() ? i : i - st.top() - 1;
                best = max(best, height * width);
            }
            st.push(i);
        }
        return best;
    }
};
```
