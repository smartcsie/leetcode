# 1567. Maximum Length of Subarray With Positive Product

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-length-of-subarray-with-positive-product/)

**難度:** 🟡 Medium　**標籤:** Dynamic Programming　**時間:** O(N) - 僅需對 nums 陣列進行一次從頭到尾的線性掃描，每個元素的狀態轉移皆為常數時間。　**空間:** O(1) - 僅使用常數個變數（ans, pos, neg）來動態追蹤狀態，不需額外配置記憶體。　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1567. Maximum Length of Subarray With Positive Product (乘積為正數的最長子陣列長度)
 * 難度：中等 (Medium)
 * 描述：給你一個整數陣列 nums，請你求出乘積為正數的最長子陣列長度。
 *       一個陣列的乘積如果為正數，則表示該子陣列中沒有 0 且負數的個數為偶數個。
 * 
 * 時間複雜度：O(N) - 僅需對 nums 陣列進行一次從頭到尾的線性掃描，每個元素的狀態轉移皆為常數時間。
 * 空間複雜度：O(1) - 僅使用常數個變數（ans, pos, neg）來動態追蹤狀態，不需額外配置記憶體。
 * 
 * 解法思路：
 * 1. 動態規劃與狀態機（Dynamic Programming State Machine）：
 *    - 維持兩個滾動變數：`pos` 代表以當前元素結尾、乘積為「正數」的最長子陣列長度；`neg` 代表以當前元素結尾、乘積為「負數」的最長子陣列長度。
 * 2. 狀態轉移邏輯：
 *    - 若遇到 `0`：任何數乘 0 都會歸零，因此 `pos` 與 `neg` 皆重置為 `0`。
 *    - 若遇到正數：正數會讓原本的正數長度加 1（`pos + 1`）；若原本沒有負數累積（`neg == 0`）則負數長度保持 0，否則 `neg + 1`。
 *    - 若遇到負數：負負得正、正負得負。此時透過 `std::swap(pos, neg)` 將正負狀態對調，再進行長度累加。
 * 3. 收集最大值：
 *    - 在每次迴圈中，利用 `ans = std::max(ans, pos)` 持續更新全域出現過的最長正乘積子陣列長度。
 */

class Solution {
public:
    int getMaxLen(std::vector<int>& nums) {
        int ans = 0, pos = 0, neg = 0;
        for (const int& num : nums) {
            // 若為 0 則歸零；否則正數長度延伸 1
            pos = (num == 0) ? 0 : pos + 1;
            // 若為 0 或先前沒有累積負數，則負數長度歸零；否則延伸 1
            neg = (num == 0 || neg == 0) ? 0 : neg + 1;
            // 遇到負數時，正負狀態互換（負負得正）
            if (num < 0) {
                std::swap(pos, neg);
            }
            // 更新歷史最大正乘積長度
            ans = std::max(ans, pos);
        }
        return ans;
    }
};
```
