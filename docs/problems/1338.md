# 1338. Reduce Array Size to the Half

[在 LeetCode 上查看](https://leetcode.com/problems/reduce-array-size-to-the-half/)

**難度:** 🟡 Medium　**標籤:** Greedy Frequency Merging　**時間:** O(N log N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1338. Reduce Array Size to the Half
 * 難度：中等 (Medium)
 * 描述：給定一個整數陣列 arr，每次可以選一個數值，移除所有等於這個
 * 數值的元素。求最少要選幾種不同的數值，才能讓陣列剩下的元素數量
 * 不超過原本的一半。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Huffman-Type Greedy 的簡化版：不用真的建堆，排序就能達到同樣的
 * 貪心效果，因為這裡不需要「動態」取最大值，一次排序就夠）：
 * 1. 先統計每個數值出現的次數（用雜湊表），把所有「出現次數」收集
 *    成一個陣列，由大到小排序。
 * 2. 貪心策略：優先移除「出現次數最多」的數值，這樣每移除一種數值，
 *    能扣掉最多的元素數量，用最少的種類數達到「至少移除一半」的目標。
 * 3. 依序把出現次數最多的數值累加進 removed（已移除的元素數），
 *    每累加一次 setSize（用掉的種類數）就 +1，一旦 removed 的兩倍
 *    達到原陣列長度（代表已經移除至少一半），立刻停止並回傳 setSize。
 * 4. 這題雖然貼近 Huffman-Type 的「每次挑最大」精神，但因為所有
 *    候選（各數值的出現次數）一開始就固定不變（不像 1167 合併後會
 *    產生新的候選），排序一次就能決定整個貪心順序，不需要用到堆的
 *    「動態插入」特性，用排序取代 heap 反而更簡潔。
 */
class Solution {
public:
    int minSetSize(vector<int>& arr) {
        unordered_map<int,int> freq;
        for (int x : arr) freq[x]++;

        vector<int> counts;
        for (auto& [num, cnt] : freq) counts.push_back(cnt);
        sort(counts.rbegin(), counts.rend());

        int n = arr.size();
        int removed = 0, setSize = 0;
        for (int c : counts) {
            removed += c;
            setSize++;
            if (removed * 2 >= n) break;
        }
        return setSize;
    }
};
```
