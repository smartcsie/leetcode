# 1238. Circular Permutation in Binary Representation

[在 LeetCode 上查看](https://leetcode.com/problems/circular-permutation-in-binary-representation/)

**難度:** 🟡 Medium　**標籤:** Backtracking Permutation　**時間:** O(2^N)　**空間:** O(2^N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1238. Circular Permutation in Binary Representation
 * 難度：中等 (Medium)
 * 描述：求一個長度為 2^n 的排列，包含 0 到 2^n-1 每個數字恰好一次，
 * 排列第一個數字是 start，且「相鄰的兩個數字（包含首尾相接）」的
 * 二進位表示法恰好只差一個 bit。
 *
 * 時間複雜度：O(2^N)
 * 空間複雜度：O(2^N)
 *
 * 解法思路：
 * （這題雖然題單把它放在 backtracking-permutation，但其實有一個
 * 直接的數學建構法，不需要真的窮舉搜尋——這是「生成一種特定排列」
 * 這類題目常見的公式解變形，跟其他排列題適合放一起理解）：
 * 1. 核心觀察：「相鄰只差一個 bit」正是格雷碼（Gray Code）的定義。
 *    標準格雷碼公式：`gray(i) = i ^ (i >> 1)`，可以生成一個從 0
 *    開始、相鄰只差一個 bit、首尾也只差一個 bit 的排列。
 * 2. 但這題要求「排列的第一個數字是 start」，不一定是 0，這裡用一個
 *    小技巧解決：把整個標準格雷碼序列，每一項都異或上 start
 *    （`start ^ gray(i)`）。因為異或同一個值不會改變「兩個數字之間
 *    差幾個 bit」這個性質（異或滿足結合律和交換律的位元運算特性），
 *    所以整體序列仍然保持「相鄰只差一個 bit」的性質，只是整體「平移」
 *    到以 start 開頭。
 * 3. 因為 gray(0) = 0，所以 `start ^ gray(0) = start`，第一項自然
 *    就是 start，不用額外處理。
 * 4. 對 i 從 0 到 2^n - 1，依序計算 `start ^ (i ^ (i >> 1))`，就是
 *    答案序列。
 */
class Solution {
public:
    vector<int> circularPermutation(int n, int start) {
        vector<int> result;
        for (int i = 0; i < (1 << n); ++i) {
            int gray = i ^ (i >> 1);
            result.push_back(start ^ gray);
        }
        return result;
    }
};
```
