# 404. Sum of Left Leaves

[在 LeetCode 上查看](https://leetcode.com/problems/sum-of-left-leaves)

## 解法：tree-dfs-path

**難度:** 🟢 Easy　**標籤:** Tree Dfs Path, DFS　**時間:** O(N)　**空間:** O(H)　**熟悉度:** 🟣 易忘

```cpp
/**
 * 題目：404. Sum of Left Leaves (左葉子節點之和)
 * 難度：簡單 (Easy)
 * 描述：計算二元樹中所有左葉子節點的和。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(H)
 *
 * 設計思路：
 * 1. 遞迴檢查每個節點： 1. 若該節點的左子節點是葉子，則直接加上該值。
 * 2. 2. 若不是，則遞迴搜尋左子樹與右子樹。
 */

class Solution {
public:
    int sumOfLeftLeaves(TreeNode* root) {
        if(!root) return 0;
        int sum = 0;
        if(root->left) {
            if(!root->left->left && !root->left->right) sum += root->left->val;
            else sum += sumOfLeftLeaves(root->left);
        }   
        sum += sumOfLeftLeaves(root->right);
        return sum;
    }
};
```

## 解法：tree-dfs-path

**難度:** 🟢 Easy　**標籤:** Tree Dfs Path　**時間:** O(N)　**空間:** O(H)　**熟悉度:** 🟡 練習過

```cpp
class Solution {
private:
    void dfs(TreeNode* root, int& sum, bool left) {
        if(!root) return;
        dfs(root->left, sum, true);
        if(left && !root->left && !root->right) sum += root->val;
        dfs(root->right, sum, false);
    }
public:
    int sumOfLeftLeaves(TreeNode* root) {
        int sum = 0;
        dfs(root, sum, false);
        return sum;
    }
};
```
