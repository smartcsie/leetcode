# 866. Prime Palindrome

[在 LeetCode 上查看](https://leetcode.com/problems/prime-palindrome/)

**難度:** 🟡 Medium　**標籤:** Math Prime, Prime, Palindrome Construction　**時間:** O(sqrt(10^9))　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：866. Prime Palindrome (質數回文)
 * 難度：中等 (Medium)
 * 描述：給定整數 n，回傳大於等於 n 的最小質數回文數。
 *
 * 時間複雜度：O(sqrt(10^9)) - 每次質數檢驗約需 O(sqrt(p))，回文數量遠小於一般整數範圍。
 * 空間複雜度：O(1) - 只使用常數個變數，不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 關鍵數論性質：偶數長度回文必為 11 的倍數 (Even-Length Palindrome Divisibility)：
 *    - 任何偶數長度的回文數，都可以證明必定能被 11 整除，因此除了 11 本身，
 *      其餘偶數長度回文（22, 33, ..., 1221...）都是合數，不可能是質數。
 * 2. 只需生成「奇數長度」回文即可涵蓋所有可能的質數回文 (Only Generate Odd-Length Palindromes)：
 *    - 因此可以完全跳過偶數長度回文的檢查，只需從較小的「前半段」數字，
 *      建構出奇數長度的回文數逐一檢查即可。
 * 3. makePalindrome：由前半段建構奇數長度回文 (Mirror Construction)：
 *    - 先把 i 本身當作 palindrome 的起始值，接著把 i 去掉最後一位數後的結果，
 *      依序反過來接到 palindrome 尾端，即可建構出奇數長度的回文（例如 i=123 -> 12321）。
 * 4. 特判處理唯一的偶數長度質數回文（11）：
 *    - 因為主迴圈完全不會產生偶數長度回文，必須額外特判：
 *      當 n 落在 [8, 11] 區間時，直接回傳 11（涵蓋了 11 是答案的所有情況）。
 * 5. 依序嘗試每個奇數長度回文並檢查是否為質數：
 *    - 從小到大生成回文數 p，一旦 p >= n 且 p 通過質數檢驗，立即回傳 p 作為答案。
 */
class Solution {
private:
    bool isPrime(int n) {
        if(n < 2) return false;
        if(n == 2 || n == 3) return true;
        if(n % 2 == 0 || n % 3 == 0) return false;
        for(int i = 5; i *i <= n; i += 6) {
            if(n % i == 0 || n % (i + 2) == 0) return false;
        }
        return true;
    }
    int makePalindrome(int n) {
        int palindrome = n;
        n /= 10;
        while(n > 0) {
            palindrome = palindrome * 10 + (n % 10);
            n /= 10;
        }
        return palindrome;
    }
public:
    int primePalindrome(int n) {
        if (8 <= n && n <= 11)
            return 11;

        for (int i = 1; i < 100000; i++) {
            int p = makePalindrome(i);

            if (p >= n && isPrime(p))
                return p;
        }

        return -1;
    }
};
```
