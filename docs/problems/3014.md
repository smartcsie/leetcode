# 3014. Minimum Number of Pushes to Type Word I

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-number-of-pushes-to-type-word-i/)

## 解法：greedy-sorting-decision

**難度:** 🟡 Medium　**標籤:** Greedy Sorting Decision　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：3014. Minimum Number of Pushes to Type Word I (輸入字串所需的最少按鍵次數 I)
 * 難度：中等 (Medium)
 * 描述：使用類似手機九宮格鍵盤，每個按鍵可以對應多個字母（最多 8 個字母共用同一個按鍵，
 *       按第 k 次循環切換到該按鍵上的第 k 個字母）。此版本假設 word 中的字母皆「不重複」，
 *       因此只需依照字串長度 n，分段計算每個字母所需的按鍵次數。
 *
 * 時間複雜度：O(1)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 分段計算 (Segment by Position)：
 *    - 因為每個按鍵最多容納 8 個字母，且字母無重複，
 *      故第 1~8 個字母只需按 1 次、第 9~16 個字母需按 2 次、
 *      第 17~24 個字母需按 3 次、第 25~26 個字母需按 4 次。
 * 2. 依字串長度 n 分四種情況處理：
 *    - n <= 8：全部字母都只需按 1 次，總按鍵數即為 n。
 *    - 8 < n <= 16：前 8 個字母各按 1 次（共 8 次），
 *      其餘 (n - 8) 個字母各按 2 次。
 *    - 16 < n <= 24：前 8 個按 1 次、中間 8 個按 2 次（共 8 + 16 = 24 次），
 *      其餘 (n - 16) 個字母各按 3 次。
 *    - n > 24（最多到 26）：前 24 個字母固定花費 8 + 16 + 24 = 48 次，
 *      其餘 (n - 24) 個字母各按 4 次。
 * 3. 累加各段花費，即為最終答案。
 *
 * 注意事項：
 *    - 此寫法直接以 word.size() 作為字母種類數量，
 *      隱含假設 word 中不含重複字母；
 *      若題目允許重複字母，應改採「統計詞頻 + 依頻率高低分配按鍵」的貪婪解法，
 *      否則計算結果可能不正確。
 */

class Solution {
public:
    int minimumPushes(string word) {
        int n = word.size();
        if (n <= 8) return n;
        else if (n <= 16) return 8 + 2 * (n - 8);
        else if (n <= 24) return 8 + 16 + 3 * (n - 16);
        return 8 + 16 + 24 + 4 * (n - 24); // 支援到 26
    }
};
```

## 解法：greedy-sorting-decision

**難度:** 🟡 Medium　**標籤:** Greedy Sorting Decision, Sorting, Counting　**時間:** O(N+26log26)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：3014. Minimum Number of Pushes to Type Word I (輸入字串所需的最少按鍵次數 I)
 * 難度：中等 (Medium)
 * 描述：使用類似手機九宮格鍵盤，每個按鍵可以對應多個字母（最多 8 個字母共用同一個按鍵，
 *       按第 k 次循環切換到該按鍵上的第 k 個字母）。給定字串 word，
 *       可以自由把 26 個字母分配到有限的按鍵上，求輸入整個 word 所需的最少總按鍵次數。
 *
 * 時間複雜度：O(N+26log26)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 貪婪分配策略 (Greedy Assignment)：
 *    - 出現頻率越高的字母，應該被分配到「按鍵次數越少」的位置（例如每個按鍵的第 1 個字母只需按 1 次）。
 * 2. 統計字母出現頻率並降冪排序：
 *    - 先統計 word 中每個字母出現的次數，再將次數由大到小排序，
 *      確保出現次數最多的字母，優先取得成本最低的按鍵位置。
 * 3. 依序分配按鍵成本：
 *    - 每個按鍵最多容納 8 個字母（一輪最多 8 個按鍵可用），
 *      排序後第 i 個字母（0-indexed）所需的按鍵次數為 (i / 8 + 1)。
 * 4. 累加總成本：
 *    - 將每個字母的出現次數乘上其對應的按鍵次數並加總，即為最終答案。
 */
class Solution {
public:
    int minimumPushes(string word) {
        int ans = 0;
        vector<int> count(26);

        for (const char c : word)
        ++count[c - 'a'];

        ranges::sort(count, greater<>());

        for (int i = 0; i < 26; ++i)
        ans += count[i] * (i / 8 + 1);

        return ans;
    }
};
```
