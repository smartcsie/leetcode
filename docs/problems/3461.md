# 3461. Check If Digits Are Equal in String After Operations I

[在 LeetCode 上查看](https://leetcode.com/problems/check-if-digits-are-equal-in-string-after-operations-i/)

**難度:** 🟢 Easy　**標籤:** Math Digit Decomposition, Simulation, Digit Manipulation　**時間:** O(N²)　**空間:** O(N)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：3461. Check If Digits Are Equal in String After Operations I (字串進行運算後檢查數字是否相等)
 * 難度：簡單 (Easy)
 * 描述：給定字串 s（只含數字字元），重複執行以下操作直到只剩兩個數字：
 *       對每對相鄰數字取和後對 10 取餘數，形成一個新的、長度少 1 的數字序列。
 *       最終判斷剩下的兩個數字是否相等。
 *
 * 時間複雜度：O(N²)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * 1. 先把字元轉成數值 (Char to Digit Conversion)：
 *    - 逐一走訪字串 s，透過 c - '0' 把每個字元轉成對應的整數數值，存入 digits 陣列。
 * 2. 模擬帕斯卡三角形式的縮減 (Pascal's Triangle Style Reduction)：
 *    - 每一輪都對相鄰兩個數字計算 (digits[i] + digits[i+1]) % 10，並寫回 digits[i]，
 *      整體概念類似帕斯卡三角形，每往下一列，有效長度就少 1。
 * 3. 原地更新，由左到右處理：
 *    - 由於計算 digits[i] 時只用到尚未被覆寫的 digits[i+1]，由左到右依序更新是安全的。
 *    - 內層迴圈邊界固定使用 digits.size()-1（而非隨 digitSize 遞減），
 *      雖然會對已經不再使用的尾端位置做多餘運算，但不影響 digits[0]、digits[1] 的正確性。
 * 4. 重複縮減直到剩下兩個數字：
 *    - 外層 while 迴圈持續進行，直到 digitSize 縮減到 2 為止。
 * 5. 最終比較：
 *    - 比較最後剩下的 digits[0] 與 digits[1] 是否相同，即為答案。
 */
class Solution {
public:
    bool hasSameDigits(string s) {
        int n = s.size();
        vector<int> digits;
        digits.reserve(n);
        for(const char& c : s) digits.push_back(c - '0');
        int digitSize = digits.size();
        while(digitSize > 2) {
            for(int i = 0; i < digits.size() - 1; i++) {
                digits[i] = (digits[i] + digits[i + 1]) % 10;
            }
            digitSize--;
        }
        return digits[0] == digits[1];
    }
};
```
