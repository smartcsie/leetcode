```cpp
/**
 * 題目：1927. Sum Game
 * 難度：中等 (Medium)
 * 描述：Alice 和 Bob 輪流將字串中的 '?' 替換成 0-9 的數字。
 * 若最後左半邊總和等於右半邊總和，則 Alice 贏；否則 Bob 贏。
 * 判斷 Alice 是否必勝。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * (期望值法)：
 * 1. 將 '?' 視為其平均期望值 4.5。
 * 2. 分別計算左右兩半邊的總和（包含數字與期望值）。
 * 3. 根據博弈特性，若兩邊期望總和不相等，Alice 必勝（因為 Bob 無法打破這個差距）。
 */

class Solution {
public:
    bool sumGame(string num) {
        double left = 0.0, right = 0.0;
        for(int l = 0, r = num.size() - 1; l < r; l++, r-- ) {
            left += (num[l] == '?') ? 4.5 : num[l] - '0';
            right += (num[r] == '?') ? 4.5 : num[r] - '0';
        }
        return left != right;
    }
};
```
