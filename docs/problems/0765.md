# 765. Couples Holding Hands

[在 LeetCode 上查看](https://leetcode.com/problems/couples-holding-hands/)

**難度:** 🔴 Hard　**標籤:** Sorting Cycle Decomposition　**時間:** O(N α(N))　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：765. Couples Holding Hands
 * 難度：困難 (Hard)
 * 分類主題：sorting-cycle-decomposition
 * 描述：n 對情侶坐成一排 2n 張椅子，row[i] 是坐在第 i 張椅子上的人
 * （情侶 k 兩人的編號是 2k 和 2k+1）。每次可以交換任兩人的座位，求
 * 讓每對情侶都相鄰而坐所需的最少交換次數。
 *
 * 時間複雜度：O(N α(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Cycle Decomposition，跟 3551 是同一個技巧家族，只是這題要先把
 * 「情侶關係」轉換成圖，才能看出環的結構）：
 * 1. 把每對「相鄰的座位」(0,1)、(2,3)、(4,5)... 看作一組，這組座位上
 *    坐的兩個人各自屬於某一對情侶（person / 2 就是情侶編號）。
 * 2. 用並查集，把這兩個「情侶編號」連起來（union）——這代表「這兩對
 *    情侶目前糾纏在同一組座位安排裡」，如果最終每對情侶都各自相鄰
 *    坐好，圖上每個情侶編號應該各自獨立（沒有任何連通關係）。
 * 3. 掃完所有座位配對之後，統計連通分量（環）的數量：如果一個連通
 *    分量裡有 k 對情侶糾纏在一起，需要 k-1 次交換才能把這 k 對都
 *    各自安置到正確的相鄰位置（這是環分解的核心公式：每個環需要
 *    環長-1 次交換）。
 * 4. 答案是 `n - 連通分量數`（n 是情侶總對數），等價於
 *    `Σ(每個連通分量的大小 - 1)`，因為每個分量各自貢獻「大小-1」次
 *    交換，加總起來剛好等於「總情侶數 - 分量數」。
 */
class Solution {
    vector<int> parent;
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    void unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }
public:
    int minSwapsCouples(vector<int>& row) {
        int n = row.size() / 2;
        parent.resize(n);
        iota(parent.begin(), parent.end(), 0);

        for (int i = 0; i < (int)row.size(); i += 2) {
            unite(row[i] / 2, row[i + 1] / 2);
        }

        unordered_set<int> roots;
        for (int i = 0; i < n; ++i) roots.insert(find(i));
        return n - (int)roots.size();
    }
};
```
