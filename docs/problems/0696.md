# 696. Count Binary Substrings

[在 LeetCode 上查看](https://leetcode.com/problems/count-binary-substrings/)

**難度:** 🟢 Easy　**標籤:** String, Greedy　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：696. Count Binary Substrings
 * 難度：簡單 (Easy)
 * 描述：計算所有出現 0 和 1 次數相等且連續的子字串。
 * 優化重點：
 * 1. 空間 O(1)：直接在遍歷時累計並計算，無需額外陣列空間。
 * 2. 邏輯簡潔：利用相鄰分組的長度限制，將問題轉化為 min(prev, curr) 的累加。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 */

class Solution {
public:
    int countBinarySubstrings(string s) {
        int ans = 0;
        int preEquals = 0;
        int curEquals = 1;
        for(int i = 1 ; i < s.size(); i++) {
            if(s[i] == s[i - 1]) {
                curEquals++;
            } else {
                ans += min(preEquals, curEquals);
                preEquals = curEquals;
                curEquals = 1;
            }
        }
        return ans + min(preEquals, curEquals);
    }
};
```

> [Count Binary Substrings](https://leetcode.com/problems/count-binary-substrings/)<br>
> 如果前後字元相等，用curEquals計數目前連續個0或1的個數，**if(s[i] == s[i - 1]) curEquals++;** <br>
> 如果前後字元不相等，找出比較短那一半的長度， **min(preEquals, curEquals)** ，0001111 =3 ，111100 = 2<br>
> ans計算總共字串，**ans += min(preEquals, curEquals);**， 因為如果 0011 = 2，字串有 01和0011剛好2種<br>
> **preEquals = curEquals;curEquals = 1;** <br>
