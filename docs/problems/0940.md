# 940. Distinct Subsequences II

[在 LeetCode 上查看](https://leetcode.com/problems/distinct-subsequences-ii/)

**難度:** 🔴 Hard　**標籤:** Dp Subsequences　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：940. Distinct Subsequences II
 * 難度：困難 (Hard)
 * 描述：給定一個字串 s，求它有幾個「不同的」非空子序列（結果對
 * 10^9+7 取模）。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （DP on Subsequences，dp 代表「目前為止所有子序列的總數（含空
 * 子序列）」，關鍵技巧是用 last[c] 扣掉重複計算的部分）：
 * 1. dp 初始化為 1（代表空子序列本身算一種）。
 * 2. 直覺上，每加入一個新字元 c，能讓「目前所有子序列」都各自多一種
 *    「在後面接上 c」的新子序列，所以子序列數量會變成 2 * dp（原本的
 *    子序列 + 每個子序列都接上 c 之後的新子序列）。
 * 3. 但這樣會重複計算：如果 c 這個字元之前出現過，那麼「加上這次的
 *    c」跟「加上上次的 c」在某些情況下會產生完全相同的子序列（因為
 *    子序列只看內容，不看是用哪個位置的字元組成）。要扣掉這個重複量，
 *    重複的量剛好等於「上一次看到字元 c 時，dp 的值」（last[c]），
 *    因為那些子序列在那個時間點就已經被算進去一次了。
 * 4. 狀態轉移：newDp = 2*dp - last[c]，然後更新 last[c] = dp（這次
 *    處理前的 dp 值，留給未來再遇到同樣字元時扣除用）。
 * 5. 最後答案是 dp - 1（扣掉一開始那個空子序列，因為題目要求非空）。
 */
class Solution {
public:
    int distinctSubseqII(string s) {
        const int MOD = 1e9 + 7;
        vector<long long> last(26, 0);
        long long dp = 1;
        for (char c : s) {
            long long newDp = (2 * dp % MOD - last[c - 'a'] + MOD) % MOD;
            last[c - 'a'] = dp;
            dp = newDp;
        }
        return (int)((dp - 1 + MOD) % MOD);
    }
};
```
