# 365. Water and Jug Problem

[在 LeetCode 上查看](https://leetcode.com/problems/water-and-jug-problem/)

**難度:** 🟡 Medium　**標籤:** Math, GCD, Bézout's Identity　**時間:** O(log(min(x,y)))　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：365. Water and Jug Problem (水壺問題)
 * 難度：中等 (Medium)
 * 描述：給定兩個容量分別為 x 公升與 y 公升的水壺，以及目標容量 target，
 *       透過裝滿、清空、互相倒水這三種操作，判斷是否能量出恰好 target 公升的水。
 *
 * 時間複雜度：O(log(min(x,y))) - 主要成本來自計算 gcd(x, y)，採用歐幾里得演算法。
 * 空間複雜度：O(1) - 只使用常數個變數，不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 貝祖定理的應用 (Bézout's Identity)：
 *    - 根據數論性質，能夠透過整數次的加減操作湊出 target 的充要條件是：
 *      target 必須是 gcd(x, y) 的整數倍（存在整數 a, b 使得 ax + by = target）。
 * 2. 容量上限限制 (Capacity Upper Bound)：
 *    - 兩個水壺能同時裝的水量總和最多是 x + y，因此 target 不可能超過這個總容量，
 *      否則就算數學上湊得出來，實際物理上也裝不下。
 * 3. target 為 0 的特殊情況：
 *    - 不需要任何操作，兩個水壺一開始都是空的，天然滿足 target = 0，
 *      利用 || 的短路特性提前回傳 true，同時避免了 x = y = 0 時計算 gcd(0, 0) 可能導致除以 0 的風險。
 * 4. 結合兩個條件得出最終答案：
 *    - 只有當 target 同時滿足「不超過總容量」與「是 gcd(x, y) 的倍數」時，才回傳 true。
 */
class Solution {
public:
    bool canMeasureWater(int x, int y, int target) {

        return target == 0 ||((x + y) >= target && target % gcd(x , y) == 0);
    }
};
```

> 祖定理的應用 (Bézout's Identity)
