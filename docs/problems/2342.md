# 2342. Max Sum of a Pair With Equal Sum of Digits

[在 LeetCode 上查看](https://leetcode.com/problems/max-sum-of-a-pair-with-equal-sum-of-digits/)

**難度:** 🟡 Medium　**標籤:** Hash Table Existence, Hash Table　**時間:** O(N*logM)　**空間:** O(N)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2342. Max Sum of a Pair With Equal Sum of Digits
 * 難度：中等 (Medium)
 * 描述：找到數位和相等的兩個數字，並使它們的和最大化。
 * 優化重點：
 * 1. 一次遍歷：在遍歷過程中即時更新最大和與分組最大值，無需二次排序。
 * 2. 映射表：利用 Hash Map 以 O(1) 平均時間查找該數位和之前的最大值。
 *
 * 時間複雜度：O(N*logM)
 * 空間複雜度：O(N)
 */

class Solution {
public:
    int maximumSum(vector<int>& nums) {
        vector<vector<int>> counts(82, vector<int>(3, -1));
        for(const int& x : nums) {
            int d = 0;
            int y = x;
            while(y > 0) {
                d += y % 10;
                y /= 10;
            }
            if(x > counts[d][1]) {
                counts[d][0] = counts[d][1];
                counts[d][1] = x;
            } else if(x > counts[d][0]) {
                counts[d][0] = x;
            } 
            if(counts[d][0] != -1 && counts[d][1] != -1) 
                counts[d][2] = max(counts[d][2], counts[d][0] + counts[d][1]);
        }
        int ans = -1;
        for(int i = 0 ; i < 82; i++) {
            if(counts[i][2] != -1) {
                ans = max(ans, counts[i][2]);
            }
        }
        return ans;
    }
};
```

> 建一個 vector<vector<int>> counts(82, vector<int>(3, -1)); 紀錄<br>
> counts[d]為digit sum = d，[0]為第二大的數，[1]為最大的數，[2]為maximum<br>
