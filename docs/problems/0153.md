# 153. Find Minimum in Rotated Sorted Array

[在 LeetCode 上查看](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)

**難度:** 🟡 Medium　**標籤:** Binary&nbsp;Search　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：待補充
 * 難度：待補充
 * 描述：待補充
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 */

class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0, right = nums.size() - 1;
        while (left < right) {
            int mid = left + ((right - left) / 2);
            
            if (nums[mid] > nums[right]) {
                // mid 在左半邊較大的區塊，最小值一定在 mid 右邊
                left = mid + 1;
            } else {
                // mid 在右半邊較小的區塊，最小值可能是 mid 或在 mid 左邊
                right = mid;
            }
        }
        return nums[left];
    }
};
```
