# 153. Find Minimum in Rotated Sorted Array

[在 LeetCode 上查看](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)

**難度:** 🟡 Medium　**標籤:** Binary Search, Binary&nbsp;Search　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：待補充
 * 難度：待補充
 * 描述：待補充
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 */

class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0, right = nums.size() - 1;
        while(left < right) {
            int mid = left + (right - left) / 2;
            if(nums[mid] > nums[right]) left = mid + 1;
            else right = mid;
        }
        return nums[left];
    }
};
```

> **例子1 : 2 3 4 5 1，中間比尾巴大，往右邊找**<br>
> **例子2 : 5 1 2 3 4，中間小於等於尾巴，往左邊找***<br>
