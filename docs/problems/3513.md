# 3513. Number of Unique XOR Triplets I

[在 LeetCode 上查看](https://leetcode.com/problems/number-of-unique-xor-triplets-i/)

## 解法：bit-manipulation

**難度:** 🟡 Medium　**標籤:** Bit Manipulation, Bit Manipulation, Brainteaser　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：3513. Number of Unique XOR Triplets I
 * 難度：待補充
 * 描述：給你一個長度為 n 的整數陣列 nums（為 1 到 n 的排列），
 * 求所有滿足 i <= j <= k 的三元組 (i, j, k)，其 nums[i] ^ nums[j] ^ nums[k]
 * 所能產生的「不同 XOR 數值」總共有多少種。
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 若陣列長度 n 小於 3，透過數學規律或直接枚舉可知其產生的獨特 XOR 結果數量剛好為 n。
 * 2. 當 n >= 3 時，透過排列 XOR 的線性空間性質，其可生成的數值範圍取決於 n 的最高有效位元。
 * 3. 我們透過一個 while 迴圈計算 n 的位元長度：
 * - 每次將 temp 右移（temp >>= 1），同時將答案左移（ans <<= 1）。
 * - 這相當於找出大於或等於 n 的最小二進位區間邊界（即 2^(bit_length)）。
 * 4. 返回計算出來的 ans 即為所有可能的獨特 XOR 結果總數。
 */

class Solution {
public:
    int uniqueXorTriplets(std::vector<int>& nums) {
        auto n = nums.size();
        if(n < 3) return n;
        return 1 << bit_width(n);
    }
};
```

class Solution {
public:
    int uniqueXorTriplets(vector<int>& nums) {
        int n = nums.size();
        if(n < 3) return n;
        return 1 << (static_cast<int>(log2(n)) + 1);
    }
};

## 解法：bit-manipulation

**難度:** 🟡 Medium　**標籤:** Bit Manipulation　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
class Solution {
public:
    int uniqueXorTriplets(vector<int>& nums) {
        int n = nums.size();
        if(n < 3) return n;
        int ans = 1;
        while(n > 0) {
            ans <<= 1;
            n >>= 1;
        }
        return ans;
    }
};
```
