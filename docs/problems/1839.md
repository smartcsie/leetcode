# 1839. Longest Substring Of All Vowels in Order

[在 LeetCode 上查看](https://leetcode.com/problems/longest-substring-of-all-vowels-in-order/)

**難度:** 🟡 Medium　**標籤:** Variable Size Sliding Window, Sliding Window, Two Pointers　**時間:** O(N)　**空間:** O(1)

```cpp
/**
 * 題目：1839. Longest Substring Of All Vowels in Order (按字典序排列的最長合法母音字串)
 * 難度：中等 (Medium)
 * 描述：給定字串 word（只含母音 a, e, i, o, u），一個「美麗子字串」需滿足：
 *       每個母音至少出現一次，且必須按照 a, e, i, o, u 的順序排列（不可倒退）。
 *       請回傳最長的美麗子字串長度，若不存在則回傳 0。
 *
 * 時間複雜度：O(N) - 只需對 word 進行一次線性掃描，每個字元只處理常數次。
 * 空間複雜度：O(1) - 只使用常數個變數（left, ans, count），不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 滑動視窗與計數 (Sliding Window + Counter)：
 *    - 用 count 追蹤目前視窗內「不同母音種類」的累積數量，left 記錄目前合法視窗的起點。
 * 2. 判斷字元順序是否合法：
 *    - 若目前字元 cur 大於等於前一個字元 prev（符合非遞減的母音順序），視窗可以繼續延伸；
 *      若嚴格大於（切換到下一個母音），count 才會增加。
 * 3. 五個母音都出現時更新答案：
 *    - 當 count 累積到 5（代表 a, e, i, o, u 都已經在目前視窗內依序出現），
 *      用目前視窗長度 (right - left + 1) 更新最大答案 ans。
 * 4. 順序被打破時重置視窗：
 *    - 若目前字元小於前一個字元（順序被打破，例如又跳回 'a'），
 *      將 count 重置為 1，並把 left 移到目前位置，開始計算新的視窗。
 */
class Solution {
public:
    int longestBeautifulSubstring(string word) {
        int left = 0;
        int ans = 0;
        int count = 1;
        for(int right = 1 ; right < word.size(); right++) {
            const char cur = word[right];
            const char prev = word[right - 1];
            if(cur >= prev) {
                if(cur > prev) count++;
                if(count == 5) {
                    ans = max(ans, right - left + 1);
                }
            } else {
                count = 1;
                left = right;
            }
        }
        return ans;
    }
};
```
