# 137. Single Number II

[在 LeetCode 上查看](https://leetcode.com/problems/single-number-ii)

## 解法：bit-manipulation

**難度:** 🟡 Medium　**標籤:** Bit Manipulation, Bit-Manipulation　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習　🏆 **最佳解**

```cpp
/**
 * 題目：待補充
 * 難度：待補充
 * 描述：待補充
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 有限狀態機 (Finite State Machine)
 * 1. 使用 one 和 two 兩個變數來記錄位元出現的次數（模 3 餘數）。
 * 2. 每個位元的狀態轉移如下：
 * - 出現 1 次：one = 1, two = 0
 * - 出現 2 次：one = 0, two = 1
 * - 出現 3 次：one = 0, two = 0 (重置)
 * 3. `~two` 的作用是：如果該位元已經在 `two` 裡了（出現兩次），
 * 則當前的 `one` 運算會被強制歸零。
 */

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int one=0, two=0;
        for(int n : nums) {
            one = (one^n) & ~two;
            two = (two^n) & ~one;
        }
        return one;
    }
};
```

> **int one = 0, two = 0;** <br>
> **for(const int& num : nums) {** <br>
> &emsp;&emsp;&emsp;&emsp;**one = one^num & ~two;** <br>
> &emsp;&emsp;&emsp;&emsp;**two = two^num & ~one;** <br>
> **}** <br>
> return one;** <br>
> 此題有三種解法，位元有限狀態機是最佳解<br>

## 解法：math

**難度:** 🟡 Medium　**標籤:** Math, Hash Set　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：137. Single Number II (只出現一次的數字 II)
 * 難度：中等 (Medium)
 * 描述：除了某個元素只出現一次以外，其餘每個元素都恰出現三次。找出那個元素。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * (數學公式法)：
 * 1. 設出現一次的數字為 x，重複三次的數字集為 S。
 * 2. 原始陣列總和 sum_all = x + 3 * sum(S)。
 * 3. Hash Set 中存儲的是所有不重複的數字，其總和 sum_unique = x + sum(S)。
 * 4. 推導公式：
 * 3 * sum_unique = 3 * x + 3 * sum(S)
 * 3 * sum_unique - sum_all = (3 * x + 3 * sum(S)) - (x + 3 * sum(S))
 * 3 * sum_unique - sum_all = 2 * x
 * x = (3 * sum_unique - sum_all) / 2
 * 注意：由於運算過程中涉及乘法與加總，數字極大時可能導致 int 溢位，
 * 因此必須使用 long long 型別。
 */

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        long sum_all = 0;
        unordered_set<int> unique_set;
        
        for(const int& num : nums) {
            sum_all += num;
            unique_set.insert(num);
        }

        long sum_unique = 0; 
        for(const int& num : unique_set) {
            sum_unique += num;
        }

        return static_cast<int>((3 * sum_unique - sum_all) / 2);
    }
};
```

> 先travsal nums，num加到sum_all，num順便insert到unique_set(unordered_set<int>)<br>
> (3 * sum_unique - sum_all) / 2<br>
> 此題有三種解法，位元有限狀態機是最佳解<br>
