# 3151. Special Array I

[在 LeetCode 上查看](https://leetcode.com/problems/special-array-i)

**難度:** 🟢 Easy　**標籤:** Array, Bit Manipulation　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：3151. Special Array I (特殊陣列 I)
 * 難度：簡單 (Easy)
 * 描述：如果陣列中每一對相鄰元素的奇偶性皆不同，則稱為特殊陣列。
 *
 * 時間複雜度：O(N) - 遍歷陣列一次。
 * 空間複雜度：O(1) - 僅使用常數空間。
 */

class Solution {
public:
    bool isArraySpecial(vector<int>& nums) {
        int n = nums.size();
        if (n <= 1) return true;
        for (int i = 0; i < n - 1; i++) {
            if (((nums[i] ^ nums[i + 1]) & 1) == 0) {
                return false;
            }
        }
        return true;
    }
};
```
