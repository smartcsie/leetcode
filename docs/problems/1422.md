# 1422. Maximum Score After Splitting a String

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-score-after-splitting-a-string/)

**難度:** 簡單 (Easy)　**標籤:** 　**時間:** O(n) - 先使用 std::count 花費 O(n) 計算總 1 數量，接著用單一迴圈花費 O(n) 掃描分割點。　**空間:** O(1) - 僅使用常數個變數（zeros, ones, ans）來追蹤狀態，不需額外配置動態記憶體。

```cpp
/**
 * 題目：1422. Maximum Score After Splitting a String (分割字串的最大得分)
 * 難度：簡單 (Easy)
 * 描述：給你一個由字元 '0' 和 '1' 組成的字串 s。返回將字串分割成兩個非空子字串（左子字串與右子字串）後的最大得分。
 *       分割字串的得分為「左子字串中 0 的數量」加上「右子字串中 1 的數量」。
 * 
 * 時間複雜度：O(n) - 先使用 std::count 花費 O(n) 計算總 1 數量，接著用單一迴圈花費 O(n) 掃描分割點。
 * 空間複雜度：O(1) - 僅使用常數個變數（zeros, ones, ans）來追蹤狀態，不需額外配置動態記憶體。
 * 
 * 解法思路：
 * 1. 預先統計總數：
 *    - 先用 `std::count` 算出整個字串中 `1` 的總個數，並將其全部視為初始的右側 `1`（`ones`）。
 *    - 變數 `zeros` 用來記錄隨著分割點向右移動，左側累積出現的 `0` 的個數。
 * 2. 單次遍歷與狀態更新：
 *    - 從左到右依序掃描到 `s.size() - 1`（確保右子字串至少留有一個字元，滿足非空條件）。
 *    - 當遇到 `1`：代表原本屬於右邊的 `1` 少了一個，因此 `--ones`。
 *    - 當遇到 `0`：代表左邊的 `0` 多了一個，因此 `zeros++`。
 * 3. 計算總得分：
 *    - 每次移動分割點後，當前的總得分為 `ones + zeros`，並透過 `std::max` 更新最大得分 `ans`。
 */

class Solution {
public:
    int maxScore(std::string s) {
        int n = s.size();
        int zeros = 0;
        // 預先計算字串中所有 '1' 的總數（初始時全部在右側）
        int ones = std::count(s.begin(), s.end(), '1');
        int ans = 0;
        // 遍歷所有可能的分割點（i + 1 < n 確保右子字串非空）
        for (int i = 0; i + 1 < s.size(); ++i) {
            if (s[i] == '1') {
                ones--;   // 移到左邊後，右側的 1 總數減 1
            } else {
                zeros++;  // 移到左邊後，左側的 0 總數加 1
            }
            // 更新最大得分
            ans = std::max(ans, ones + zeros);
        }
        return ans;
    }
};
```
