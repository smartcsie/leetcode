# 810. Chalkboard XOR Game

[在 LeetCode 上查看](https://leetcode.com/problems/chalkboard-xor-game/)

**難度:** 🔴 Hard　**標籤:** Math Game Theory, Game Theory　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習　🏆 **最佳解**

```cpp
/**
 * 題目：810. Chalkboard XOR Game (黑板異或遊戲)
 * 難度：困難 (Hard)
 * 描述：黑板上寫著一組整數，兩人輪流擦掉一個數字（Alice 先手）。若擦掉某數字後，
 *       剩餘所有數字的 XOR 變成 0，該玩家就輸了；若輪到某玩家時，剩餘數字的 XOR
 *       本來就是 0，該玩家直接獲勝。假設雙方都採取最佳策略，判斷 Alice 是否能獲勝。
 *
 * 時間複雜度：O(N) - 只需計算一次整體 XOR。
 * 空間複雜度：O(1) - 只使用常數個變數。
 *
 * 解法思路：
 * 1. 情況一：一開始整體 XOR 就是 0 (Immediate Win)：
 *    - 根據規則，只要輪到某玩家時整體 XOR 為 0，該玩家立即獲勝，
 *      Alice 先手，所以只要一開始 XOR 為 0，Alice 直接贏。
 * 2. 情況二：數字個數為偶數時，Alice 必勝 (Parity Argument)：
 *    - 若整體 XOR 不為 0，可以證明：只要數字總數是偶數，Alice 永遠有辦法選擇
 *      不讓自己觸發「XOR 變 0」的擦除方式，並且透過對稱策略，
 *      始終能把「無法避免讓 XOR 歸零」的困境留給 Bob。
 * 3. 反之，數字個數為奇數且整體 XOR 不為 0，則 Alice 必敗：
 *    - 在此情況下，不管 Alice 怎麼選，最終都無法避免讓自己或後續局面
 *      落入必須把 XOR 歸零的窘境，因此回傳 false。
 * 4. 結論化簡成一行判斷式：
 *    - 回傳「整體 XOR 為 0」或「數字個數為偶數」兩者之一成立即可。
 */
class Solution {
public:
    bool xorGame(vector<int>& nums) {
        int count = 0;
        for(const int& num : nums) {
            count ^= num;
        }
        return (count == 0) || (nums.size() % 2 ==0);
    }
};
```
