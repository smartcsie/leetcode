# 3550. Smallest Index With Digit Sum Equal to Index

[在 LeetCode 上查看](https://leetcode.com/problems/smallest-index-with-digit-sum-equal-to-index/)

**難度:** 🟢 Easy　**標籤:** Math Digit Decomposition, Digit Manipulation　**時間:** O(N * D)　**空間:** O(1)　**熟悉度:** 🟢 熟練　🏆 **最佳解**

```cpp
/**
 * 題目：3550. Smallest Index With Digit Sum Equal to Index (數字位數和等於索引的最小索引)
 * 難度：簡單 (Easy)
 * 描述：給定整數陣列 nums，找出最小的索引 i，使得 nums[i] 的各位數字之和恰好等於 i；
 *       若不存在這樣的索引，回傳 -1。
 *
 * 時間複雜度：O(N * D) - N 為陣列長度，D 為數字位數（視為常數，通常不超過 10）。
 * 空間複雜度：O(1) - 只使用常數個變數。
 *
 * 解法思路：
 * 1. 由左到右依序檢查每個索引 (Left-to-Right Linear Scan)：
 *    - 因為要找「最小」符合條件的索引，只需要由左到右掃描一次，
 *      一旦找到第一個符合條件的索引就能立即回傳，不需要繼續檢查後面的元素。
 * 2. 計算目前元素的各位數字和 (Compute Digit Sum)：
 *    - 透過反覆取餘數（% 10）取得最低位數字、整除（/ 10）去掉最低位，
 *      逐步累加所有位數，直到數字變成 0 為止。
 * 3. 邊界情況：nums[i] 恰好為 0 時 (Zero Value Edge Case)：
 *    - 若 nums[i] 是 0，while 迴圈的條件 (temp > 0) 一開始就不成立，
 *      迴圈完全不會執行，digit_sum 保持初始值 0，正確對應「0 的位數和是 0」。
 * 4. 找到符合條件就立即回傳，否則回傳 -1：
 *    - 若目前索引的位數和恰好等於索引本身，直接回傳該索引；
 *      若整個陣列掃描完都沒有符合的索引，回傳 -1。
 */
class Solution {
public:
    int smallestIndex(vector<int>& nums) {
        for(int i = 0; i < nums.size(); i++) {
            int digit_sum = 0;
            int temp = nums[i];
            while(temp > 0) {
                digit_sum += temp % 10;
                temp /= 10;
            }
            if(digit_sum == i) return i;
        }
        return -1;
    }
};
```
