# 349. Intersection of Two Arrays

[在 LeetCode 上查看](https://leetcode.com/problems/intersection-of-two-arrays/)

**難度:** 🟢 Easy　**標籤:** Hash Table　**時間:** O(N+M)　**空間:** O(N)

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        bool appear[1001];
        vector<int> res;
        memset(appear, false, sizeof(appear));
        for(int num : nums1) {
            appear[num] = true;
        }
        for(int num : nums2) {
            if(appear[num]) {
                res.push_back(num);
                appear[num] = false;
            }
        }
        return res;

    }
};
```
