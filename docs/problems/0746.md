# 746. Min Cost Climbing Stairs

```cpp
/**
 * 題目：746. Min Cost Climbing Stairs
 * 難度：簡單 (Easy)
 * 描述：給定一個陣列 cost，cost[i] 是從第 i 階往上爬所需付出的費用。
 * 每次可以爬 1 階或 2 階，可以從索引 0 或索引 1 開始爬，求到達樓梯頂端
 * （陣列長度之外的那一階）所需的最小總費用。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （動態規劃，dp[i] 代表「到達第 i 階」所需的最小費用）：
 * 1. 定義 dp[i] 為走到第 i 階（尚未離開，準備從這階往上跳）所需的最小費用。
 * 2. 起點可以是索引 0 或索引 1，兩者都不用先付費就能站上去，所以
 *    dp[0] = 0、dp[1] = 0。
 * 3. 狀態轉移：要走到第 i 階，只能從第 i-1 階跨 1 步、或第 i-2 階跨 2 步
 *    上來，跨出去之前要先付「出發那一階」的費用，所以
 *    dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])。
 * 4. 樓梯頂端是索引 n（陣列外面那一格，不用再付費），答案就是 dp[n]。
 */
class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n = cost.size();
        if (n <= 1) return 0;
        vector<int> dp(n + 1);
        dp[0] = 0, dp[1] = 0;
        for (int i = 2; i <= n; i++) {
            dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
        }
        return dp[n];
    }
};
```

## 解法：dp-fibonacci

**難度:** 🟢 Easy　**標籤:** Dp Fibonacci　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練　🏆 **最佳解**

**📅 練習歷程:**

```cpp
/**
 * 題目：746. Min Cost Climbing Stairs
 * 難度：Easy
 * 描述：cost[i] 是踩上第 i 階要付的費用。付費後可以往上爬 1 階或 2 階，
 *       起點可以選第 0 階或第 1 階，目標是爬過最後一階（到達頂端）。
 *       回傳到達頂端的最小總費用。
 *
 * 分類主題：dp-linear
 * 技巧：一維 DP, 滾動變數只保留前兩階, 答案取最後兩階的較小值
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：線性 DP + 滾動變數
 * 1. 狀態：dp[i] = 「踩到第 i 階（含這階費用）」的最小總費用。
 * 2. 初始：可以從第 0 或第 1 階起跳，所以 dp[0] = cost[0]、dp[1] = cost[1]。
 * 3. 轉移：第 i 階只能從 i - 1 或 i - 2 階上來，
 *    dp[i] = cost[i] + min(dp[i - 1], dp[i - 2])。
 * 4. 頂端在最後一階之外，最後一步可以從倒數第一階或倒數第二階跨上去，
 *    所以答案是 min(dp[n - 1], dp[n - 2])。
 * 5. dp[i] 只依賴前兩項，用 n0、n1 兩個變數滾動即可，不需要整個陣列：
 *    n0 = dp[i - 2]、n1 = dp[i - 1]，算出 n2 = dp[i] 後整體往前移一格。
 * 6. 迴圈結束時，n0 = dp[n - 2]、n1 = dp[n - 1]，
 *    n = 2 時迴圈不會執行，直接回傳 min(cost[0], cost[1])，結果正確。
 */
class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n0 = cost[0];  // dp[i - 2]：踩到前前一階的最小費用
        int n1 = cost[1];  // dp[i - 1]：踩到前一階的最小費用
        int n2;            // dp[i]：踩到目前這階的最小費用

        for(int i = 2; i < cost.size(); i++) {
            n2 = cost[i] + min(n0, n1);  // 從前一階或前前一階上來，取較便宜者
            n0 = n1;                     // 窗口往前滑一格
            n1 = n2;
        }

        // 最後一步可以從最後一階或倒數第二階跨到頂端
        return min(n0, n1);
    }
};
```
