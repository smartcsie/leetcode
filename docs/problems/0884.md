# 884. Uncommon Words from Two Sentences

[在 LeetCode 上查看](https://leetcode.com/problems/uncommon-words-from-two-sentences)

**難度:** 🟢 Easy　**標籤:** Hash Table Uniqueness　**時間:** O(N+M)　**空間:** O(N+M)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：884. Uncommon Words from Two Sentences (兩句話中的不常見單字)
 * 難度：簡單 (Easy)
 * 描述：回傳所有在其中一句只出現一次，且在另一句沒出現過的單字。
 *
 * 時間複雜度：O(N+M)，其中 N 和 M 分別是兩個句子的長度。
 * 空間複雜度：O(N+M)，用來儲存所有唯一的單字。
 *
 * 解法思路：
 * 將兩個字串合併視為一個字串流，統計單字出現的總次數，頻率為 1 即為不常見單字。
 */

class Solution {
public:
    vector<string> uncommonFromSentences(string s1, string s2) {
        unordered_map<string, int> counts;
        string s;
        istringstream iss1(s1);
        while(iss1 >> s) counts[s]++;
        istringstream iss2(s2);
        while(iss2 >> s) counts[s]++;
        vector<string> ans;
        for(const auto& [str , count] : counts) {
            if(count == 1) ans.push_back(str);
        }
        return ans;
    }
};
```
