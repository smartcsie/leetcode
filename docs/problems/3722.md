# 3722. Lexicographically Smallest String After Reverse

[在 LeetCode 上查看](https://leetcode.com/problems/lexicographically-smallest-string-after-reverse/)

**難度:** 🟡 Medium　**標籤:** String, Brute Force　**時間:** O(N²)　**空間:** O(N)　**熟悉度:** 🔴 生疏　🏆 **最佳解**

```cpp
/**
 * 題目：3722. Lexicographically Smallest String After Reverse (反轉後字典序最小的字串)
 * 難度：中等 (Medium)
 * 描述：給定長度為 n 的小寫英文字串 s，必須「恰好執行一次」操作：
 *       選擇任一整數 k（1 <= k <= n），可以選擇反轉「前 k 個字元」或反轉「後 k 個字元」。
 *       回傳執行完這唯一一次操作後，能得到的字典序最小字串。
 *
 * 時間複雜度：O(N²) - 對每個 k（O(N) 種選擇），都需要 O(N) 時間建構並比較字串，
 *             整體約為 O(N²)。
 * 空間複雜度：O(N) - 每次迭代都需要建構長度為 N 的暫存字串。
 *
 * 解法思路：
 * 1. 窮舉所有可能的 k 值 (Enumerate All Possible k)：
 *    - 因為 k 的範圍是 1 到 n，資料規模通常不大，可以直接窮舉每一種 k，
 *      分別嘗試「反轉前 k 個字元」與「反轉後 k 個字元」這兩種操作。
 * 2. 建構「反轉前 k 個字元」的候選字串 (Reverse First k Characters)：
 *    - 取出前 k 個字元反轉後，接上原本未變動的後半段，組成候選字串 t1。
 * 3. 建構「反轉後 k 個字元」的候選字串 (Reverse Last k Characters)：
 *    - 取出最後 k 個字元反轉後，接在原本未變動的前半段後面，組成候選字串 t2。
 * 4. 在所有候選字串中取字典序最小值：
 *    - 用 ans 持續追蹤目前看過的所有候選字串（含原字串本身、每個 k 產生的 t1 與 t2）中，
 *      字典序最小的那一個，走訪完所有 k 之後，ans 即為最終答案。
 */
class Solution {
public:
    string lexSmallest(string s) {
        string ans = s;
        int n = s.size();
        for (int k = 1; k <= n; ++k) {
            // 反轉前 k 個字元
            string t1 = s.substr(0, k);
            reverse(t1.begin(), t1.end());
            t1 += s.substr(k);

            // 反轉後 k 個字元
            string t2 = s.substr(0, n - k);
            string suffix = s.substr(n - k);
            reverse(suffix.begin(), suffix.end());
            t2 += suffix;

            ans = min({ans, t1, t2});
        }
        return ans;
    }
};
```
