# 2707. Extra Characters in a String

[在 LeetCode 上查看](https://leetcode.com/problems/extra-characters-in-a-string/)

**難度:** 🟡 Medium　**標籤:** Dynamic Programming, Hash Set　**時間:** O(N³)　**空間:** O(N+D)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：2707. Extra Characters in a String (字串中的額外字元)
 * 難度：中等 (Medium)
 * 描述：給定字串 s 與字典 dictionary，將 s 拆分成若干個子字串，每個子字串
 *       要嘛是 dictionary 中的單字，要嘛視為「多餘字元」。回傳最少的多餘字元數。
 *
 * 時間複雜度：O(N³)
 *             並丟進 unordered_set 做雜湊比對，額外花費約 O(N)，整體約 O(N³)。
 * 空間複雜度：O(N+D)
 *
 * 解法思路：
 * 1. 定義狀態：dp[i] 為前 i 個字元的最少多餘字元數 (DP State Definition)：
 *    - dp[i] 代表 s 的前 i 個字元（即 s[0..i-1]），拆分後所需要的最少多餘字元數量。
 *    - dp[0] = 0（空字串沒有任何多餘字元）。
 * 2. 雙層迴圈窮舉所有可能的切割點 (Enumerate All Split Points)：
 *    - 對每個結尾位置 i，嘗試所有可能的起點 j（0 <= j < i），
 *      檢查子字串 s[j..i-1] 是否恰好是字典中的一個單字。
 * 3. 若該子字串是字典單字：直接繼承 dp[j]（不增加多餘字元）：
 *    - 因為這段完整匹配到一個字典單字，不貢獻任何多餘字元，dp[i] 可以直接更新為 dp[j]。
 * 4. 若該子字串不是字典單字：視為整段都是多餘字元：
 *    - 更新 dp[i] = min(dp[i], dp[j] + (i - j))；當 j = i-1（單一字元）時，
 *      這個分支恰好等價於經典寫法的 dp[i-1] + 1，確保最終仍能取到正確的最小值。
 * 5. 最終答案：
 *    - dp[n] 即為整個字串 s 拆分後所需要的最少多餘字元總數。
 */
class Solution {
public:
    int minExtraChar(string s, vector<string>& dictionary) {
        unordered_set dicSet(dictionary.begin(), dictionary.end());
        const int n = s.size();
        vector<int> dp(n + 1, n);
        dp[0] = 0;
        for(int i = 1; i <= n; i++) {
            for(int j = 0; j < i; j++) {
                if(dicSet.count(s.substr(j, i - j))) {
                    dp[i] = min(dp[i], dp[j]);
                } else {
                    dp[i] = min(dp[i], dp[j] + i - j);
                }
            }
        }
        return dp[n];
    }
};
```
