# 3702. Longest Subsequence With Non-Zero Bitwise XOR

[在 LeetCode 上查看](https://leetcode.com/problems/longest-subsequence-with-non-zero-bitwise-xor/)

**難度:** 🟡 Medium　**標籤:** Bit Manipulation, Greedy　**時間:** O(N)　**空間:** O(1)

```cpp
/**
 * 題目：3702. Longest Subsequence With Non-Zero Bitwise XOR
 * 難度：待補充
 * 描述：給定一個整數陣列 nums，找出一個最長的子序列 (Subsequence)，
 * 使得該子序列所有元素的按位與 XOR 總和不為 0。回傳該子序列的最大長度。
 *
 * 時間複雜度：O(N) - 全部 XOR，三種情況數學分析。
 * 空間複雜度：O(1) - 僅使用常數空間。
 *
 * 解法思路：
 * 1. 檢查極端情況：如果整個陣列的所有元素全部都是 0，那麼無論選取哪個子序列，
 * XOR 總和永遠是 0，此時無解，回傳 0。
 * 2. 計算全體 XOR 總和 (mask)：
 * - 如果 mask != 0，代表整條陣列原本的 XOR 總和就不為 0，
 * 因此我們可以直接選取「全部元素」，長度即為 nums.size()。
 * - 如果 mask == 0，代表整條陣列的 XOR 總和為 0。這時我們只需要隨便拔掉一個元素（例如任何一個非 0 元素或陣列中其中一個數），
 * 就能破壞平衡，讓剩餘的 XOR 總和變成非 0。此時最大長度為 nums.size() - 1。
 */

class Solution {
public:
    int longestSubsequence(std::vector<int>& nums) {
        int n = nums.size();
        if(count(nums.begin(), nums.end(), 0) == n) return 0;
        int xorOp = accumulate(nums.begin(), nums.end(), 0, bit_xor<int>());
        return xorOp != 0 ? n : n - 1;
    }
};
```

> 三種case<br>
> case 1 : nums 全為 0，回傳 0<br>
> case 2 : nums 全部 xor 的結果不為 0，回傳 nums.size()<br>
> case 3 : nums 全部 xor 的結果為 0，拿掉一個元素即可，回傳 nums.size() - 1<br>
> case 2到case 3 是因為拿掉一個元素就不會為0了
