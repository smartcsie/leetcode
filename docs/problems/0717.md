# 717. 1-bit and 2-bit Characters

[在 LeetCode 上查看](https://leetcode.com/problems/1-bit-and-2-bit-characters/)

**難度:** 🟢 Easy　**標籤:** Array, Simulation　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 注意

```cpp
/**
 * 題目：717. 1-bit and 2-bit Characters (1-bit 與 2-bit 字元)
 * 難度：簡單 (Easy)
 * 描述：判斷最後一個字元是否為 1-bit 字元。
 *
 * 時間複雜度：O(N)，N 為陣列長度。
 * 空間複雜度：O(1)。
 *
 * 解法思路：
 * 1. 簡化指標移動邏輯。
 * 2. 移除不必要的變數以節省空間。
 */

#include <vector>

class Solution {
public:
    bool isOneBitCharacter(std::vector<int>& bits) {
        int n = bits.size();
        int i = 0;
        while (i < n - 1) {
            i += (bits[i] == 1) ? 2 : 1;
        }
        return i == n - 1;
    }
};
```
