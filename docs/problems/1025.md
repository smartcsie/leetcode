# 1025. Divisor Game

[在 LeetCode 上查看](https://leetcode.com/problems/divisor-game/)

**難度:** 🟢 Easy　**標籤:** Math, Game Theory　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🟠 再練習　🏆 **最佳解**

```cpp
/**
 * 題目：1025. Divisor Game (除數博弈)
 * 難度：簡單 (Easy)
 * 描述：Alice 和 Bob 輪流操作黑板上的整數 n（Alice 先手）：選擇任一滿足
 *       0 < x < n 且 n % x == 0 的整數 x，並把 n 替換成 n - x。無法移動的玩家輸掉遊戲。
 *       假設雙方都採取最佳策略，判斷 Alice 是否能獲勝。
 *
 * 時間複雜度：O(1) - 只需一次取餘數運算。
 * 空間複雜度：O(1) - 只使用常數空間。
 *
 * 解法思路：
 * 1. 關鍵觀察：n 為偶數時 Alice 必勝 (Even n is a Winning Position)：
 *    - 若 n 是偶數，Alice 永遠可以選擇 x = 1（1 一定整除任何 n），
 *      把 n 變成奇數，丟給 Bob 面對奇數局面。
 * 2. n 為奇數時的性質：奇數的因數必為奇數 (Odd n's Divisors are Odd)：
 *    - 若 n 是奇數，n 的所有因數 x 也都必定是奇數，
 *      因此 n - x（奇數減奇數）結果必定是偶數，代表奇數局面的玩家，
 *      不管怎麼選，都只能把偶數局面留給對手。
 * 3. 歸納出「偶勝奇敗」的規律：
 *    - 這形成一個穩定的循環：偶數局面的玩家，永遠能把奇數局面丟給對手；
 *      奇數局面的玩家，則永遠被迫把偶數局面留給對手。
 *    - 由於遊戲最終會在 n=1（無法移動，輪到的玩家輸）結束，
 *      透過歸納法可以證明：n 為偶數時，先手的玩家（在本題中即為 Alice）必勝。
 * 4. 結論化簡成一行判斷式：
 *    - 直接回傳 n % 2 == 0，即為「n 是偶數時 Alice 必勝」的結論。
 */
class Solution {
public:
    bool divisorGame(int n) {
        return (n % 2 == 0);
    }
};
```
