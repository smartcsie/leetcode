# 791. Custom Sort String

[在 LeetCode 上查看](https://leetcode.com/problems/custom-sort-string/)

**難度:** 🟡 Medium　**標籤:** String, Counting Sort　**時間:** O(N+M)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：791. Custom Sort String (自定義字串排序)
 * 難度：中等 (Medium)
 * 描述：給定兩個字串 order 和 s，order 中的字元皆為唯一，且代表了字元的優先順序。
 *       請將 s 重新排列，使其字元順序符合 order 所定義的相對優先順序，
 *       s 中未出現在 order 的字元，維持原本相對順序接在後面即可。
 *
 * 時間複雜度：O(N+M)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 計數排序 (Counting Sort)：
 *    - 先用 counts[26] 統計 s 中每個字元出現的次數。
 * 2. 依照 order 優先輸出：
 *    - 依序走訪 order 中的每個字元，將該字元依照統計到的出現次數，重複附加到答案字串。
 *    - 同時用 appear[26] 標記哪些字元已經處理過。
 * 3. 補上剩餘字元：
 *    - 最後再走訪一次 s，把沒有出現在 order 裡的字元（appear 為 false）依原順序接在答案後面。
 */
class Solution {
public:
    string customSortString(string order, string s) {
        vector<int> counts(26, 0);
        string ans;
        for(const char& c : s) counts[c - 'a']++;
        for(const char& c : order) {
            while(counts[c - 'a']) {
                ans.push_back(c);
                counts[c - 'a']--;
            }
        }
        for(int i = 0; i < 26; i++) {
            while(counts[i]) {
                ans.push_back(i + 'a');
                counts[i]--;
            }
        }
        return ans;
    }
};
```
