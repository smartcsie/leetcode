# 406. Queue Reconstruction by Height

[在 LeetCode 上查看](https://leetcode.com/problems/queue-reconstruction-by-height/)

**難度:** 🟡 Medium　**標籤:** Greedy Sorting Decision　**時間:** O(N²)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：406. Queue Reconstruction by Height
 * 難度：中等 (Medium)
 * 分類主題：greedy-sorting-decision
 * 描述：給定一組人 people[i] = [h, k]，h 是身高、k 是「排在他前面、
 * 身高 >= h 的人數」。重新排列這些人，讓每個人的 k 值都符合實際隊列
 * 位置。
 *
 * 時間複雜度：O(N²)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Sorting + Greedy Decision，排序順序的選擇是這題的靈魂：先排「不
 * 會被後面影響」的維度，才能讓插入動作天然滿足另一個維度的限制）：
 * 1. 排序規則：身高 h 由高到低排；身高相同時，k 值由小到大排。
 * 2. **為什麼這樣排序有效**：身高較高的人插入隊列時，後面身高較矮的
 *    人插入不會影響到「已經排好的高個子」們的相對順序跟前面人數
 *    （因為矮個子不算進高個子的 k 值計算），所以只要按身高從高到低
 *    處理，每個人插入時看到的「已排好的人」都一定 >= 他的身高，
 *    可以直接用 k 值當作插入位置的索引。
 * 3. 依序把排序後的每個人插入到結果陣列的第 k 個位置（`insert`），
 *    插入操作會自動把後面的元素往後推，天然維持隊列結構。
 * 4. 全部插入完成後，結果陣列就是滿足所有人 k 值限制的隊列。
 */
class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        sort(people.begin(), people.end(), [](const vector<int>& a, const vector<int>& b) {
            if (a[0] != b[0]) return a[0] > b[0];
            return a[1] < b[1];
        });
        vector<vector<int>> result;
        for (auto& p : people) {
            result.insert(result.begin() + p[1], p);
        }
        return result;
    }
};
```
