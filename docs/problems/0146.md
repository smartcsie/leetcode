# 146. LRU Cache

[在 LeetCode 上查看](https://leetcode.com/problems/lru-cache/)

**難度:** 🟡 Medium　**標籤:** Design, Hash Table, Doubly Linked List, Design　**時間:** O(1)　**空間:** O(Capacity)　**熟悉度:** 🟠 再練習　🏆 **最佳解**

```cpp
/**
 * 題目：146. LRU Cache (LRU 快取機制)
 * 難度：中等 (Medium)
 * 描述：設計並實作一個 LRU（最近最少使用）快取機制，支援 get 與 put 操作，
 *       兩者的時間複雜度都必須是 O(1)；當容量超過上限時，需要淘汰最久未使用的資料。
 *
 * 時間複雜度：O(1)
 *             以及 std::list::splice 的常數時間節點搬移（splice 不需要複製資料）。
 * 空間複雜度：O(Capacity)
 *
 * 解法思路：
 * 1. 雙向鏈結串列維護使用順序 (Doubly Linked List for Recency Order)：
 *    - 用 std::list<pair<int,int>> 儲存 (key, value)，串列尾端（back）代表最近使用，
 *      串列前端（front）代表最久未使用。
 * 2. 雜湊表儲存 key 到節點位置的映射 (Hash Map to Iterator)：
 *    - unordered_map<int, iterator> 讓每個 key 都能在 O(1) 時間內，
 *      直接定位到其在鏈結串列中的節點位置，不需要線性搜尋。
 * 3. get：命中時搬到最新位置 (Move to Back on Hit)：
 *    - 若找到 key，利用 list::splice 把該節點直接搬移到串列尾端（O(1)，不需要
 *      重新配置記憶體或複製資料），標記為最近使用，並回傳其值。
 * 4. put：已存在則更新並搬移，不存在則視容量決定是否淘汰：
 *    - 若 key 已存在，直接更新該節點的值，並同樣搬移到尾端。
 *    - 若 key 不存在且容量已滿，先移除串列前端（最久未使用）的節點，
 *      並同步從雜湊表中刪除該 key，再把新節點插入尾端並記錄其位置。
 * 5. splice 的關鍵優勢：迭代器不失效 (Iterator Stability)：
 *    - std::list::splice 只是重新連結節點指標，不會使既有的迭代器失效，
 *      因此雜湊表裡儲存的迭代器，在節點被搬移後依然有效可用。
 */
class LRUCache {
private:
    int size;
    list<pair<int,int>> lst;                          // back = 最新
    unordered_map<int, list<pair<int,int>>::iterator> mp;  // key → iterator

public:
    LRUCache(int capacity) : size(capacity) {}

    int get(int key) {
        auto it = mp.find(key);
        if (it == mp.end()) return -1;

        // 搬到 back（最新）
        lst.splice(lst.end(), lst, it->second);
        return it->second->second;
    }

    void put(int key, int value) {
        auto it = mp.find(key);
        if (it != mp.end()) {
            // 已存在 → 更新並搬到 back
            it->second->second = value;
            lst.splice(lst.end(), lst, it->second);
        } else {
            if (lst.size() == size) {
                // 移除最舊（front）
                mp.erase(lst.front().first);
                lst.pop_front();
            }
            lst.push_back({key, value});
            mp[key] = std::prev(lst.end());
        }
    }
};
```
