# 292. Nim Game

[在 LeetCode 上查看](https://leetcode.com/problems/nim-game/)

**難度:** 🟢 Easy　**標籤:** Math, Game Theory　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🟣 易忘　🏆 **最佳解**

```cpp
/**
 * 題目：292. Nim Game (Nim 遊戲)
 * 難度：簡單 (Easy)
 * 描述：你和朋友輪流從一堆共 n 顆石頭中拿取，每次可拿 1~3 顆，拿走最後一顆石頭的人獲勝。
 *       你先手，假設雙方都採取最佳策略，判斷你是否能獲勝。
 *
 * 時間複雜度：O(1)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 關鍵觀察：只有「4 的倍數」是必敗局面 (Losing Positions are Multiples of 4)：
 *    - 因為每次最多能拿 3 顆，若剩餘數量是 4 的倍數，不管對手拿 1、2、3 顆，
 *      你都能拿走「湊成 4」的補數（例如對手拿 1 顆，你就拿 3 顆），
 *      讓場上剩餘數量永遠維持在 4 的倍數，最終逼迫對手面對剩 0 顆、無石可拿的窘境。
 * 2. 反過來：只要不是 4 的倍數就必勝 (Non-Multiples of 4 are Winning Positions)：
 *    - 只要 n 不是 4 的倍數，你可以先拿走 (n mod 4) 顆，讓剩餘數量變成 4 的倍數，
 *      把「必敗局面」丟給對手，之後只要持續維持這個 4 的倍數策略即可獲勝。
 * 3. 結論化簡成一行判斷式：
 *    - 直接回傳 n % 4 != 0，即為「n 不是 4 的倍數時你必勝」的結論。
 */
class Solution {
public:
    bool canWinNim(int n) {
        return !(n % 4 == 0);
    }
};
```

> 只有「4 的倍數」是必敗局面
