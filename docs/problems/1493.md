# 1493. Longest Subarray of 1's After Deleting One Element

[在 LeetCode 上查看](https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/)

**難度:** 🟡 Medium　**標籤:** Sliding Window, Two Pointers　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1493. Longest Subarray of 1's After Deleting One Element
 * 難度：待補充
 * 描述：給你一個二進位陣列 nums，你需要刪除其中恰好一個元素。
 * 請返回刪除後，只包含 1 的最長子陣列的長度。如果陣列中原本沒有 1 或是全部刪除後為空，返回 0。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （滑動視窗法 Sliding Window）：
 * 1. 視窗狀態維護：
 * - 使用滑動視窗（`left` 到 `right`）來尋找最多包含一個 `0` 的最長子陣列。
 * - 變數 `zeros` 用來記錄當前視窗中 `0` 的數量。
 * 2. 視窗收縮機制：
 * - 當右指標 `right` 遇到 `0` 時，將 `zeros` 加 1。
 * - 若 `zeros` 大於或等於 2（即視窗中出現了兩個以上的 `0`，不符合題目「只能刪除一個元素/容許一個 0」的條件），則開始收縮左指標 `left`，直到把多餘的 `0` 移出視窗外。
 * 3. 長度計算與更新：
 * - 因為題目要求「必須刪除一個元素」，所以視窗內扣除掉一個被刪除的元素後，其實際的連續 `1` 的長度為 `right - left`（注意：此處 `right - left` 代表含一個 0 的視窗總長度減去 1 個字元，數學上剛好等於 `right - left`）。最後透過 `max(ans, right - left)` 更新最大值。
 */

class Solution {
public:
    int longestSubarray(std::vector<int>& nums) {
        int ans = 0;
        int zeros = 0;
        int left = 0;
        
        for (int right = 0; right < nums.size(); right++) {
            // 若當前元素為 0，累積計數
            if (nums[right] == 0) {
                zeros++;
            }
            
            // 當視窗內包含 2 個或以上的 0 時，收縮左指標
            while (zeros >= 2) {
                if (nums[left++] == 0) {
                    zeros--;
                }
            }
            
            // 更新最大長度（因為視窗容許一個 0，實際連續 1 的長度剛好等於 right - left）
            ans = std::max(ans, right - left);
        }
        
        return ans;
    }
};
```
