# 986. Interval List Intersections

[在 LeetCode 上查看](https://leetcode.com/problems/interval-list-intersections/)

**難度:** 🟡 Medium　**標籤:** Array Interval, Two Pointers, Interval Processing　**時間:** O(M+N)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：986. Interval List Intersections
 * 難度：待補充
 * 描述：給定兩個由「已排序且不相交」的區間列表 firstList 和 secondList，
 * 返回這兩個區間列表的交集。
 *
 * 時間複雜度：O(M+N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （雙指標法 Two Pointers）：
 * 1. 區間交集的核心數學邏輯：
 * - 兩個區間 `[A_start, A_end]` 與 `[B_start, B_end]` 的交集範圍為：
 * `start = max(A_start, B_start)`
 * `end = min(A_end, B_end)`
 * - 當且僅當 `start <= end` 時，代表交集區間確實存在。
 * 2. 指標推進策略：
 * - 比較兩個區間的「結束位置（end）」。結束位置較早的那個區間已經不可能和下一個區間產生交集了，
 * 因此結束位置較小的那個指針可以向後移動（`i++` 或 `j++`）。
 */

class Solution {
public:
    std::vector<std::vector<int>> intervalIntersection(std::vector<std::vector<int>>& firstList, std::vector<std::vector<int>>& secondList) {
        vector<vector<int>> ans;
        vector<vector<int>>& a = firstList;
        vector<vector<int>>& b = secondList;
        int m = a.size();
        int n = b.size();
        if(m == 0 || n == 0) return {};
        int i =0, j = 0;
        while(i < m && j < n) {
            int start = max(a[i][0], b[j][0]);
            int end = min(a[i][1], b[j][1]);
            if(start <= end) ans.push_back({start, end});
            if(a[i][1] < b[j][1]) i++;
            else j++;
        }
        return ans;
    }
};
```
