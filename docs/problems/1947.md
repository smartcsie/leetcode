# 1947. Maximum Compatibility Score Sum

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-compatibility-score-sum/)

**難度:** 🟡 Medium　**標籤:** Backtracking Permutation　**時間:** O(M!　**空間:** O(M)（used 陣列 + 遞迴深度）　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1947. Maximum Compatibility Score Sum
 * 難度：中等 (Medium)
 * 描述：給定 m 個學生和 m 個導師的問卷答案（都是 0/1 組成的陣列），
 * 把學生跟導師一對一配對，「相容分數」是兩人問卷裡答案相同的題數。
 * 求一種配對方式，讓所有配對的相容分數總和最大。
 *
 * 時間複雜度：O(M! * M * K)
 * 空間複雜度：O(M)
 *
 * 解法思路：
 * （Permutation 回溯，本質是「幫每個學生分配一個還沒被分配過的
 * 導師」）：
 * 1. backtrack(studentIdx, curScore) 代表「已經處理到第 studentIdx
 *    個學生、目前累積分數是 curScore」。
 * 2. 枚舉還沒被分配的導師 j，計算學生 studentIdx 跟導師 j 的相容
 *    分數（逐題比對答案是否相同），遞迴處理下一個學生。
 * 3. **剪枝的關鍵（之前版本在這裡算錯）**：樂觀上界要用「剩下的學生
 *    數 × 每個學生最多能拿到的分數」來估計，而「每個學生最多能拿到
 *    的分數」的上限是**問卷題數 k**（不是學生人數 m！），因為相容
 *    分數是逐題比對算出來的，最多就是題數。如果誤用 m 當作這個上限，
 *    在 k > m（題數比人數多）的情況下，上界會被低估，導致原本還有
 *    機會的分支被提早剪掉，得到錯誤（偏低）的答案。
 * 4. base case：studentIdx == m，代表所有學生都配對完畢，更新全域
 *    最佳解 best。
 */
class Solution {
    int m, k, best = 0;
    vector<bool> used;

    void backtrack(vector<vector<int>>& students, vector<vector<int>>& mentors, int studentIdx, int curScore) {
        if (curScore + (m - studentIdx) * k <= best) return;
        if (studentIdx == m) {
            best = max(best, curScore);
            return;
        }
        for (int j = 0; j < m; ++j) {
            if (used[j]) continue;
            int score = 0;
            for (int s = 0; s < k; ++s) {
                if (students[studentIdx][s] == mentors[j][s]) score++;
            }
            used[j] = true;
            backtrack(students, mentors, studentIdx + 1, curScore + score);
            used[j] = false;
        }
    }

public:
    int maxCompatibilitySum(vector<vector<int>>& students, vector<vector<int>>& mentors) {
        m = students.size();
        k = students[0].size();
        used.assign(m, false);
        backtrack(students, mentors, 0, 0);
        return best;
    }
};
```
