# 1551. Minimum Operations to Make Array Equal

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-operations-to-make-array-equal/)

**難度:** 🟡 Medium　**標籤:** Greedy Coin Change　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1551. Minimum Operations to Make Array Equal
 * 難度：中等 (Medium)
 * 描述：給定一個長度為 n 的陣列 arr，arr[i] = 2*i + 1（也就是
 * 1, 3, 5, ..., 2n-1）。每次操作可以選兩個索引 x, y，把 arr[x] +1、
 * arr[y] -1（相當於把一個單位從 y 轉移到 x）。求讓所有元素都相等
 * 所需的最少操作次數。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （這題分類在 Coin Change 底下，但更準確地說是利用陣列的對稱性
 * 做數學推導，跟找零錢的關係比較薄弱，先列出正確解法）：
 * 1. 因為每次操作是「一邊 +1、另一邊 -1」，陣列總和永遠不變。要讓
 *    所有元素相等，目標值只能是「總和 ÷ n」，也就是這個等差數列的
 *    平均值 = n（1+3+5+...+(2n-1) = n²，平均剛好是 n）。
 * 2. **關鍵觀察（利用對稱性）**：這個數列以 n 為中心對稱——小於 n
 *    的那些元素「總共缺多少」，剛好等於大於 n 的那些元素「總共多多少」
 *    （因為數列本身左右對稱）。所以只需要算「下半部分」缺多少，就是
 *    答案，不用管上半部分（它們的多餘量會透過操作被下半部分吸收）。
 * 3. 對 i = 0 到 n/2 - 1（下半部分，元素值是 2i+1），每個元素跟目標
 *    值 n 的差距是 n - (2i+1)，全部加總就是答案。
 * 4. 這其實是一個標準的「所有元素移動到中位數/平均值最省成本」問題，
 *    因為這個特殊數列的中位數剛好就是平均值 n，公式可以直接化簡成
 *    對下半部求和。
 */
class Solution {
public:
    int minOperations(int n) {
        int ops = 0;
        for (int i = 0; i < n / 2; ++i) {
            int val = 2 * i + 1;
            ops += (n - val);
        }
        return ops;
    }
};
```
