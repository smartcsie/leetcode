# 131. Palindrome Partitioning

[在 LeetCode 上查看](https://leetcode.com/problems/palindrome-partitioning/)

**難度:** 🟡 Medium　**標籤:** Backtracking Combination　**時間:** O(N × 2^N)（最壞情況，回溯窮舉所有切割方式）　**空間:** O(N)（遞迴堆疊 + 目前路徑）　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：131. Palindrome Partitioning
 * 難度：中等 (Medium)
 * 描述：給定一個字串 s，把它切割成幾段，讓每一段都是回文，回傳所有
 * 可能的切割方式。
 *
 * 時間複雜度：O(N × 2^N)（最壞情況，回溯窮舉所有切割方式）
 * 空間複雜度：O(N)（遞迴堆疊 + 目前路徑）
 *
 * 解法思路：
 * （標準回溯，跟 Combination Sum 系列是同一個框架，只是這裡限制
 * 「每一段都要是回文」而不是「總和等於目標值」）：
 * 1. backtrack(start) 代表「目前已經處理到 s 的第 start 個字元，
 *    前面的部分已經切好」，要決定從 start 開始的下一段要切多長。
 * 2. 枚舉這一段的結尾 end（從 start 到字串結尾），如果 s[start..end]
 *    是回文，就把它加進目前路徑 path，遞迴處理 backtrack(end+1)。
 * 3. base case：start 走到字串結尾，代表整個字串都切完了，把目前的
 *    path 存進結果。
 * 4. 回溯：遞迴回來後要把剛剛加進 path 的這一段移除（pop_back），
 *    才能繼續嘗試下一種切法。
 * 5. isPalindrome 用雙指標從兩端往中間夾，判斷子字串是否為回文，
 *    這是這題唯一的「額外檢查」，其餘完全是通用的切割型回溯模板。
 */
class Solution {
    vector<vector<string>> result;
    vector<string> path;
    string s;

    bool isPalindrome(int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) return false;
            left++; right--;
        }
        return true;
    }

    void backtrack(int start) {
        if (start == (int)s.size()) {
            result.push_back(path);
            return;
        }
        for (int end = start; end < (int)s.size(); ++end) {
            if (isPalindrome(start, end)) {
                path.push_back(s.substr(start, end - start + 1));
                backtrack(end + 1);
                path.pop_back();
            }
        }
    }

public:
    vector<vector<string>> partition(string s_) {
        s = s_;
        backtrack(0);
        return result;
    }
};
```
