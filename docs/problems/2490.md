# 2490. Circular Sentence

[在 LeetCode 上查看](https://leetcode.com/problems/circular-sentence)

**難度:** 🟢 Easy　**標籤:** String　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2490. Circular Sentence (環形句)
 * 難度：簡單 (Easy)
 * 描述：檢查句子是否為環形：相鄰詞的銜接處字元相等，且句首與句尾字元相等。
 *
 * 時間複雜度：O(N) - 遍歷一次字串。
 * 空間複雜度：O(1) - 僅使用常數空間。
 */

class Solution {
public:
    bool isCircularSentence(string sentence) {
        const string& s = sentence;
        if(s.front() != s.back()) return false;
        for(int i = 0; i < s.size(); i++) {
            if(s[i] == ' ' && s[i + 1] != s[i - 1]) return false;
        }
        return true;
    }
};
```

> 先檢查第一個和最後一個char是否相等，segment 1或多同時處理，if(sentence.front() != sentence.back()) return false;<br>
