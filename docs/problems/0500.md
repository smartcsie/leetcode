**技巧:** 字母對應列號的查表、位元遮罩記錄出現過的列、c \| 32 轉小寫、遮罩只剩一個 1 代表同一列

```cpp
/**
 * 題目：500. Keyboard Row
 * 難度：Easy
 * 描述：給定字串陣列 words，回傳其中「只用美式鍵盤同一列字母就能打出來」的單字。
 *       三列分別為 "qwertyuiop"、"asdfghjkl"、"zxcvbnm"，大小寫字母視為相同。
 *
 * 分類主題：string
 * 技巧：字母對應列號的查表, 位元遮罩記錄出現過的列, c | 32 轉小寫, 遮罩只剩一個 1 代表同一列
 *
 * 時間複雜度：O(L)，L 為所有單字的字元總數
 * 空間複雜度：O(1)（查表固定 26 個字母，不計輸出）
 *
 * 解法思路：查表 + 位元遮罩
 * 1. 先建立「字母 → 列號」的對照表 c2r，三列分別對應 1、2、3。
 * 2. 逐字掃描單字，用 mask 記錄「目前出現過哪些列」：
 *    mask |= 1 << 列號，所以第 1、2、3 列分別對應 bit 1、2、3，
 *    即遮罩值 2、4、8。
 * 3. 若所有字母都在同一列，mask 一定停在 2、4、8 其中之一；
 *    只要出現第二種列，mask 就會同時有兩個 1（例如 6、10、12、14），
 *    不在這三個值內，就可以提早跳出，不用掃完整個單字。
 * 4. 大小寫轉換用 c | 32：大寫字母的 ASCII 第 5 位元（值 32）是 0，
 *    OR 上 32 即轉成小寫；小寫字母本來就是 1，不受影響。
 *    只適用於英文字母，題目保證單字只含英文字母。
 * 5. 掃完仍維持單一列的單字，加入答案。
 */

class Solution {
public:
    vector<string> findWords(vector<string>& words) {
        vector<string> ans;
        static constexpr string_view rows = "23321222122233111121131313";
        for(const string& word : words) {
            bool oneRow = true;
            int idx1 = (word[0] | 32) - 'a';
            char first = rows[idx1];
            for(const char& c : word) {
                int idx2 = (c | 32) - 'a';
                if(rows[idx2] ^ first) {
                    oneRow = false;
                    break;
                }
            }
            if(oneRow) ans.push_back(word);
        }
        return ans;
    }
};
```
