# 1758. Minimum Changes To Make Alternating Binary String

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-changes-to-make-alternating-binary-string)

**難度:** 🟢 Easy　**標籤:** String　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：1758. Minimum Changes To Make Alternating Binary String (生成交替二進位字串的最小操作數)
 * 難度：簡單 (Easy)
 * 描述：計算將字串變為 "0101..." 或 "1010..." 所需的最少翻轉次數。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 */

class Solution {
public:
    int minOperations(string s) {
        int count = 0;
        for(int i = 0; i < s.size(); i++) {
            if(i % 2 == s[i] - '0') count++;
        }
        return min(static_cast<int>(s.size()) - count, count);
    }
};
```

> **for(int i = 0 ; i < s.size(); i++) if(i % 2 == s[i]-'0') count++;** <br>
> 上面是算 01010101 ...需要修改的bit數<br>
> min(static_cast<int>(s.size()) - count, count)是抓 0101...和 1010...改比較少的為答案
