# 3079. Find the Sum of Encrypted Integers

[在 LeetCode 上查看](https://leetcode.com/problems/find-the-sum-of-encrypted-integers/)

**難度:** 🟢 Easy　**標籤:** Math Digit Decomposition, Digit Manipulation　**時間:** O(N*D)　**空間:** O(D)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：3079. Find the Sum of Encrypted Integers (求加密整數的和)
 * 難度：簡單 (Easy)
 * 描述：定義 encrypt(x) 為：把整數 x 的每一位數字，都替換成 x 當中最大的那個數字。
 *       給定整數陣列 nums，回傳所有元素經過 encrypt 後的總和。
 *
 * 時間複雜度：O(N*D) - N 為陣列長度，D 為數字的最大位數（視為常數，通常不超過 10）。
 * 空間複雜度：O(D) - 每次處理時需要一個長度為 D 的暫存字串。
 *
 * 解法思路：
 * 1. 單一位數的捷徑判斷 (Single-Digit Shortcut)：
 *    - 若 num 小於 10（本身只有一位數），encrypt 後的結果就是自己，直接累加即可。
 *      這只是效能上的小優化，即使拿掉這個分支，讓 else 邏輯統一處理，結果依然正確。
 * 2. 轉成字串以逐位取出數字 (Convert to String for Digit Access)：
 *    - 對於多位數的 num，先用 to_string 轉成字串，方便逐一存取每個位數字元。
 * 3. 找出最大位數字元 (Find Max Digit)：
 *    - 利用 std::max_element 找出字串中最大的字元（也就是最大的數字位）。
 * 4. 組成新字串並轉換回整數 (Reconstruct and Convert Back)：
 *    - 建立一個與原本長度相同、每一位都是 maxChar 的新字串
 *      （例如原本是 3 位數，maxChar 是 '5'，就組成 "555"），
 *      再用 stoi 轉換回整數，即為 encrypt(num) 的結果。
 * 5. 累加所有加密後的結果：
 *    - 將每個元素加密後的值累加進 ans，最終回傳總和。
 */
class Solution {
public:
    int sumOfEncryptedInt(vector<int>& nums) {
        int ans = 0;
        for(const int& num : nums) {
            if(num < 10) {
                ans += num;
            } else {
                string str = to_string(num);
                char maxChar = *max_element(str.begin(), str.end());
                ans += stoi(string(str.size(), maxChar));
            }
        }
        return ans;
    }
};
```
