# 3114. Latest Time You Can Obtain After Replacing Characters

[在 LeetCode 上查看](https://leetcode.com/problems/latest-time-you-can-obtain-after-replacing-characters/)

**難度:** 🟢 Easy　**標籤:** Greedy, String　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：3114. Latest Time You Can Obtain After Replacing Characters
 * 難度：待補充
 * 描述：給定一個字串表示 12 小時制的時間（格式為 "HH:MM"），其中某些數字可能是 '?'。
 * 請將 '?' 替換成數字，求出能表示的最晚有效時間。
 *
 * 時間複雜度：O(1)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * (Greedy)：
 * - 12 小時制的有效範圍是 "00:00" 到 "11:59"。
 * - 第 0 位 (時十位)：如果第 1 位已經是 '2'~'9'，則第 0 位只能是 '0' (如 09)；否則最大可以是 '1' (如 11)。
 * - 第 1 位 (時個位)：如果第 0 位是 '1'，則最大只能是 '1' (即 11)；否則可以是 '9' (即 09)。
 * - 第 3 位 (分十位)：最大為 '5' (即 59分)。
 * - 第 4 位 (分個位)：最大為 '9'。
 */

class Solution {
public:
    string findLatestTime(string s) {
        if(s[0] == '?') {
            if(s[1] == '0' || s[1] == '1' || s[1] == '?') s[0] = '1';
            else s[0] = '0';
        }
        if(s[1] == '?') {
            if(s[0] == '1') s[1] = '1';
            else s[1] = '9';
        }
        if(s[3] == '?') s[3] = '5';
        if(s[4] == '?') s[4] = '9';
        return s;
    }
};
```
