```cpp
/**
 * 題目：2264. Largest 3-Same-Digit Number in String
 * 難度：Easy
 * 描述：給定代表一個大整數的字串 num。找出 num 中長度為 3、
 *       且三個字元完全相同的子字串，回傳其中數值最大的那一個（以字串形式回傳）。
 *       若不存在，回傳空字串 ""。注意結果可能含前導 0（例如 "000"）。
 *
 * 分類主題：string-substring-enumeration
 * 技巧：固定長度 3 的視窗掃描, 三個字元相同才算, 比較字元大小等價於比較數字大小, 用空字串表示尚未找到
 *
 * 時間複雜度：O(n)
 * 空間複雜度：O(1)
 *
 * 解法思路：線性掃描每個長度為 3 的子字串
 * 1. 從 i = 0 掃到 n - 3，檢查 num[i]、num[i + 1]、num[i + 2] 是否三個都相同。
 * 2. 三個相同時，這個子字串的數值只取決於那個數字本身（"777" > "333"），
 *    所以只要比較 num[i] 與目前答案的第一個字元即可。
 *    '0' ~ '9' 的字元編碼依序遞增，直接比較字元就等價於比較數字大小。
 * 3. ans 為空代表還沒找到過，直接採用；否則只有當前數字更大才更新。
 * 4. 結果用 string(3, num[i]) 組成，會保留前導 0，所以 "000" 也會正確回傳。
 * 5. 一直沒找到就回傳初始的空字串，符合題意。
 * 6. 迴圈條件 num.size() - 2 是無號數運算，num.size() 小於 2 時會溢位成很大的數；
 *    題目保證長度至少為 3，所以不會發生。
 */
class Solution {
public:
    string largestGoodInteger(string num) {
        string ans;  // 空字串代表目前還沒找到
        for(int i = 0; i < num.size() - 2; i++) {
            // 三個連續字元相同
            if(num[i] == num[i + 1] && num[i + 1] == num[i + 2]) {
                // 第一次找到，或這個數字比目前答案更大，就更新
                if(ans.empty() || num[i] > ans[0]) {
                    ans = string(3, num[i]);
                }
            }
        }
        return ans;
    }
};
```
