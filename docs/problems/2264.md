# 2264. Largest 3-Same-Digit Number in String

[在 LeetCode 上查看](https://leetcode.com/problems/largest-3-same-digit-number-in-string/)

**難度:** 🟢 Easy　**標籤:** Array Linear Scan, String　**時間:** O(N)　**空間:** O(1)

```cpp
/**
 * 題目：2264. Largest 3-Same-Digit Number in String (字串中最大的 3 位相同數字)
 * 難度：簡單 (Easy)
 * 描述：給定數字字串 num，找出其中「連續三個相同數字」所組成的最大合法子字串
 *       （例如 "222"），若不存在則回傳空字串。
 *
 * 時間複雜度：O(N) - 只需對字串進行一次線性掃描。
 * 空間複雜度：O(1) - 只使用常數個變數（maxChar），不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 線性掃描檢查每個長度為 3 的視窗 (Linear Scan for Triple)：
 *    - 對每個索引 i，檢查 num[i]、num[i+1]、num[i+2] 是否三者皆相同，
 *      代表存在一個合法的「連續三位相同數字」。
 * 2. 用哨兵值 0 追蹤目前找到的最大合法數字：
 *    - maxChar 初始化為字元值 0（不是字元 '0'），因為任何實際數字字元的 ASCII 值
 *      都大於 0，可以安全地用「是否等於 0」來判斷「尚未找到任何合法三連數字」。
 * 3. 更新最大值：
 *    - 每當找到符合條件的三連數字，用 max(maxChar, num[i]) 更新目前找到的最大數字字元。
 * 4. 組合最終答案：
 *    - 若 maxChar 仍為 0（代表整個字串都沒有出現過三連相同數字），回傳空字串；
 *      否則回傳由該數字字元重複 3 次組成的字串（例如 maxChar 為 '7' 則回傳 "777"）。
 */
class Solution {
public:
    string largestGoodInteger(string num) {
        char maxChar = 0;
        for(int i = 0 ; i < num.size() - 2; i++) {
            if(num[i] == num[i + 1] && num[i] == num[i + 2]) {
                maxChar = max(maxChar, num[i]);
            }
        }
        return (maxChar == 0) ? "" : string(3, maxChar);
    }
};
```
