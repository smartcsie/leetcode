# 3120. Count the Number of Special Characters I

[在 LeetCode 上查看](https://leetcode.com/problems/count-the-number-of-special-characters-i/)

## 解法：bit-manipulation

**難度:** 🟢 Easy　**標籤:** Bit Manipulation　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：3120. Count the Number of Special Characters I
 * 難度：簡單 (Easy)
 * 描述：計算字串中同時出現大小寫形式的字母數量。
 * 優化重點：
 * 1. 位元遮罩 (Bitmask)：使用 int 作為 26 位元陣列，紀錄 'a'-'z' 與 'A'-'Z' 的出現狀態。
 * 2. 空間效率：僅用兩個整數變數，實現 O(1) 的輔助空間。
 * 3. 狀態合併：透過 `lower & upper` 運算，直接找出同時存在的位元。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 */

class Solution {
public:
    int numberOfSpecialChars(string word) {
        int lower = 0;
        int upper = 0;
        for(char c : word) {
            if(islower(c)) lower |= 1 << (c-'a');
            if(isupper(c)) upper |= 1 << (c-'A');
        }
        return __builtin_popcount(lower & upper);
    }
};
```

## 解法：bit-manipulation-and

**難度:** 🟢 Easy　**標籤:** Bit Manipulation And　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：3120. Count the Number of Special Characters I
 * 難度：簡單 (Easy)
 * 分類主題：bit-manipulation-mask
 * 描述：給定一個字串 word，如果某個字母同時以大寫跟小寫出現在字串裡，
 * 就稱它是「特殊字母」，求總共有幾個特殊字母。
 *
 * 時間複雜度：O(N)，N 是字串長度
 * 空間複雜度：O(1)（bitmask 固定只需要 26 個 bit）
 *
 * 解法思路：
 * （Bitmask，用兩個整數的每個 bit 分別記錄「這個字母的大寫版本出現
 * 過嗎」跟「小寫版本出現過嗎」，最後用 AND 找出兩邊都出現過的字母）：
 * 1. 用 `accumulate` 搭配一個 lambda，把整個字串「摺疊」成一組
 *    `{大寫遮罩, 小寫遮罩}`，累加初始值是 `{0, 0}`。
 * 2. 對每個字元 `c`：如果是大寫字母，把 `mask[0]`（大寫遮罩）的第
 *    `c - 'A'` 個 bit 設成 1（代表這個字母的大寫版本出現過）；如果
 *    是小寫字母，同樣邏輯設定 `mask[1]`（小寫遮罩）對應的 bit。
 * 3. **關鍵技巧**：不管同一個字母的同一種大小寫出現幾次，遮罩對應
 *    的那個 bit 一直是 1（`|=` 只會設定成 1，不會累加次數），天生
 *    就有去重效果，不用額外處理重複計數的問題。
 * 4. 掃完整個字串後，`ans[0]`、`ans[1]` 分別是「出現過的大寫字母
 *    集合」跟「出現過的小寫字母集合」，兩個各自用 26 個 bit 表示
 *    （bit 0 代表 a/A，bit 1 代表 b/B，以此類推）。
 * 5. 用 `ans[0] & ans[1]` 做 AND：只有「兩邊都出現過」的字母，對應
 *    的 bit 才會在 AND 之後還是 1（一邊是 0、另一邊是 1 的字母，AND
 *    後變 0，代表只出現過其中一種大小寫，不算特殊字母）。
 * 6. `__builtin_popcount` 直接數出 AND 結果裡有幾個 bit 是 1，就是
 *    「同時有大小寫出現」的字母總數，也就是答案。
 * 7. 這題也可以不用 `accumulate` + lambda 這麼「函數式」的寫法，改成
 *    普通迴圈逐字元更新兩個 int 變數，邏輯完全一樣、可讀性可能更好，
 *    但這版示範了 STL 演算法 `accumulate` 搭配自訂 lambda、用
 *    `vector<int>` 當累加狀態的技巧，是另一種常見的寫法風格。
 */
class Solution {
public:
    int numberOfSpecialChars(string word) {
        auto ans = accumulate(word.begin(), word.end(), vector<int>({0, 0}),[](vector<int> mask, char c) {
            if(isupper(c)) mask[0] |= 1 << (c - 'A');
            if(islower(c)) mask[1] |= 1 << (c - 'a');
            return mask;
        });
        return __builtin_popcount(ans[0] & ans[1]);
    }
};
```
