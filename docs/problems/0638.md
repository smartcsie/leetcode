# 638. Shopping Offers

[在 LeetCode 上查看](https://leetcode.com/problems/shopping-offers/)

**難度:** 🟡 Medium　**標籤:** Backtracking Combination　**時間:** O(∏(needs[i]+1))　**空間:** O(∏(needs[i]+1))　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：638. Shopping Offers
 * 難度：中等 (Medium)
 * 描述：給定每種商品的原價 price、一些優惠組合 special（每個優惠是
 * 「買各商品幾件、總價多少」）、以及需要買的數量 needs，優惠可以重複
 * 使用，求買齊 needs 所需的最少花費。
 *
 * 時間複雜度：O(∏(needs[i]+1)
 * 空間複雜度：O(∏(needs[i]+1)
 *
 * 解法思路：
 * （回溯 + 記憶化，這是修正過 TLE 版本的重點）：
 * 1. **原本會 TLE 的原因**：純回溯沒有記憶化，同一組 needs 狀態會被
 *    「不同順序套用優惠」重複計算多次（例如先套優惠 A 再套優惠 B，
 *    跟先套 B 再套 A，會走到同一個 needs，卻被當成兩條全新路徑各自
 *    展開），優惠數量一多，重複計算的量會指數爆炸。
 * 2. **修正 1：加記憶化**。把 needs 這個狀態（陣列）編碼成一個整數
 *    當 key：因為每個商品的 needs[i] 最多 10（0~10 共 11 種可能），
 *    用 11 進位打包成一個 long long（`key = key*11 + needs[i]`），
 *    存進 unordered_map，同一個狀態只算一次。
 * 3. **修正 2：先濾掉不划算的優惠**。如果某個優惠的價格 >= 單獨用
 *    原價買同樣數量商品的花費，這個優惠永遠不會被選中（用原價買一定
 *    比較划算或至少一樣），直接在最外層先濾掉，減少遞迴時要枚舉的
 *    分支數。
 * 4. **修正 3：用固定大小陣列取代 vector**。price.length 最多 6，
 *    改用 `array<int,6>` 取代 `vector<int>` 傳遞 needs 狀態，避免
 *    每次遞迴呼叫都要在 heap 上重新配置記憶體（這在大量遞迴呼叫下
 *    開銷非常可觀）。
 * 5. 狀態轉移邏輯跟原本一樣：base case 是「不用任何優惠、直接原價
 *    買齊」；對每個優惠，檢查扣減後 needs 是否都 >= 0，若合法就遞迴
 *    算出「用了這個優惠之後剩下部分」的最少花費，加上優惠本身價格，
 *    取所有選項的最小值。
 */
class Solution {
    unordered_map<long long, int> memo;
    int n;
    vector<int>* pricePtr;
    vector<vector<int>>* specialPtr;

    long long encode(array<int,6>& needs) {
        long long key = 0;
        for (int i = 0; i < n; ++i) key = key * 11 + needs[i];
        return key;
    }

    int backtrack(array<int,6>& needs) {
        long long key = encode(needs);
        auto it = memo.find(key);
        if (it != memo.end()) return it->second;

        auto& price = *pricePtr;
        auto& special = *specialPtr;

        int best = 0;
        for (int i = 0; i < n; ++i) best += price[i] * needs[i];

        for (auto& offer : special) {
            bool valid = true;
            array<int,6> newNeeds;
            for (int i = 0; i < n; ++i) {
                int remain = needs[i] - offer[i];
                if (remain < 0) { valid = false; break; }
                newNeeds[i] = remain;
            }
            if (!valid) continue;
            int cost = offer[n] + backtrack(newNeeds);
            best = min(best, cost);
        }
        return memo[key] = best;
    }

public:
    int shoppingOffers(vector<int>& price, vector<vector<int>>& special, vector<int>& needsVec) {
        n = price.size();
        pricePtr = &price;

        vector<vector<int>> usefulSpecials;
        for (auto& offer : special) {
            int retailCost = 0;
            for (int i = 0; i < n; ++i) retailCost += offer[i] * price[i];
            if (offer[n] < retailCost) usefulSpecials.push_back(offer);
        }
        specialPtr = &usefulSpecials;

        array<int,6> needs{};
        for (int i = 0; i < n; ++i) needs[i] = needsVec[i];
        return backtrack(needs);
    }
};
```
