# 973. K Closest Points to Origin

[在 LeetCode 上查看](https://leetcode.com/problems/k-closest-points-to-origin)

**難度:** 🟡 Medium　**標籤:** Quick Select, QuickSelect　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：973. K Closest Points to Origin (最接近原點的 K 個點)
 * 難度：中等 (Medium)
 * 描述：在平面上給定一組座標點，回傳距離原點最近的 K 個點。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 原地計算距離並 push_back 到點陣列末端，避免額外記憶體配置。
 * 2. 使用 nth_element 在 O(N) 時間內完成分區。
 * 3. pop_back 移除計算值，還原點的座標資訊。
 */

class Solution {
public:
    vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
        auto it = points.begin() + k;
        nth_element(points.begin(), it, points.end(),
            [](const vector<int>& a, const vector<int>& b) {
                return a[0]*a[0] + a[1]*a[1] < b[0]*b[0] + b[1]*b[1];
            });
        return vector<vector<int>>(points.begin(), it);
    }
};
```
