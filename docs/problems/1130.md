# 1130. Minimum Cost Tree From Leaf Values

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-cost-tree-from-leaf-values/)

**難度:** 🟡 Medium　**標籤:** Dp Interval　**時間:** O(N³)　**空間:** O(N²)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1130. Minimum Cost Tree From Leaf Values
 * 難度：中等 (Medium)
 * 描述：給定一個正整數陣列 arr，把它當作某棵二元樹的葉節點（依中序排列，
 * 順序不能改變）。每個內部節點的值是它左右子樹裡最大葉節點值的乘積，
 * 整棵樹的成本是所有內部節點值的總和。求最小可能的成本。
 *
 * 時間複雜度：O(N³)
 * 空間複雜度：O(N²)
 *
 * 解法思路：
 * （Interval DP，dp[i][j] 代表「用 arr[i..j] 這段葉節點」建樹的最小成本）：
 * 1. 先預處理 maxVal[i][j]，代表 arr[i..j] 這段區間的最大值（要建內部
 *    節點時常常需要查詢子區間最大值，先算好避免重複計算）。
 * 2. 狀態轉移：枚舉切割點 k（i <= k < j），把 arr[i..j] 切成
 *    arr[i..k] 和 arr[k+1..j] 兩段，分別當作左右子樹：
 *    dp[i][j] = min over k of dp[i][k] + dp[k+1][j] + maxVal[i][k] * maxVal[k+1][j]。
 *    也就是先建好左右兩個子樹（成本分別是 dp[i][k]、dp[k+1][j]），再加上
 *    這次合併產生的內部節點成本（兩邊最大值相乘）。
 * 3. 按照區間長度由小到大遞推，答案是 dp[0][n-1]。
 * 4. 這題其實有 O(N) 的單調堆疊解法（利用「每次合併掉較小的相鄰元素」
 *    的貪心觀察），但這版走標準 Interval DP 套路，跟同分類其他題目
 *    模板一致，比較好類比記憶。
 */
class Solution {
public:
    int mctFromLeafValues(vector<int>& arr) {
        int n = arr.size();
        vector<vector<int>> maxVal(n, vector<int>(n));
        for (int i = 0; i < n; ++i) {
            maxVal[i][i] = arr[i];
            for (int j = i + 1; j < n; ++j) {
                maxVal[i][j] = max(maxVal[i][j - 1], arr[j]);
            }
        }
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int len = 2; len <= n; ++len) {
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;
                dp[i][j] = INT_MAX;
                for (int k = i; k < j; ++k) {
                    int cost = dp[i][k] + dp[k + 1][j] + maxVal[i][k] * maxVal[k + 1][j];
                    dp[i][j] = min(dp[i][j], cost);
                }
            }
        }
        return dp[0][n - 1];
    }
};
```
