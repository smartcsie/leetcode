# 2116. Check if a Parentheses String Can Be Valid

[在 LeetCode 上查看](https://leetcode.com/problems/check-if-a-parentheses-string-can-be-valid/)

**難度:** 🟡 Medium　**標籤:** Greedy, String　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：2116. Check if a Parentheses String Can Be Valid (檢查括號字串是否可以有效)
 * 難度：中等 (Medium)
 * 描述：給定括號字串 s 與同長度的 locked 字串（'1' 表示該位置字元不可更改，'0' 表示可任意
 *       改成 '(' 或 ')'），判斷能否透過修改所有 locked 為 '0' 的位置，使 s 成為有效括號字串。
 *
 * 時間複雜度：O(N) - 只需對字串進行一次線性掃描。
 * 空間複雜度：O(1) - 只使用常數個變數（minOpen, maxOpen），不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 快速排除奇數長度 (Odd Length Early Return)：
 *    - 有效括號字串的左右括號數量必須相等，總長度必為偶數，奇數長度直接回傳 false。
 * 2. 追蹤「未配對左括號數量」的可能區間 [minOpen, maxOpen]：
 *    - minOpen 代表在最悲觀情況下（萬用字元都盡量當作 ')' 使用），目前未配對左括號的最少可能數量。
 *    - maxOpen 代表在最樂觀情況下（萬用字元都盡量當作 '(' 使用），目前未配對左括號的最多可能數量。
 * 3. 更新 minOpen（悲觀：能關就關）：
 *    - 若字元是固定的 '('，未配對左括號 +1；
 *      若是固定的 ')' 或萬用字元（視為 ')'），未配對左括號 -1。
 * 4. 更新 maxOpen（樂觀：能開就開）：
 *    - 若字元是固定的 '(' 或萬用字元（視為 '('），未配對左括號 +1；
 *      若是固定的 ')'，未配對左括號 -1。
 * 5. 提前失敗與邊界修正：
 *    - 若 maxOpen 一度變成負數，代表即使在最樂觀情況下，右括號都已經多過左括號，無法挽回，直接回傳 false。
 *    - minOpen 不可能為負（未配對左括號數量下限為 0），若計算後小於 0，修正為 0。
 * 6. 最終判斷：
 *    - 走訪完整個字串後，若 minOpen 為 0，代表存在一種修改方式能讓左右括號完全配對，回傳 true。
 */
class Solution {
public:
    bool canBeValid(string s, string locked) {
        int n = s.size();
        if (n & 1) return false;  // 奇數長度必定無效
        int minOpen = 0, maxOpen = 0;
        for (int i = 0; i < n; i++) {
            bool isOpen     = s[i] == '(';
            bool isWildcard = locked[i] == '0';
            // 最悲觀：能關就關（萬用字元當 ) ，固定 ) 也關）
            minOpen += (!isOpen || isWildcard) ? -1 : 1;
            // 最樂觀：能開就開（萬用字元當 ( ，固定 ( 也開）
            maxOpen += (isOpen || isWildcard) ? 1 : -1;
            // 最樂觀情況都無法平衡，直接失敗
            if (maxOpen < 0) return false;
            // 未配對左括號不可能為負
            minOpen = max(minOpen, 0);
        }
        return minOpen == 0;
    }
};
```
