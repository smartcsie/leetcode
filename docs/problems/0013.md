# 13. Roman to Integer

[在 LeetCode 上查看](https://leetcode.com/problems/roman-to-integer)

**難度:** 🟢 Easy　**標籤:** Hash Table Mapping, Hash Table, String　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 注意

```cpp
/**
 * 題目：13. Roman to Integer (羅馬數字轉整數)
 * 難度：簡單 (Easy)
 * 描述：將羅馬數字轉換為整數。
 *
 * 時間複雜度：O(N) - 遍歷字串一次。
 * 空間複雜度：O(1) - 使用固定大小陣列作為查找表。
 *
 * 解法思路：
 * 1. 使用陣列取代 unordered_map：直接將 char 對應到 int，避免雜湊函式開銷。
 * 2. 減少記憶體配置：靜態陣列存於 stack，比動態分配的 map 更快。
 */

int ans = 0;
        vector<int> roman(128);

        roman['I'] = 1;
        roman['V'] = 5;
        roman['X'] = 10;
        roman['L'] = 50;
        roman['C'] = 100;
        roman['D'] = 500;
        roman['M'] = 1000;

        for (int i = 0; i + 1 < s.length(); ++i)
        if (roman[s[i]] < roman[s[i + 1]])
            ans -= roman[s[i]];
        else
            ans += roman[s[i]];

        return ans + roman[s.back()];
```
