```cpp
/**
 * 題目：90. Subsets II
 * 難度：Medium
 * 描述：給定可能含重複數字的整數陣列 nums，回傳所有可能的子集（冪集），
 *       解集不能包含重複的子集，順序不拘。
 *
 * 分類主題：backtracking-combination
 * 技巧：先排序讓相同數字相鄰, 迭代式逐步擴展子集, 遇到重複數字只擴展上一輪新增的子集
 *
 * 時間複雜度：O(n * S)，S 為不重複子集的數量，最壞（全部相異）S = 2^n
 *   每個子集建立時要複製一次，花 O(n)
 * 空間複雜度：O(n)，暫存的一個子集（不計輸出）
 *
 * 解法思路：迭代擴展 + 重複數字只接在上一輪新增的子集後面
 * 1. 先排序：相同數字排在一起，才能用「與前一個比較」判斷是否重複。
 * 2. 一開始 ans 只有空集合。每處理一個數字 nums[i]，
 *    就把它加到若干個現有子集的尾端，產生新子集。
 * 3. nums[i] 與前一個不同：替「所有」現有子集加上 nums[i]，
 *    這是標準的子集生成方式，每輪子集數量翻倍。
 * 4. nums[i] 與前一個相同：只替「上一輪新增的那批」加上 nums[i]。
 *    原因：更早的子集加上這個數字，在上一輪（處理前一個相同數字時）已經產生過了，
 *    再加一次會得到重複的子集。
 *    例如 [1,2,2]：第二個 2 若也擴展 [] 與 [1]，會得到 [2]、[1,2]，和第一個 2 的結果重複。
 * 5. lastStart 記錄「本輪新增的子集在 ans 中的起點」，下一輪遇到重複數字時，
 *    就從這個索引開始擴展，一直到本輪開始前的 ans 大小為止。
 * 6. 先固定 to = ans.size() 再迴圈，確保本輪新增的子集不會在同一輪被再次擴展。
 */
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans = {{}};  // 一開始只有空集合
        int lastStart = 0;               // 上一輪「新增」的子集，在 ans 中的起始索引
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            bool isDuplicate = (i > 0 && nums[i] == nums[i - 1]);
            // 不重複：替所有現有子集加上 nums[i]
            // 重複：只替「上一輪新增的那批」加上 nums[i]，
            //       因為更早的子集加上這個數字，在上一輪已經產生過了
            int from = isDuplicate ? lastStart : 0;
            int to = ans.size();  // 本輪開始前的大小，也是本輪新增子集的起點
            for (int j = from; j < to; j++) {
                vector<int> next = ans[j];  // 複製後再加，避免 push_back 擴容影響參考
                next.push_back(nums[i]);
                ans.push_back(next);
            }
            lastStart = to;  // 記下本輪新增的起點，供下一輪判斷
        }
        return ans;
    }
};
```

```cpp
/**
 * 題目：90. Subsets II
 * 難度：中等 (Medium)
 * 描述：給你一個可能包含重複元素的整數陣列 nums，請你返回該陣列所有可能的子集（冪集）。
 * 解集不能包含重複的子集。你可以按任意順序返回解集。
 *
 * 時間複雜度：O(N*2^N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （位元遮罩窮舉 + 排序去重 Bitmask + Sorting + Hash Set）：
 * 1. 陣列排序（Sorting）：
 * - 先對 `nums` 進行排序，確保相同的元素會相鄰排列。雖然本解法透過 `std::set` 進行去重，但排序有助於讓相同組成的子集順序一致。
 * 2. 透過 Bitmask 窮舉所有子集：
 * - 沿用 78 題的概念，透過從 `0` 到 `2^n - 1` 的整數位元遮罩，組合出所有可能被選取的子集。
 * 3. 利用 `std::set` 過濾重複組合：
 * - 由於原始陣列含有重複元素，不同的位元選擇組合可能會產生內容完全相同的子集。利用 `set::insert` 的回傳值（`.second` 代表是否成功插入新元素），自動過濾掉重複出現的子集，並將唯一結果存入 `res` 矩陣中。
 */

class Solution {
public:
    std::vector<std::vector<int>> subsetsWithDup(std::vector<int>& nums) {
        int n = nums.size();
        std::sort(nums.begin(), nums.end()); // 排序陣列，讓重複元素相鄰
        
        std::set<std::vector<int>> seen; // 利用 set 自動去除重複的子集
        std::vector<std::vector<int>> res;
        
        // 透過 2^n 種位元遮罩窮舉所有子集
        for (int mask = 0; mask < (1 << n); mask++) {
            std::vector<int> cur;
            
            for (int i = 0; i < n; i++) {
                if (mask & (1 << i)) {
                    cur.push_back(nums[i]);
                }
            }
            
            // 若該子集尚未出現過，則成功插入並加入結果集
            if (seen.insert(cur).second) {
                res.push_back(cur);
            }
        }
        
        return res;
    }
};
```
