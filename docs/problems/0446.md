# 446. Arithmetic Slices II - Subsequence

[在 LeetCode 上查看](https://leetcode.com/problems/arithmetic-slices-ii-subsequence/)

**難度:** 🔴 Hard　**標籤:** Dp Subsequences　**時間:** O(N²)　**空間:** O(N²)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：446. Arithmetic Slices II - Subsequence
 * 難度：困難 (Hard)
 * 描述：給定一個整數陣列 nums，求裡面有幾個「等差子序列」（長度至少 3，
 * 相鄰兩項差值固定，元素不需要連續，但順序要保持原本的相對順序）。
 *
 * 時間複雜度：O(N²)
 * 空間複雜度：O(N²)
 *
 * 解法思路：
 * （DP on Subsequences，dp[i] 是一個「公差 -> 數量」的 map，代表
 * 以 nums[i] 結尾、各種公差的等差子序列各有幾個，這題的關鍵是要用
 * map 而不是普通陣列，因為公差可以是任意整數）：
 * 1. dp[i][diff] 代表「以 nums[i] 結尾、公差為 diff」的等差子序列
 *    個數（這裡包含長度為 2 的情況，也就是只有兩個元素、還「不成
 *    等差數列」但可以延伸的候選）。
 * 2. 狀態轉移：對每一對 (j, i) 且 j < i，算出公差 diff = nums[i] -
 *    nums[j]，查詢 dp[j][diff]（代表「以 nums[j] 結尾、公差也是 diff」
 *    的候選數量）：
 *    - 這個數量 cnt 直接貢獻到答案 result（因為每一個「以 j 結尾、
 *      公差 diff」的候選，接上 nums[i] 之後，都變成一個長度 >= 3 的
 *      合法等差子序列）。
 *    - 同時更新 dp[i][diff] += cnt + 1（+1 是因為 (j, i) 這一對本身
 *      也算一個新的「長度 2」候選，可以繼續往後延伸）。
 * 3. 這個 "+1 但不算進 result" 的細節是這題的核心：長度 2 的 pair 不算
 *    等差數列（題目要求長度至少 3），但要記錄下來，因為之後如果有
 *    第三個元素接上來，就會變成合法的等差子序列。
 * 4. 累加所有 (i, j) 配對貢獻的 cnt，就是最終答案。
 */
class Solution {
public:
    int numberOfArithmeticSlices(vector<int>& nums) {
        int n = nums.size();
        long long result = 0;
        vector<unordered_map<long long,int>> dp(n);
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                long long diff = (long long)nums[i] - nums[j];
                int cnt = dp[j].count(diff) ? dp[j][diff] : 0;
                result += cnt;
                dp[i][diff] += cnt + 1;
            }
        }
        return (int)result;
    }
};
```
