# 1851. Minimum Interval to Include Each Query

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-interval-to-include-each-query/)

**難度:** 🔴 Hard　**標籤:** Greedy Priority Queue　**時間:** O((N+Q) log N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1851. Minimum Interval to Include Each Query
 * 難度：困難 (Hard)
 * 分類主題：greedy-priority-queue
 * 描述：給定一組區間 intervals 和一組查詢 queries，對每個查詢值，找
 * 出「包含這個值」的所有區間裡，長度最小的那個，回傳它的長度（沒有
 * 任何區間包含就回傳 -1）。
 *
 * 時間複雜度：O((N+Q) log N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （跟 502 IPO 是同一種「動態候選池 + heap 挑最好的」模式，候選條件
 * 換成「左端點 <= 查詢值」，heap 排序依據換成「區間長度」）：
 * 1. 把 intervals 依照左端點排序；queries 排序但要保留原始索引
 *    （因為答案要按照查詢原本的順序回傳）。
 * 2. 用一個 min-heap 存 {區間長度, 右端點}，依照長度排序（長度最小
 *    的在最上面）。
 * 3. 依照排序後的查詢值由小到大掃描：
 *    - 先把「左端點 <= 目前查詢值」的所有區間都丟進 heap（這些區間
 *      已經涵蓋到查詢值的左界了）。
 *    - 把 heap 頂端「右端點 < 目前查詢值」的區間都彈出丟棄（這些
 *      區間雖然長度小，但已經涵蓋不到目前的查詢值了，之後的查詢值
 *      只會更大，這些區間永遠用不到了，直接丟掉不用留著）。
 *    - 處理完後，heap 頂端（如果還有）就是「涵蓋這個查詢值、長度
 *      最小」的區間，直接讀它的長度當答案。
 * 4. 依照查詢值由小到大處理，可以保證「左端點 <= 查詢值」的區間只需
 *    要單調往前掃一次（不用每次都重新篩選一遍），加上 heap 的頂端
 *    淘汰機制，整體是 O((N+Q) log N)。
 */
class Solution {
public:
    vector<int> minInterval(vector<vector<int>>& intervals, vector<int>& queries) {
        sort(intervals.begin(), intervals.end());
        int q = queries.size();
        vector<int> order(q);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return queries[a] < queries[b];
        });

        vector<int> result(q, -1);
        priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> minHeap;
        int i = 0;
        int n = intervals.size();

        for (int idx : order) {
            int query = queries[idx];
            while (i < n && intervals[i][0] <= query) {
                int len = intervals[i][1] - intervals[i][0] + 1;
                minHeap.push({len, intervals[i][1]});
                i++;
            }
            while (!minHeap.empty() && minHeap.top().second < query) {
                minHeap.pop();
            }
            if (!minHeap.empty()) result[idx] = minHeap.top().first;
        }
        return result;
    }
};
```
