# 3512. Minimum Operations to Make Array Sum Divisible by K

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-operations-to-make-array-sum-divisible-by-k/)

**難度:** 🟢 Easy　**標籤:** Array Linear Scan　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：3512. Minimum Operations to Make Array Sum Divisible by K
 * 難度：簡單 (Easy)
 * 描述：透過減少陣列中的元素值，使總和能被 K 整除，求最小操作次數。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 令 S 為總和。我們需要將總和變為 (S - x)，使得 (S - x) % k == 0。
 * 這等同於 x = S % k。
 */

class Solution {
public:
    int minOperations(vector<int>& nums, int k) {
        int sum =accumulate(nums.begin(), nums.end(), 0);
        return sum % k;
    }
};
```

> 全部加起來除以k取餘數，可以一邊加，一邊取餘數<br>
