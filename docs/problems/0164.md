# 164. Maximum Gap

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-gap/)

## 解法：sorting-implementation

**難度:** 🟡 Medium　**標籤:** Sorting Algorithm Implementation, Bucket Sort, Pigeonhole Principle　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：164. Maximum Gap (最大間距)
 * 難度：困難 (Hard)
 * 描述：給定整數陣列 nums，回傳其排序後相鄰元素之間的最大差值；
 *       若陣列元素少於兩個，回傳 0。
 *
 * 時間複雜度：O(N) - 桶的建立與掃描皆為線性，不需要真正對整個陣列排序。
 * 空間複雜度：O(N) - 需要額外的桶陣列，桶的數量與 N 同量級。
 *
 * 解法思路：
 * 1. 鴿籠原理：決定桶的大小 (Pigeonhole Principle for Bucket Size)：
 *    - 若將 [min, max] 這個範圍平均分成 (N-1) 個桶，
 *      根據鴿籠原理，答案（最大間距）不可能發生在「同一個桶內部」，
 *      因為每個桶的寬度必定小於等於平均間距，所以真正的最大間距只可能出現在「跨桶」之間。
 * 2. 計算桶的大小與數量：
 *    - bucketSize = max(1, (mx - mn) / (n - 1))，用 max 1 避免所有數字相同時桶大小為 0。
 *    - 桶的數量則依據數值範圍與桶大小反推。
 * 3. 只需記錄每個桶的「最小值」與「最大值」：
 *    - 不需要把每個桶內的完整資料都存起來，因為同一桶內的間距不可能是答案，
 *      只需要知道每個桶的邊界值，就足以算出跨桶的間距。
 * 4. 只比較「相鄰非空桶」之間的邊界 (Compare Adjacent Non-Empty Buckets)：
 *    - 依序走訪所有桶，用 prevMax 記錄上一個非空桶的最大值，
 *      跳過空桶，計算目前桶的最小值與 prevMax 的差距，取最大值即為答案。
 * 5. 邊界情況：
 *    - 元素少於 2 個，或所有元素相同（mn == mx），直接回傳 0。
 */
class Solution {
public:
    int maximumGap(vector<int>& nums) {
        int n = nums.size();
        if (n < 2) return 0;

        int mn = *min_element(nums.begin(), nums.end());
        int mx = *max_element(nums.begin(), nums.end());
        if (mn == mx) return 0;

        // 桶的大小：確保「同一個桶內」的最大間距一定小於答案，答案只可能出現在跨桶之間
        int bucketSize = max(1, (mx - mn) / (n - 1));
        int bucketCount = (mx - mn) / bucketSize + 1;

        vector<int> bucketMin(bucketCount, INT_MAX);
        vector<int> bucketMax(bucketCount, INT_MIN);

        for (int num : nums) {
            int idx = (num - mn) / bucketSize;
            bucketMin[idx] = min(bucketMin[idx], num);
            bucketMax[idx] = max(bucketMax[idx], num);
        }

        int maxGap = 0;
        int prevMax = mn;
        for (int i = 0; i < bucketCount; i++) {
            if (bucketMin[i] == INT_MAX) continue;
            maxGap = max(maxGap, bucketMin[i] - prevMax);
            prevMax = bucketMax[i];
        }
        return maxGap;
    }
};
```

## 解法：sorting-radix-sort

```cpp
/**
 * 題目：164. Maximum Gap
 * 難度：困難 (Hard)
 * 分類主題：sorting-radix-sort
 * 描述：給定一個未排序的整數陣列 nums，求排序後相鄰兩個元素之間最大
 * 的差值。如果陣列少於 2 個元素，回傳 0。要求時間複雜度 O(N)、空間
 * 複雜度 O(N)（不能直接用一般 O(N log N) 的比較排序）。
 *
 * 時間複雜度：O(N * D)，D 是最大值的位數（視為常數，因此整體是 O(N)）
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Radix Sort，基數排序：不比較元素大小，而是逐位數字分別排序，
 * 從最低位（個位）排到最高位，是這題能達到 O(N) 而非 O(N log N) 的
 * 關鍵）：
 * 1. **核心概念**：一般排序（快排、合併排序）靠「兩兩比較」，理論
 *    下限是 O(N log N)；基數排序完全不比較大小，而是把數字拆成一位
 *    一位處理，每一位都用「計數排序」（值域固定是 0~9，天生 O(N)）
 *    分桶，只要做的輪數（位數）是常數，整體就能壓到 O(N)。
 * 2. exp 代表目前正在處理「哪一位」的位值（1 = 個位、10 = 十位、
 *    100 = 百位...）。外層迴圈從 exp=1 開始，每輪乘以 10，直到
 *    `maxVal / exp` 變成 0（代表所有位數都處理完了）為止。
 * 3. 每一輪內部是一次**穩定的計數排序**，針對「目前這一位的數字」
 *    （用 `(x / exp) % 10` 取出）：
 *    - 先統計 0~9 每個數字出現幾次。
 *    - 把 count 陣列轉成前綴和，代表「這個數字（或更小）總共有幾個
 *      元素該排在它前面」，這樣才能算出每個元素排序後的正確位置。
 *    - **從右往左**掃描原陣列填進 buffer（這是穩定排序的關鍵：如果
 *      從左往右掃，相同數字的相對順序會被打亂，之後排更高位時，前面
 *      幾輪排好的順序就會失效）。
 * 4. 排到最高位之後，整個陣列就是完全排序好的，最後只要線性掃描
 *    一次相鄰元素的差值，取最大值即可。
 * 5. 這題也有「桶排序」版本的經典解法（利用鴿籠原理證明最大間距一定
 *    >= 桶的寬度，可以跳過桶內排序直接比較跨桶邊界），思路跟基數排序
 *    完全不同，如果你手上的版本是那個，應該歸進 `sorting-bucket-sort`
 *    而不是這裡。
 */
class Solution {
public:
    int maximumGap(vector<int>& nums) {
        int n = nums.size();
        if (n < 2) return 0;

        radixSort(nums);

        int maxGap = 0;
        for (int i = 1; i < n; ++i) {
            maxGap = max(maxGap, nums[i] - nums[i - 1]);
        }
        return maxGap;
    }

private:
    void radixSort(vector<int>& nums) {
        int maxVal = *max_element(nums.begin(), nums.end());
        int n = nums.size();
        vector<int> buffer(n);

        for (int exp = 1; maxVal / exp > 0; exp *= 10) {
            vector<int> count(10, 0);

            for (int x : nums) {
                int digit = (x / exp) % 10;
                count[digit]++;
            }
            for (int d = 1; d < 10; ++d) {
                count[d] += count[d - 1];
            }
            for (int i = n - 1; i >= 0; --i) {
                int digit = (nums[i] / exp) % 10;
                buffer[--count[digit]] = nums[i];
            }
            nums = buffer;
        }
    }
};
```
