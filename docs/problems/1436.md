# 1436. Destination City

[在 LeetCode 上查看](https://leetcode.com/problems/destination-city)

**難度:** 🟢 Easy　**標籤:** String, Hash Table　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：1436. Destination City (旅行終點站)
 * 難度：簡單 (Easy)
 * 描述：給你一系列路徑，找出唯一的終點城市（該城市沒有往外走的路線）。
 *
 * 時間複雜度：O(N) - 兩次線性掃描路徑。
 * 空間複雜度：O(N) - 儲存所有出發城市。
 */

class Solution {
public:
    string destCity(vector<vector<string>>& paths) {
        unordered_map<string, string> s2d;
        for(const vector<string>& path : paths ) {
            s2d[path[0]] = path[1];
        }
        string city = paths[0][0];
        while(s2d.count(city)) {
            city = s2d[city];
        }
        return city;
    }
};
```
