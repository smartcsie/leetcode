# 3345. Smallest Divisible Digit Product I

[在 LeetCode 上查看](https://leetcode.com/problems/smallest-divisible-digit-product-i/)

**難度:** 🟢 Easy　**標籤:** Brute Force, Digit Manipulation　**時間:** O(K × D)　**空間:** O(1)

```cpp
/**
 * 題目：3345. Smallest Divisible Digit Product I
 * 難度：簡單 (Easy)
 * 描述：找出大於等於 n 的最小整數，使其所有數位的乘積可以被 t 整除。
 * 核心概念：
 * - 從 n 開始逐一枚舉候選數。
 * - 對每個候選數拆解各數位並計算乘積。
 * - 檢查乘積是否為 t 的倍數，符合條件即回傳。
 *
 * 時間複雜度：O(K × D) - 從 n 開始枚舉，digit product 檢查整除性。
 * 空間複雜度：O(1) - 僅使用常數空間。
 */
class Solution {
public:
    int smallestNumber(int n, int t) {
        for(int i = n; ; i++) {
            int temp = i;
            int product = 1;
            while(temp > 0) {
                product *= temp % 10;
                temp /= 10;
            }
            if(product % t == 0) return i;
        }
        return -1;
    }
};
```
