# 1653. Minimum Deletions to Make String Balanced

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-deletions-to-make-string-balanced/)

**難度:** 🟡 Medium　**標籤:** Greedy Prefix Suffix　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1653. Minimum Deletions to Make String Balanced
 * 難度：中等 (Medium)
 * 分類主題：greedy-prefix-suffix
 * 描述：給定一個只由 'a'、'b' 組成的字串 s，求最少刪除幾個字元，才能
 * 讓剩下的字串變成「所有 'a' 都排在所有 'b' 前面」（平衡字串）。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （Prefix/Suffix Greedy + 一維 DP 的混合形態，dp 代表「目前為止的
 * 前綴」變平衡所需的最少刪除數，隨掃描即時更新）：
 * 1. 維護兩個變數：dp（讓 s[0..i] 變平衡的最少刪除數）、countB
 *    （目前為止看過的 'b' 數量）。
 * 2. 掃描每個字元：
 *    - 遇到 'b'：這個字元不會破壞「前面都是 a」的平衡性（b 本來就該
 *      在後面），單純把 countB + 1，dp 不用改變。
 *    - 遇到 'a'：這個字元出現在「已經看過一些 b」之後，會破壞平衡
 *      （a 不該出現在 b 後面），要嘛刪掉這個 a（dp + 1），要嘛回頭
 *      刪掉前面所有看過的 b（花費 countB，讓這個 a 前面乾淨），
 *      取兩者較小值更新 dp：`dp = min(dp + 1, countB)`。
 * 3. **為什麼這個轉移是對的**：dp 代表「到目前為止最優的刪除量」，
 *    不需要記錄「刪的到底是哪些字元」，因為 countB 已經隱含了「如果
 *    要讓目前這個 a 合法，最多要付出的代價」，取 min 保證每一步都是
 *    當下最優，而且不會影響未來的判斷（後面的 b 不受影響，後面的 a
 *    只看目前的 dp 值）。
 * 4. 掃描完整個字串，dp 就是答案。
 */
class Solution {
public:
    int minimumDeletions(string s) {
        int dp = 0;
        int countB = 0;
        for (char c : s) {
            if (c == 'b') {
                countB++;
            } else {
                dp = min(dp + 1, countB);
            }
        }
        return dp;
    }
};
```
