# 2826. Sorting Three Groups

[在 LeetCode 上查看](https://leetcode.com/problems/sorting-three-groups/)

**難度:** 🟡 Medium　**標籤:** Dynamic Programming Lis, Longest Non-Decreasing Subsequence　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏　🏆 **最佳解**

```cpp
/**
 * 題目：2826. Sorting Three Groups (三組排序)
 * 難度：中等 (Medium)
 * 描述：陣列 nums 中每個元素值皆為 1、2 或 3，每次操作可以移除一個元素，
 *       求讓剩餘陣列變成不遞減序列所需要的最少操作次數。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 轉化問題：等價於找「最長不遞減子序列」(Equivalent to Longest Non-Decreasing Subsequence)：
 *    - 因為每次操作是「移除」元素，最少移除次數 = 總長度 - 最長保留下來的
 *      不遞減子序列長度；由於數值只會是 1、2、3，這種子序列必定長得像
 *      「一段 1、接一段 2、再接一段 3」（其中某幾段可以是空的）。
 * 2. dp[i] 代表：目前為止，結尾數值不超過 i 的最長不遞減子序列長度：
 *    - dp[1]、dp[2]、dp[3] 分別代表結尾 <= 1、<= 2、<= 3 的最佳長度。
 * 3. 遇到目前數字 num，先直接延伸 dp[num]：
 *    - ++dp[num] 代表「把這個數字接在同樣結尾 <= num 的最佳子序列後面」，
 *      因為數值相同，接上去仍然保持不遞減。
 * 4. 用較小的 dp 值更新較大的 dp 值，維持「範圍越大、長度不會變差」的單調性：
 *    - dp[2] = max(dp[2], dp[1])：結尾 <= 2 的最佳長度，
 *      至少要跟結尾 <= 1 的最佳長度一樣好（因為 <=1 的子序列，結尾也一定 <=2）。
 *    - dp[3] = max(dp[3], dp[2])：同理，結尾 <= 3 的最佳長度，至少要跟結尾 <= 2 的一樣好。
 * 5. 最終答案：
 *    - dp[3] 即為整個陣列可以找到的最長不遞減子序列長度，
 *      答案為 nums.size() - dp[3]（總長度扣掉最長可保留的部分，即為需要移除的數量）。
 */
class Solution {
public:
    int minimumOperations(vector<int>& nums) {
        vector<int> dp(4);
        for (const int num : nums) {
            ++dp[num];
            dp[2] = max(dp[2], dp[1]);
            dp[3] = max(dp[3], dp[2]);
        }
        return nums.size() - dp[3];
    }
};
```
