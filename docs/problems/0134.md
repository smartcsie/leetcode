# 134. Gas Station

[在 LeetCode 上查看](https://leetcode.com/problems/gas-station/)

**難度:** 🟡 Medium　**標籤:** Greedy Fractional Knapsack　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：134. Gas Station
 * 難度：中等 (Medium)
 * 描述：環形路線上有 n 個加油站，gas[i] 是第 i 站能加的油量，cost[i]
 * 是從第 i 站開到下一站要花的油量。求能繞完整個環一圈的起點是哪個
 * （保證解唯一，如果不存在回傳 -1）。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （單趟掃描貪心，利用一個關鍵數學性質，把看似要 O(N²) 窮舉起點的
 * 問題降到 O(N)）：
 * 1. **關鍵性質**：如果從起點 A 出發、油量在某個站 i 變成負的（走不下
 *    去了），那麼 A 到 i 之間的任何一站當起點，也一定走不到 i（因為
 *    中途的油量只會更早見底，不會更晚）。這代表只要發現半路油量見底，
 *    就可以直接把新的起點設成「見底的下一站」，前面所有站都不用再
 *    考慮了。
 * 2. 用 tank 追蹤「假設從目前的 start 出發，走到現在」剩下的油量；
 *    用 total 追蹤「整個環一圈下來，油量總和夠不夠」（這是判斷有沒有
 *    解的依據：只要 total >= 0，一定存在唯一解）。
 * 3. 掃描每一站，累加 gas[i]-cost[i] 到 tank 和 total；如果 tank
 *    變成負的，代表從目前的 start 走不到這裡，把 start 更新成 i+1，
 *    tank 歸零重新算。
 * 4. 掃完整圈後，如果 total >= 0，代表 start 就是答案（一定能繞完
 *    整圈）；否則代表怎麼選起點都不夠油，回傳 -1。
 */
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        int total = 0, tank = 0, start = 0;
        for (int i = 0; i < n; ++i) {
            int diff = gas[i] - cost[i];
            total += diff;
            tank += diff;
            if (tank < 0) {
                start = i + 1;
                tank = 0;
            }
        }
        return total >= 0 ? start : -1;
    }
};
```
