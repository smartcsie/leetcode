# 263. Ugly Number

[在 LeetCode 上查看](https://leetcode.com/problems/ugly-number)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(logN)　**空間:** O(1)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：263. Ugly Number (醜數)
 * 難度：簡單 (Easy)
 * 描述：給你一個整數 n ，請你判斷 n 是否為「醜數」。
 * 醜數就是只包含質因數 2、3 或 5 的正整數。
 *
 * 時間複雜度：O(logN)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 根據定義，醜數必須是正整數，故 n <= 0 直接回傳 false。
 * 2. 依序檢查 2, 3, 5 是否為其因數，如果是就一直除下去。
 * 3. 最後檢查剩下的數字是否為 1。如果是 1，代表原本的所有質因數都在 {2, 3, 5} 集合內。
 */

class Solution {
public:
    bool isUgly(int n) {
        if(n <= 0) return false;
        for (int f : {2, 3, 5}) {
            while (n % f == 0) {
                n /= f;
            }
        }

        return n == 1;
    }
};
```

> 注意邊界條件if(n <= 0) return false;<br>
> n如果可被2整除，n除以2，n如果可被3整除，n除以3，n如果可被5整除，n除以5，最後是否等於1<br>
