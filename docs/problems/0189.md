# 189. Rotate Array

[在 LeetCode 上查看](https://leetcode.com/problems/rotate-array/)

**難度:** 🟡 Medium　**標籤:** Array　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 注意　🏆 **最佳解**

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        std::rotate(nums.begin(), nums.begin() + (nums.size() - k % nums.size()), nums.end());
    }
};
```
