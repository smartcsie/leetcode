# 189. Rotate Array

[在 LeetCode 上查看](https://leetcode.com/problems/rotate-array/)

**難度:** 🟡 Medium　**標籤:** Array　**時間:** O(N)　**空間:** O(1)

```cpp
/**
 * 題目：待補充
 * 難度：待補充
 * 描述：待補充
 *
 * 時間複雜度：O(N) - 遍歷半個陣列，進行 n/2 次交換。 O(N) - 三次 reverse，in-place 旋轉。
 * 空間複雜度：O(1) - 僅使用兩個整數變數作為指標，原地修改。 O(1) - 不使用額外陣列。
 *
 * 解法思路：
 * 雙指標法 (Two Pointers)
 * 1. 使用兩個指標：left 指向字串開頭，right 指向字串結尾。
 * 2. 當 left < right 時，交換兩個指標所指向的字元。
 * 3. 交換後，將 left 向右移動，right 向左移動，直到兩者相遇或交錯。
 * 這種方法不需要額外的空間來儲存字串，直接在原有的 vector 上進行操作。
 */

class Solution {
public:
    void reverseString(vector<char>& s) {
        int i = 0;
        int j = s.size() - 1;
        while( i <= j) {
            swap(s[i++], s[j--]);
        }
    }
};
```
