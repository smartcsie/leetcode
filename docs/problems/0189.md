# 189. Rotate Array

[在 LeetCode 上查看](https://leetcode.com/problems/rotate-array/)

**難度:** 🟡 Medium　**標籤:** Array　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習　🏆 **最佳解**

**技巧:** rotate

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        k %= nums.size();
        reverse(nums.begin(), nums.end());
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());
    }
};
```
