# 526. Beautiful Arrangement

[在 LeetCode 上查看](https://leetcode.com/problems/beautiful-arrangement/)

**難度:** 🟡 Medium　**標籤:** Backtracking Permutation　**時間:** O(K)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：526. Beautiful Arrangement
 * 難度：中等 (Medium)
 * 描述：給定整數 n，把 1 到 n 排成一個排列 perm，使得對每個位置 i
 * （1-indexed），perm[i] 能被 i 整除、或 i 能被 perm[i] 整除。求總共
 * 有幾種這樣的排列。
 *
 * 時間複雜度：O(K)
 * 條件剪掉大部分分支）
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Permutation 回溯，跟 46. Permutations 是同一個框架——逐個位置
 * 決定要放哪個還沒用過的數字——只是這題多了「整除關係」的合法性
 * 檢查，讓很多分支提早被剪掉）：
 * 1. backtrack(pos) 代表「目前要決定位置 pos（1-indexed）該放哪個
 *    數字」。
 * 2. 枚舉每個還沒用過的數字 num（1 到 n），檢查是否滿足
 *    `num % pos == 0 || pos % num == 0`，滿足才嘗試放進這個位置：
 *    標記 used[num] = true，遞迴處理下一個位置 backtrack(pos+1)，
 *    回溯時記得恢復 used[num] = false。
 * 3. base case：pos > n，代表 1 到 n 每個位置都排好了，找到一組合法
 *    排列，count++。
 * 4. 這題不需要保留完整的排列陣列（因為只是計數，不用回傳實際排列
 *    內容），只需要 used 陣列追蹤哪些數字用過，比一般排列題更精簡。
 */
class Solution {
    int n;
    int count = 0;
    vector<bool> used;

    void backtrack(int pos) {
        if (pos > n) {
            count++;
            return;
        }
        for (int num = 1; num <= n; ++num) {
            if (used[num]) continue;
            if (num % pos == 0 || pos % num == 0) {
                used[num] = true;
                backtrack(pos + 1);
                used[num] = false;
            }
        }
    }

public:
    int countArrangement(int n_) {
        n = n_;
        used.assign(n + 1, false);
        backtrack(1);
        return count;
    }
};
```
