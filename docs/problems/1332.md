# 1332. Remove Palindromic Subsequences

[在 LeetCode 上查看](https://leetcode.com/problems/remove-palindromic-subsequences/)

**難度:** 🟢 Easy　**標籤:** Two Pointers Opposite　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：1332. Remove Palindromic Subsequences
 * 難度：簡單 (Easy)
 * 描述：給定一個只由字元 'a' 和 'b' 組成的字串 s，每次操作可以移除 s 的
 * 一個回文子序列（subsequence，不需連續），求把整個字串清空所需的最少
 * 操作次數。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （雙指標判斷回文 + 觀察字元種類只有兩種）：
 * 1. 特殊情況：空字串：
 * - 如果 s 本身是空字串，代表不需要任何操作即可清空，直接回傳 0。
 * 2. 用雙指標判斷 s 是否本身就是回文：
 * - left 從頭、right 從尾同時往中間夾，只要有任一組字元不相等，
 *   就代表 s 不是回文，直接回傳 2。
 * 3. 關鍵觀察（為什麼答案只會是 1 或 2）：
 * - 字串只由 'a'、'b' 兩種字元組成：如果 s 本身就是回文，一次操作
 *   直接整串移除即可，答案是 1；如果不是回文，最多也只需要兩步——
 *   先把所有 'a' 當成一個回文子序列移除（"aaa...a" 一定是回文），
 *   再把剩下的所有 'b' 當成另一個回文子序列移除，答案是 2。
 * - 因此完全不需要動態規劃或複雜的回文分割演算法，只要判斷「s 是否
 *   本身就是回文」這一件事就能決定答案是 1 還是 2。
 */
class Solution {
public:
    int removePalindromeSub(string s) {
        if(s.size() == 0) return 0;
        int left = 0;
        int right = s.size() - 1;
        while(left < right) {
            if(s[left++] != s[right--]) return 2;
        }
        return 1;
    }
};
```
