# 1608. Special Array With X Elements Greater Than or Equal X

**難度:** 🟢 Easy　**標籤:** Array Linear Scan　**時間:** O(N + V)　**空間:** O(V)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：1608. Special Array With X Elements Greater Than or Equal X
 * 難度：簡單 (Easy)
 * 描述：給定非負整數陣列 nums。若存在一個數字 x，使得 nums 中
 *       恰好有 x 個元素大於或等於 x，則 nums 是特殊陣列，回傳該 x；
 *       否則回傳 -1。題目保證若 x 存在則唯一，且 x 不必出現在 nums 裡。
 *
 * 分類主題：array-suffix-sum
 * 技巧：計數陣列, 後綴和, 值域固定用 array
 *
 * 時間複雜度：O(N + V)，V = 1000 為值域上界
 * 空間複雜度：O(V)
 *
 * 解法思路：計數 + 後綴和
 * 1. 值域只有 0 ~ 1000，先用 counts[v] 統計每個值出現幾次。
 * 2. 把 counts 轉成後綴和：counts[i] += counts[i + 1]，
 *    轉完後 counts[i] 就是「nums 中大於或等於 i 的元素個數」。
 * 3. 從 0 到 1000 掃描，第一個滿足 counts[i] == i 的 i 就是答案；
 *    都不滿足則回傳 -1。
 * 4. x = 0 不會成立：nums 至少有 1 個元素，counts[0] = n >= 1，
 *    所以不需要特判。
 */
class Solution {
public:
    int specialArray(vector<int>& nums) {
        array<int, 1001> counts = {};  // counts[v]：值為 v 的元素個數，之後轉成後綴和

        // 統計每個值出現的次數
        for (const int& x : nums) counts[x]++;

        // 轉成後綴和：counts[i] = 大於或等於 i 的元素個數
        // counts[1000] 本身已是後綴和，所以從 999 開始往前累加
        for (int i = 999; i >= 0; i--) counts[i] += counts[i + 1];

        // 找到「恰好有 i 個元素大於或等於 i」的 i
        for (int i = 0; i <= 1000; i++) {
            if (counts[i] == i) return i;
        }
        return -1;
    }
};
```

## 解法：binary-search-on-answer

**難度:** 🟢 Easy　**標籤:** Binary Search On Answer　**時間:** O(N²)　**空間:** O(1)　**熟悉度:** 🔴 生疏

**📅 練習歷程:**

- ✅ **2026-10-16** 對

```cpp
/**
 * 題目：1608. Special Array With X Elements Greater Than or Equal X
 * 難度：簡單 (Easy)
 * 描述：找出 x 使得陣列中恰好有 x 個元素大於或等於 x。
 *
 * 時間複雜度：O(NlogN)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （排序 + Binary Search）：
 * 排序後對 x 做二分搜尋，用 lower_bound 計算大於等於 x 的元素數量是否等於 x。
 */
class Solution {
public:
    int specialArray(vector<int>& nums) {
        // 1. 先排序，這樣後面才能用 std::lower_bound 快速找出大於等於某數的數量
        ranges::sort(nums);
        int n = nums.size();
        
        // 2. 對可能的答案 x 進行二分搜尋
        // x 的可能範圍是 0 到 n
        int left = 0, right = n;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            // 計算 nums 中「大於或等於 mid」的元素個數
            // lower_bound 會回傳第一個「大於或等於 mid」的位置
            auto it = ranges::lower_bound(nums, mid);
            int count = nums.end() - it; // 剩餘的元素個數就是大於等於 mid 的數量
            
            if (count == mid) {
                return mid; // 找到符合條件的 X！
            } else if (count > mid) {
                left = mid + 1; // 數量太多了，試試看更大的 x
            } else {
                right = mid - 1; // 數量太少了，試試看更小的 x
            }
        }
        
        return -1; // 找不到
    }
};
```
