# 1288. Remove Covered Intervals

[在 LeetCode 上查看](https://leetcode.com/problems/remove-covered_intervals/)

**難度:** 🟡 Medium　**標籤:** Sorting, Greedy　**時間:** O(NlogN)　**空間:** O(logN)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1288. Remove Covered Intervals
 * 難度：待補充
 * 描述：給你一個區間列表，請你刪除列表中被其他區間所完全覆蓋的區間。
 * 如果區間 [c, d] 被區間 [a, b] 覆蓋，當且僅當 a <= c 且 d <= b。
 * 請返回最後剩下的不被覆蓋的區間數量。
 *
 * 時間複雜度：O(NlogN)
 * 空間複雜度：O(logN)
 *
 * 解法思路：
 * （排序與貪心策略）：
 * 1. 自定義排序規則：
 * - 先依照區間的起點由小到大排序（`a[0] < b[0]`）。
 * - 如果起點相同，則依照區間的終點由大到小排序（`a[1] > b[1]`）。
 * 2. 貪心掃描與覆蓋判定：
 * - 經過上述排序後，我們只需維護一個記錄當前最大終點的變數 `prevEnd`。
 * - 當我們遍歷到一個新區間 `v` 時，如果 `prevEnd < v[1]`，代表這個區間的終點延伸得比之前任何一個區間都遠，
 * 因此它**沒有**被前面的區間完全覆蓋，我們將其計入答案，並更新 `prevEnd = v[1]`。
 * - 反之，如果 `prevEnd >= v[1]`，代表這個區間的終點被包在之前的區間之內（因為起點已經大於或等於前一個區間了），
 * 故它會被完全覆蓋，直接跳過。
 */

class Solution {
public:
    int removeCoveredIntervals(std::vector<std::vector<int>>& intervals) {
        // 自定義排序：起點升冪；若起點相同，終點降冪
        std::sort(intervals.begin(), intervals.end(), [](const std::vector<int>& a, const std::vector<int>& b) {
            if (a[0] == b[0]) return a[1] > b[1];
            return a[0] < b[0];
        });
        int prevEnd = 0;
        int ans = 0;
        for (const std::vector<int>& v : intervals) {
            // 若當前區間的終點大於記錄的 prevEnd，代表未被覆蓋
            if (prevEnd < v[1]) {
                prevEnd = v[1];
                ans++;
            }
        }
        return ans;
    }
};
```
