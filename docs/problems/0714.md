# 714. Best Time to Buy and Sell Stock with Transaction Fee

[在 LeetCode 上查看](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/)

**難度:** 🟡 Medium　**標籤:** Dp State Machine　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：714. Best Time to Buy and Sell Stock with Transaction Fee
 * 難度：中等 (Medium)
 * 描述：給定每天的股價 prices 和一筆固定手續費 fee，可以進行無限次
 * 交易，每次交易（一買一賣算一次）要付一次手續費，求最大總利潤。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （State Machine DP，跟 122 幾乎一樣的框架，只是賣出時要扣手續費）：
 * 1. cash：手上沒股票的最大利潤，hold：手上持有股票的最大利潤，跟
 *    122 定義完全相同。
 * 2. 狀態轉移唯一的差別：賣出時（cash 的轉移）要扣掉 fee：
 *    cash = max(cash, hold + price - fee)
 *    hold = max(hold, cash - price)
 * 3. 初始化要特別注意：不能像 122 一樣把 hold 設成 INT_MIN，因為這題
 *    转移時有 `- fee`，如果第一天股價很低、fee 又比較大，
 *    `INT_MIN + price - fee` 會整數下溢（overflow 變成一個超大的正
 *    數，導致答案完全錯誤）。改成用第一天的股價初始化
 *    hold = -prices[0]，迴圈從第二天開始跑，安全地避開這個邊界問題。
 * 4. 答案是最後一天的 cash。
 */
class Solution {
public:
    int maxProfit(vector<int>& prices, int fee) {
        int n = prices.size();
        int cash = 0, hold = -prices[0];
        for (int i = 1; i < n; ++i) {
            int newCash = max(cash, hold + prices[i] - fee);
            int newHold = max(hold, cash - prices[i]);
            cash = newCash;
            hold = newHold;
        }
        return cash;
    }
};
```
