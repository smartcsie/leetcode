# 2006. Count Number of Pairs With Absolute Difference K

[在 LeetCode 上查看](https://leetcode.com/problems/count-number-of-pairs-with-absolute-difference-k/)

**難度:** 🟢 Easy　**標籤:** Array Linear Scan, Hash Table, Frequency Map　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟢 熟練

```cpp
class Solution {
public:
    int countKDifference(vector<int>& nums, int k) {
        int n = nums.size();
        int ans = 0;
        for(int i = 0; i < n; i++) {
            for(int j = i + 1; j < n; j++) {
                if(abs(nums[i] - nums[j]) == k) ans++;
            }
        }
        return ans;
    }
};
```
