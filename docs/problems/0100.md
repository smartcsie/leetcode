# 100. Same Tree

[在 LeetCode 上查看](https://leetcode.com/problems/same-tree/)

**難度:** 🟢 Easy　**標籤:** Tree　**時間:** O(N)　**空間:** O(H)　**熟悉度:** 🟢 熟練　🏆 **最佳解**

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if(p == q) return true;
        if(!p || !q || p->val != q->val) return false;
        return isSameTree(p->left , q->left) && isSameTree(p->right , q->right);
    }
};
```

> [Same Tree](https://leetcode.com/problems/same-tree/) <br>
> 如果p q 都為空，回傳true，只有p或只有或兩個val不相等，回傳false，最後return isSameTree(p左子樹和q左子樹) 且 isSameTree(p右子樹和q右子樹)<br>
