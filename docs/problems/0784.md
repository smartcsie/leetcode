# 784. Letter Case Permutation

[在 LeetCode 上查看](https://leetcode.com/problems/letter-case-permutation/)

**難度:** 🟡 Medium　**標籤:** Backtracking　**時間:** O(2ᴺ)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：784. Letter Case Permutation
 * 難度：中等 (Medium)
 * 描述：透過改變字母大小寫，找出所有可能的組合。
 * 優化重點：
 * 1. 預分配空間：透過計算字母數量預先 reserve 結果容器，減少記憶體重分配。
 * 2. 減少函式呼叫：透過位元運算優化大小寫轉換 (僅限 ASCII 字母)。
 *
 * 時間複雜度：O(2^N) - 每個字母位置有大小寫兩種選擇。
 * 空間複雜度：O(N) - 遞迴深度與當前字串各佔 O(N)。
 */

class Solution {
private:
    void backtrack(string& s, int index, vector<string>& res) {
        while (index < s.size() && isdigit(s[index])) {
            index++;
        }
        if(index == s.size()) {
            res.push_back(s);
            return;
        }
        s[index] = tolower(s[index]);
        backtrack(s, index + 1, res);
        s[index] = toupper(s[index]);
        backtrack(s, index + 1, res);
    } 
public:
    vector<string> letterCasePermutation(string s) {
        vector<string> res;
        backtrack(s, 0, res);
        return res;
    }
};
```

> [Letter Case Permutation](https://leetcode.com/problems/letter-case-permutation/) <br>
> index從開始傳進backtrack，因為只要處理大小寫，index先跳過不是大小寫，while (index < s.size() && isdigit(s[index])) index++<br>
> 終止遞迴條件， if(index == s.size()) { res.push_back(s); return;}<br>
> index目標字元轉lowercase遞迴， s[index] = tolower(s[index]); backtrack(s, index + 1, res);<br>
> index目標字元轉uppercase遞迴， s[index] = toupper(s[index]); backtrack(s, index + 1, res);<br>
