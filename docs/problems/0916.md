# 916. Word Subsets

[在 LeetCode 上查看](https://leetcode.com/problems/word-subsets/)

**難度:** 🟡 Medium　**標籤:** Hash Table Counting, Hash Table, Counting　**時間:** O(N * L)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：916. Word Subsets (單字子集)
 * 難度：中等 (Medium)
 * 描述：給定兩個字串陣列 words1、words2，若 words1 中的某個單字，對於 words2 中
 *       每一個單字都是「通用的」（即該單字包含 words2 中每個單字所需的每個字母，
 *       且數量足夠），則稱該單字為通用單字。回傳 words1 中所有通用單字。
 *
 * 時間複雜度：O(N * L) - N 為 words1 與 words2 的總單字數，L 為單字平均長度，
 *             整體只需線性掃描所有字元一次。
 * 空間複雜度：O(1) - 只使用固定大小 26 的計數陣列，不隨輸入規模成長。
 *
 * 解法思路：
 * 1. 把 words2 的所有要求，合併成單一份「最低需求表」(Merge Requirements)：
 *    - 對 words2 中每個單字，統計各字母出現次數；同一個字母在不同單字中，
 *      只需要取「最大值」即可代表 words1 的單字必須至少擁有的數量
 *      （因為每個 words2 單字的要求是獨立檢查，不會疊加）。
 * 2. 用 temp 陣列統計單一單字的字母次數，freqs 陣列取所有單字的最大值：
 *    - 這樣就能把「必須同時滿足 words2 裡每一個單字的要求」，
 *      簡化成「只需要滿足一份合併後的最低需求表」。
 * 3. 對 words1 的每個單字，統計字母次數並逐一比對需求表：
 *    - 若合併需求表中某個字母的需求量大於 0，但目前單字擁有的數量不足，
 *      代表這個單字不是通用單字，標記為不合格並提前跳出檢查。
 * 4. 收集所有通過檢查的單字：
 *    - 只要通過合併需求表的檢查，就代表對 words2 中每一個單字都同時滿足了要求，
 *      將該單字加入答案陣列。
 */
class Solution {
public:
    vector<string> wordSubsets(vector<string>& words1, vector<string>& words2) {
        vector<int> freqs(26);
        for(const string& word : words2) {
            vector<int>  temp(26);
            for(const char& c : word) {
                temp[c - 'a']++;
                freqs[c - 'a']= max(freqs[c - 'a'], temp[c - 'a']);
            }
        }

        vector<string> ans;
        for(const string& word : words1) {
            bool isSub= true;
            vector<int> freqs1(26);
            for(const char& c : word) freqs1[c - 'a']++;
            for(int i = 0; i < freqs.size(); i++) {
                if(freqs[i] > 0 && freqs1[i] < freqs[i]) {
                    isSub = false;
                    break;
                }
            }
            if(isSub) ans.push_back(word);
        }
        return ans;
    }
};
```
