# 66. Plus One

[在 LeetCode 上查看](https://leetcode.com/problems/plus-one/)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟡 注意

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int carry = 0;
        for(int i = digits.size() - 1; i >= 0; i--) {
            if(i == digits.size() - 1) carry += 1;
            carry += digits[i];
            digits[i] = carry % 10;
            carry /= 10;
            if(carry == 0) break;
        }
        if(carry == 1) digits.insert(digits.begin(), 1);
        return digits;
    }
};
```
