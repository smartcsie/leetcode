# 3884. First Matching Character From Both Ends

[在 LeetCode 上查看](https://leetcode.com/problems/first-matching-character-from-both-ends/description/)

**難度:** 🟢 Easy　**標籤:** Two-Pointers　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：3884. First Matching Character From Both Ends
 * 難度：簡單 (Easy)
 * 描述：在字串中找到第一個左右指標指向相同字元的索引位置。
 * 優化重點：
 * 1. 雙指標法 (Two-pointers)：同時從頭 (left) 與尾 (right) 進行檢查，將複雜度壓縮至單次遍歷。
 * 2. 提前中斷：一旦找到符合條件的字元，立即返回結果，達到最佳效能。
 *
 * 時間複雜度：O(N) - 對撞指針，找第一對相同字元。
 * 空間複雜度：O(1) - 僅使用兩個指針。
 */


class Solution {
public:
    int firstMatchingIndex(std::string s) {
        int left = 0;
        int right = s.size() - 1;
        
        // 雙指標向中間收斂
        while (left <= right) {
            // 如果兩端字元相等，返回左側指標位置
            if (s[left] == s[right]) {
                return left;
            }
            left++;
            right--;
        }
        
        // 若遍歷完成仍無匹配，返回 -1
        return -1;
    }
};
```
