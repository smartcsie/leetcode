# 1678. Goal Parser Interpretation

[在 LeetCode 上查看](https://leetcode.com/problems/goal-parser-interpretation/)

**難度:** 🟢 Easy　**標籤:** String, Parsing　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🔴 生疏　🏆 **最佳解**

```cpp
/**
 * 題目：1678. Goal Parser Interpretation (Goal 解析器的意料之外)
 * 難度：簡單 (Easy)
 * 描述：給定字串 command，僅由 "G"、"()"、"(al)" 這三種片段組成。將 "G" 解釋為
 *       "G"、"()" 解釋為 "o"、"(al)" 解釋為 "al"，回傳解析後串接而成的字串。
 *
 * 時間複雜度：O(N) - 只需對 command 進行一次線性掃描。
 * 空間複雜度：O(N) - 輸出字串的長度與輸入規模同量級。
 *
 * 解法思路：
 * 1. 逐一辨識三種固定片段 (Identify Three Fixed Tokens)：
 *    - 因為題目保證 command 只由這三種固定片段組成，
 *      不需要複雜的解析邏輯，只要看目前位置的字元，就能判斷出是哪一種片段。
 * 2. 遇到 'G' 直接對應輸出 (Direct Match for 'G')：
 *    - 若目前字元是 'G'，代表這個片段長度為 1，直接輸出 'G'，索引前進 1。
 * 3. 用下一個字元區分 "()" 和 "(al)" (Disambiguate by Next Character)：
 *    - 若目前字元不是 'G'，必定是 '('，此時只需看緊接著的下一個字元：
 *      若是 ')'，代表是長度為 2 的 "()"，輸出 'o'，索引前進 2；
 *      否則必定是長度為 4 的 "(al)"，輸出 "al"，索引前進 4。
 * 4. 為何存取 command[i+1] 是安全的：
 *    - 因為只要目前字元不是 'G'，就必定是某個完整片段（"()" 或 "(al)"）的開頭 '('，
 *      而這兩種片段長度都至少為 2，所以 command[i+1] 必定存在，不會超出字串範圍。
 */
class Solution {
public:
    string interpret(string command) {
        string ans;
        for (int i = 0; i < command.size(); ) {
            if (command[i] == 'G') ans += 'G', ++i;
            else if (command[i + 1] == ')') ans += 'o', i += 2;
            else ans += "al", i += 4;
        }
        return ans;
    }
};
```
