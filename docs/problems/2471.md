# 2471. Minimum Number of Operations to Sort a Binary Tree by Level

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-number-of-operations-to-sort-a-binary-tree-by-level/)

**難度:** 🟡 Medium　**標籤:** Sorting Cycle Decomposition　**時間:** O(N log N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：2471. Minimum Number of Operations to Sort a Binary Tree by Level
 * 難度：中等 (Medium)
 * 分類主題：sorting-cycle-decomposition
 * 描述：給定一棵二元樹，每次操作可以交換「同一層」任兩個節點的值。
 * 求讓每一層都變成嚴格遞增排列，所需的最少操作次數（每層獨立計算，
 * 加總就是答案）。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （直接把 3551 的環分解技巧，逐層套用在 BFS 走訪出來的每一層陣列
 * 上，是這個技巧的「重複應用」範例）：
 * 1. 用標準 BFS 逐層走訪這棵樹，把每一層的節點值收集成一個陣列
 *    level（跟 102 題的層序走訪框架完全相同）。
 * 2. 對每個 level 陣列，套用標準的「最少交換次數排序」演算法
 *    （環分解）：
 *    - 先算出「排序後，每個位置該放原本哪個索引的值」（idx 陣列，
 *      依值大小排序後的索引順序）。
 *    - 從頭掃描每個位置 i：如果 idx[i] == i（代表這個位置的值已經
 *      在正確位置上）或已經走訪過，跳過；否則沿著 idx 走一圈，數出
 *      這個環的長度 cycleSize，貢獻 `cycleSize - 1` 次交換到這一層
 *      的答案。
 * 3. 把每一層算出來的交換次數累加，就是整棵樹的答案。
 * 4. 這題示範了同一個核心技巧（環分解）可以重複套用在「多個獨立的
 *    子問題」上（這裡的子問題是「樹的每一層」），不是只能用一次；
 *    只要問題能拆解成互不影響的小段，各自跑一次環分解、答案加總
 *    即可。
 */
class Solution {
    long long minSwapsToSort(vector<int>& arr) {
        int n = arr.size();
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(), [&](int a, int b) { return arr[a] < arr[b]; });

        vector<bool> visited(n, false);
        long long swaps = 0;
        for (int i = 0; i < n; ++i) {
            if (visited[i] || idx[i] == i) continue;
            int cycleSize = 0;
            int j = i;
            while (!visited[j]) {
                visited[j] = true;
                j = idx[j];
                cycleSize++;
            }
            swaps += cycleSize - 1;
        }
        return swaps;
    }

public:
    int minimumOperations(TreeNode* root) {
        long long total = 0;
        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            int size = q.size();
            vector<int> level;
            for (int i = 0; i < size; ++i) {
                TreeNode* node = q.front(); q.pop();
                level.push_back(node->val);
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            total += minSwapsToSort(level);
        }
        return (int)total;
    }
};
```
