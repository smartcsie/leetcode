# 102. Binary Tree Level Order Traversal

[在 LeetCode 上查看](https://leetcode.com/problems/binary-tree-level-order-traversal/)

**難度:** 🟡 Medium　**標籤:** Tree, BFS　**時間:** O(N)　**空間:** O(W)　**熟悉度:** 🟢 熟練　🏆 **最佳解**

```cpp
/**
 * 題目：102. Binary Tree Level Order Traversal
 * 難度：中等 (Medium)
 * 描述：以層序（BFS）遍歷二元樹，回傳每層節點值組成的二維陣列。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(W)
 *
 * 解法思路：
 * （BFS + Queue）：
 * 用 queue 做層序遍歷，每次處理完整的一層，把該層所有節點值收集後加入結果。
 **/
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if(root == nullptr) return {};
        vector<vector<int>> res;
        queue<TreeNode*> q({root});
        while(!q.empty()) {
            vector<int> level;
            for(int i=q.size(); i > 0; i--) {
                TreeNode* node = q.front();
                q.pop();
                level.push_back(node->val);
                if(node->left) q.push(node->left);
                if(node->right) q.push(node->right);
            }
            res.push_back(level);
        }
        return res;
    }
};
```
