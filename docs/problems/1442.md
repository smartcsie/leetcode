# 1442. Count Triplets That Can Form Two Arrays of Equal XOR

[在 LeetCode 上查看](https://leetcode.com/problems/count-triplets-that-can-form-two-arrays-of-equal-xor/)

**難度:** 🟡 Medium　**標籤:** Bit Manipulation Xor, Prefix XOR　**時間:** O(N²)　**空間:** O(1)

```cpp
/**
 * 題目：1442. Count Triplets That Can Form Two Arrays of Equal XOR (形成兩個異或相等陣列的三元組數目)
 * 難度：中等 (Medium)
 * 描述：給定整數陣列 arr，統計滿足 0 <= i < j <= k < arr.length 的三元組 (i, j, k) 數量，
 *       使得 arr[i] XOR arr[i+1] XOR ... XOR arr[j-1] 等於 arr[j] XOR arr[j+1] XOR ... XOR arr[k]。
 *
 * 時間複雜度：O(N²) - 雙層迴圈窮舉所有 (i, k) 區間組合，內層邊算 XOR 邊判斷。
 * 空間複雜度：O(1) - 只使用常數個變數（postfix, ans），不需額外配置記憶體。
 *
 * 解法思路：
 * 1. 關鍵數學性質：前後段 XOR 相等 ⟺ 整段 XOR 為 0 (Key XOR Property)：
 *    - 若前段 [i, j-1] 的 XOR 等於後段 [j, k] 的 XOR，將兩者做 XOR 會互相抵消為 0，
 *      因此「前段 XOR = 後段 XOR」的條件，等價於「整段 [i, k] 的 XOR = 0」。
 * 2. 轉化為窮舉區間 [i, k] 並檢查整段 XOR (Reduce to Range XOR Check)：
 *    - 外層迴圈固定左端點 i，內層迴圈把右端點 j（代表 k）往右擴展，
 *      同時累積 postfix 為 arr[i] 到 arr[j] 的 XOR 結果。
 * 3. 一旦整段 XOR 為 0，計算合法切割點數量 (Count Valid Split Points)：
 *    - 當 postfix == 0（代表區間 [i, j] 整段 XOR 為 0）時，
 *      中間的切割點 m 可以是 (i, j] 範圍內的任意整數，共有 (j - i) 種選擇，
 *      每種切割方式都對應一組合法的三元組 (i, m, j)，因此將 (j - i) 累加進 ans。
 */
class Solution {
public:
    int countTriplets(vector<int>& arr) {
        int n =  arr.size();
        if(n < 2) return 0;
        int ans= 0;
        for(int i = 0; i < n; i++) {
            int postfix = arr[i];
            for(int j = i + 1; j < n; j++) {
                postfix ^= arr[j];
                if(postfix == 0) ans += j - i;
            }
        }
        return ans;
    }
};
```
