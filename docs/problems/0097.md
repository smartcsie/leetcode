# 97. Interleaving String

[在 LeetCode 上查看](https://leetcode.com/problems/interleaving-string/)

**難度:** 🟡 Medium　**標籤:** Dynamic Programming Lcs, Two Strings　**時間:** O(M * N)　**空間:** O(M * N)　**熟悉度:** 🔴 生疏　🏆 **最佳解**

```cpp
/**
 * 題目：97. Interleaving String (交錯字串)
 * 難度：中等 (Medium)
 * 描述：給定三個字串 s1、s2、s3，判斷 s3 是否可以由 s1 與 s2 交錯組成
 *       （交錯保持各自原本內部的相對順序，但可以互相穿插）。
 *
 * 時間複雜度：O(M * N) - M、N 分別為 s1、s2 的長度，需要填滿整個 (M+1) x (N+1) 的 dp 表格。
 * 空間複雜度：O(M * N) - 使用二維陣列 dp 儲存每個子問題的結果。
 *
 * 解法思路：
 * 1. 長度檢查提前排除 (Length Check Early Exit)：
 *    - 若 s1 與 s2 的長度總和不等於 s3 的長度，不可能交錯組成，直接回傳 false。
 * 2. 定義狀態：dp[i][j] 代表 s1 前 i 個字元與 s2 前 j 個字元，能否交錯組成 s3 前 (i+j) 個字元：
 *    - dp[0][0] = true（兩個空字串交錯組成空字串，天然成立）。
 * 3. 狀態轉移：來自 s1 或來自 s2 兩種可能 (Two Transition Sources)：
 *    - fromS1：若 s1 的第 i 個字元（索引 i-1）等於 s3 對應位置的字元，
 *      且扣掉這個字元後的子問題 dp[i-1][j] 成立，則這條路徑可行。
 *    - fromS2：同理，若 s2 的第 j 個字元等於 s3 對應位置的字元，
 *      且 dp[i][j-1] 成立，則這條路徑也可行。
 * 4. 只要其中一條路徑可行即可：
 *    - dp[i][j] = fromS1 || fromS2，只要有任何一種交錯方式能走到這個狀態就成立。
 * 5. 最終答案：
 *    - dp[m][n] 即代表整個 s1、s2 是否能交錯組成完整的 s3。
 */
class Solution {
public:
    bool isInterleave(string s1, string s2, string s3) {
        int m = s1.size();
        int n = s2.size();
        if(m + n != s3.size()) return false;
        vector<vector<bool>> dp(m + 1 , vector<bool>(n + 1, false));
        dp[0][0] = true;
        for(int i = 0 ; i <= m; i++) {
            for(int j = 0 ; j <= n; j++) {
                if(i == 0 && j == 0) continue;
                bool fromS1 = (i > 0 && s1[i - 1] == s3[i + j- 1] && dp[i - 1][j]);
                bool fromS2 = (j > 0 && s2[j - 1] == s3[i + j- 1] && dp[i][j - 1]);
                dp[i][j] = fromS1 || fromS2;
            }
        }
        return dp[m][n];
    }
};
```
