# 2645. Minimum Additions to Make Valid String

[在 LeetCode 上查看](https://leetcode.com/problems/minimum-additions-to-make-valid-string/)

**難度:** 🟡 Medium　**標籤:** Greedy, Simulation　**時間:** O(N)　**空間:** O(1)

```cpp
/**
 * 題目：2645. Minimum Additions to Make Valid String
 * 難度：待補充
 * 描述：給你一個字串 word，你可以隨時隨地插入 'a'、'b' 或 'c'。
 * 請返回使 word 變成「由多個 "abc" 連接而成的合法字串」所需的最小插入次數。
 *
 * 時間複雜度：O(N) - 單次遍歷，貪婪匹配 abc 模式。
 * 空間複雜度：O(1) - 僅使用常數空間。
 *
 * 解法思路：
 * （貪心與區塊計數模擬）：
 * 1. 週期性匹配（"abc" 循環）：
 * - 合法字串的形式為 "abcabcabc..."，其字元順序固定為 'a' -> 'b' -> 'c'。
 * 2. 區塊貪心策略：
 * - 我們以每一輪「完整或部分的 abc 循環」作為一個區塊。
 * - 在每一輪迴圈中，我們盡可能連續匹配字串中的 'a'、'b'、'c'。
 * - 實際抓到的字元數量記為 `count`（最多 3 個）。
 * - 該輪所需要補上的字元數量即為 `(3 - count)`，並將其累積到總答案 `ans` 中。
 */

class Solution {
public:
    int addMinimum(std::string word) {
        int ans = 0;
        int n = word.size();
        // 每次嘗試匹配一輪完整的 "abc" 循環
        for (int i = 0; i < n; ) {
            int count = 0; // 記錄當前輪次實際匹配到了幾個字母
            if (i < n && word[i] == 'a') {
                count++;
                i++;
            } 
            if (i < n && word[i] == 'b') {
                count++;
                i++;
            } 
            if (i < n && word[i] == 'c') {
                count++;
                i++;
            }
            // 每一輪標準長度為 3，缺幾個就補幾個 (3 - count)
            ans += (3 - count);
        }
        return ans;
    }
};
```
