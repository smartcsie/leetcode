# 2148. Count Elements With Strictly Smaller and Greater Elements

[在 LeetCode 上查看](https://leetcode.com/problems/count-elements-with-strictly-smaller-and-greater-elements/)

**難度:** 🟢 Easy　**標籤:** Array, Sorting　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2148. Count Elements With Strictly Smaller and Greater Elements
 * 難度：簡單 (Easy)
 * 描述：計算陣列中嚴格小於最大值且嚴格大於最小值的元素個數。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 邏輯簡化：透過總長度扣除極值個數，避免複雜的判斷式。
 * 2. 防禦性：若最大值與最小值相同（所有元素相等），應回傳 0。
 */

class Solution {
public:
    int countElements(vector<int>& nums) {
        auto [minIt, maxIt] = minmax_element(nums.begin(), nums.end());
        int mn = *minIt;
        int mx = *maxIt;
        int ans = 0;
        for(const int& x : nums) {
            if(x != mn && x !=mx) ans++;
        }
        return ans;
    }
};
```
