# 2839. Check if Strings Can be Made Equal With Operations I

[在 LeetCode 上查看](https://leetcode.com/problems/check-if-strings-can-be-made-equal-with-operations-i/)

**難度:** 🟢 Easy　**標籤:** String, Simulation　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2839. Check if Strings Can be Made Equal With Operations I (通過操作使字串相等 I)
 * 難度：簡單 (Easy)
 * 描述：給定兩個長度為 4 的字串 s1 和 s2，每次操作可以選擇任一字串中相距 2 個位置的
 *       兩個索引（即索引 i 與 i+2），並交換這兩個位置的字元。判斷是否能透過任意次數的
 *       操作，讓 s1 和 s2 變得相等。
 *
 * 時間複雜度：O(1)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 觀察交換規則的本質 (Swap Pattern Analysis)：
 *    - 因為只能交換「相距 2」的位置，長度為 4 的字串（索引 0,1,2,3）會被分成兩組獨立的配對：
 *      索引 (0, 2) 一組、索引 (1, 3) 一組。同一組內的字元可以任意交換順序，但無法跨組交換。
 * 2. 各自檢查兩組是否能配對成功：
 *    - 對於索引 (0, 2) 這組，s1 能變成 s2 的條件是：
 *      s1[0]==s2[0] 且 s1[2]==s2[2]（不交換即相同），或是
 *      s1[0]==s2[2] 且 s1[2]==s2[0]（交換後相同）。
 * 3. 索引 (1, 3) 這組同理：
 *    - 檢查 s1[1]、s1[3] 是否能透過同樣的「不交換」或「交換」方式對應到 s2[1]、s2[3]。
 * 4. 兩組條件同時成立才算可行：
 *    - 因為兩組彼此獨立，必須「索引 (0,2) 這組可行」且「索引 (1,3) 這組也可行」，
 *      才能保證整個 s1 可以變成 s2。
 */
class Solution {
public:
    bool canBeEqual(string s1, string s2) {
        return  (   (s1[0] == s2[2] && s1[2] == s2[0])      || 
                    (s1[0] == s2[0] && s1[2] == s2[2]) )    &&
                (   (s1[1] == s2[3] && s1[3] == s2[1])      ||  
                    (s1[1] == s2[1] && s1[3] == s2[3]) ) ;
    }
};
```
