# 646. Maximum Length of Pair Chain

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-length-of-pair-chain/)

**難度:** 🟡 Medium　**標籤:** Dp Lis　**時間:** O(N²)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：646. Maximum Length of Pair Chain
 * 難度：中等 (Medium)
 * 描述：給定一組數對 pairs，pairs[i] = [left, right]。如果 c < d，
 * 數對 [a, b] 可以接在 [c, d] 後面組成鏈。求最長的鏈長度是多少。
 *
 * 時間複雜度：O(N²)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （排序後做標準 LIS 型 DP，dp[i] 代表「以第 i 個數對結尾」的最長鏈長度）：
 * 1. 先照數對的第一個元素排序，讓「能不能接在後面」的判斷變成只需要
 *    往前看（j < i），不用再考慮順序問題，這步是為了讓後面能套用跟
 *    LIS(300) 一樣的 DP 模板。
 * 2. dp[i] 初始化為 1（每個數對自己單獨成一條長度 1 的鏈）。
 * 3. 狀態轉移：對每個 i，往前看每個 j < i，如果 pairs[j][1] < pairs[i][0]
 *    （代表 pairs[i] 可以接在 pairs[j] 後面），就用 dp[j] + 1 更新
 *    dp[i]，取所有可能接法裡最長的。
 * 4. 答案是所有 dp[i] 的最大值。
 * 5. 這題其實有更快的貪心解法（O(N log N)，照 right 排序後貪心選最早
 *    結束的），但貪心解法的正確性證明比較不直覺；這版 DP 解法邏輯上
 *    直接對應 LIS 的思路，跟 300、673、354 是同一個分類（dp-lis），
 *    比較好類比記憶。
 */
class Solution {
public:
    int findLongestChain(vector<vector<int>>& pairs) {
        sort(pairs.begin(), pairs.end());
        int n = pairs.size();
        vector<int> dp(n, 1);
        int ans = 1;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (pairs[j][1] < pairs[i][0]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
```
