# 2656. Maximum Sum With Exactly K Elements

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-sum-with-exactly-k-elements/)

**難度:** 簡單 (Easy)　**標籤:** 　**時間:** O(N) - 只需要遍歷一次 `nums` 陣列來尋找最大值，其中 n 為陣列長度。　**空間:** O(1) - 僅使用常數個變數來儲存最大值與計算結果，不需額外配置動態記憶體。

```cpp
/**
 * 題目：2656. Maximum Sum With Exactly K Elements (K 個元素的最大和)
 * 難度：簡單 (Easy)
 * 描述：給你一個下標從 0 開始的整數陣列 nums 和一個整數 k。你可以執行以下操作恰好 k 次：
 *       1. 從 nums 中選擇一個元素 m。
 *       2. 將選中的元素從 nums 中移除（此題中每次操作可以重複選，或者根據題意，實際上是把選中的數加到總和後，讓該數值加 1）。
 *       3. 將新元素 m + 1 放回 nums。
 *       請你返回執行恰好 k 次操作後，可以獲得的最大總和。
 * 
 * 時間複雜度：O(N) - 只需要遍歷一次 `nums` 陣列來尋找最大值，其中 n 為陣列長度。
 * 空間複雜度：O(1) - 僅使用常數個變數來儲存最大值與計算結果，不需額外配置動態記憶體。
 * 
 * 解法思路：
 * 1. 貪婪策略 (Greedy Strategy)：
 *    - 為了讓總和最大化，我們每次都應該挑選當前陣列中的**最大值**。
 *    - 當我們挑選了最大值 `mx` 之後，題目規則會將其變為 `mx + 1` 放回。這意味著接下來的 k 次操作中，我們實際上會依序選取：`mx`, `mx + 1`, `mx + 2`, ..., `mx + k - 1`。
 * 2. 數學公式優化 (Math Formula)：
 *    - 這是一個首項為 `mx`、公差為 1、共有 `k` 項的等差級數。
 *    - 總和公式可寫為：$(mx) + (mx + 1) + (mx + 2) + \dots + (mx + k - 1)$
 *    - 化簡後即為：$mx \times k + \frac{k \times (k - 1)}{2}$。
 */

class Solution {
public:
    int maximizeSum(std::vector<int>& nums, int k) {
        // 尋找陣列中的最大值
        int mx = *std::max_element(nums.begin(), nums.end());
        
        // 利用等差級數公式直接計算總和：mx 被加了 k 次，加上 0 到 (k-1) 的遞增量
        return mx * k + k * (k - 1) / 2;
    }
};
```
