# 1987. Number of Unique Good Subsequences

[在 LeetCode 上查看](https://leetcode.com/problems/number-of-unique-good-subsequences/)

**難度:** 🔴 Hard　**標籤:** Dp Subsequences　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1987. Number of Unique Good Subsequences
 * 難度：困難 (Hard)
 * 描述：給定一個二進位字串 binary，求它有幾個「不同的」好子序列（好
 * 子序列的定義：不能有前導零，除非它本身就是單獨的 "0"）。結果對
 * 10^9+7 取模。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （DP on Subsequences，跟 940 是同一個家族，但這題多了「不能有前導
 * 零」的限制，所以要分開追蹤「以 0 結尾」跟「以 1 結尾」的子序列數）：
 * 1. end0、end1 分別代表「目前為止，以 0 結尾」「以 1 結尾」的不同
 *    好子序列數量。
 * 2. 狀態轉移，遇到字元 c：
 *    - 如果 c 是 '1'：可以接在任何現有子序列後面（不管前面是 0 結尾
 *      還是 1 結尾都合法，因為只要不是「開頭是 0」就沒有前導零問題），
 *      而且這個 '1' 本身也可以自成一個新的長度 1 子序列，所以：
 *      end1 = end0 + end1 + 1。
 *    - 如果 c 是 '0'：只能接在「已經以某個非零開頭」的子序列後面才
 *      合法（不能自己開頭，否則變成前導零），所以只能接在 end0 或
 *      end1 後面延伸，不能 +1（因為單獨的 "0" 這個特例最後會另外處理，
 *      不算進這個遞推裡）：
 *      end0 = end0 + end1（這裡的 end0 更新不會重複計算，因為右式的
 *      end0 是「上一輪」的值，代表把 0 接在所有已存在、以 0 結尾的
 *      子序列後面，跟接在以 1 結尾的子序列後面，兩者互斥、不重複）。
 * 3. 遍歷完整個字串後，「一般」好子序列的答案是 end0 + end1。
 * 4. 特例處理：如果字串裡至少出現過一次 '0'，代表單獨的 "0" 這個
 *    子序列也是合法的好子序列（它沒有被上面的遞推涵蓋到，因為上面的
 *    end0 遞推規則刻意排除了「0 自己開頭」的情況），額外 +1。
 */
class Solution {
public:
    int numberOfUniqueGoodSubsequences(string binary) {
        const int MOD = 1e9 + 7;
        long long end0 = 0, end1 = 0;
        bool hasZero = false;
        for (char c : binary) {
            if (c == '1') {
                end1 = (end0 + end1 + 1) % MOD;
            } else {
                hasZero = true;
                end0 = (end0 + end1) % MOD;
            }
        }
        long long ans = (end0 + end1) % MOD;
        if (hasZero) ans = (ans + 1) % MOD;
        return (int)ans;
    }
};
```
