# 2164. Sort Even and Odd Indices Independently

[在 LeetCode 上查看](https://leetcode.com/problems/sort-even-and-odd-indices-independently/)

**難度:** 🟢 Easy　**標籤:** Sorting　**時間:** O(NlogN)　**空間:** O(N)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 題目：2164. Sort Even and Odd Indices Independently
 * 難度：簡單 (Easy)
 * 描述：偶數索引非遞減，奇數索引非遞增。
 *
 * 時間複雜度：O(NlogN) - 排序佔主要開銷。
 * 空間複雜度：O(N) - 額外儲存分離後的陣列。
 *
 * 解法思路：
 * 1. 使用 reserve() 預分配記憶體，避免動態擴充開銷。
 * 2. 使用標準的迭代器操作進行回填，確保安全性。
 */

class Solution {
public:
    vector<int> sortEvenOdd(vector<int>& nums) {
        int n = nums.size();
        vector<int> odd;
        vector<int> even;
        odd.reserve(n / 2);
        even.reserve(n / 2);
        for(int i = 0; i < n; i++) {
            ((i & 1) ? odd : even).push_back(nums[i]);
        }
        sort(odd.begin(), odd.end(), greater<>());
        sort(even.begin(), even.end());
        nums.clear();
        for(int i = 0; i < n; i++) nums.push_back(i & 1 ? odd[i >> 1] : even[i >> 1]);
        return nums;
    }
};
```
