**技巧:** 構造法 直接蓋出唯一路徑、路徑做成 L 形、其餘格子全部封成障礙

```cpp
/**
 * 題目：3963. Create Grid With Exactly One Path
 * 難度：Easy
 * 描述：給定 m 與 n，建構任意一個 m x n 的網格，只含 '.'（空格）與 '#'（障礙），
 *       使得從左上角 (0, 0) 到右下角 (m-1, n-1)，
 *       只能往右或往下走，且恰好只有一條合法路徑。
 *
 * 分類主題：matrix-construction
 * 技巧：構造法 直接蓋出唯一路徑, 路徑做成 L 形, 其餘格子全部封成障礙
 *
 * 時間複雜度：O(m * n)，主要是建立整張網格
 * 空間複雜度：O(1)（不計輸出）
 *
 * 解法思路：構造 L 形路徑
 * 1. 不需要計算路徑數量，直接把網格設計成「只有一條路可以走」。
 * 2. 先把整張網格填滿 '#'。
 * 3. 把第 0 列整列設為 '.'：從 (0, 0) 一路往右走到 (0, n-1)。
 * 4. 把最後一行整行設為 '.'：從 (0, n-1) 一路往下走到 (m-1, n-1)。
 * 5. 為什麼路徑唯一：
 *    - 在第 0 列的 (0, j)，j < n-1 時，往下的 (1, j) 是 '#'，只能繼續往右。
 *    - 走到最後一行後，只能往下（右邊已出界）。
 *    所以每一步都只有一個選擇，整條路徑唯一。
 * 6. 邊界情況：
 *    - m = 1：第 0 列就是整張網格，全是 '.'，路徑為一直線。
 *    - n = 1：最後一行就是整張網格，全是 '.'，路徑為一直線。
 */
class Solution {
public:
    vector<string> createGrid(int m, int n) {
        vector<string> ans(m, string(n, '#'));  // 先全部設為障礙

        for (int i = 0; i < m; i++) ans[i].back() = '.';  // 最後一行：由上往下的通道
        for (int j = 0; j < n; j++) ans[0][j] = '.';      // 第 0 列：由左往右的通道

        return ans;
    }
};
```
