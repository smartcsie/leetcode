# 204. Count Primes

[在 LeetCode 上查看](https://leetcode.com/problems/count-primes/)

**難度:** 🟡 Medium　**標籤:** Math, Sieve　**時間:** O(NloglogN)　**空間:** O(N)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：204. Count Primes (計算質數)
 * 難度：中等 (Medium)
 * 描述：統計小於 n 的質數數量。
 *
 * 時間複雜度：O(NloglogN)
 * 空間複雜度：O(N)，但佔用的記憶體空間極小。
 *
 * 解法思路：
 * 1. 使用 bitset 的 .count() 函數取代手動迴圈統計。
 * 2. 篩選時精準控制邊界為 n-1。
 */

class Solution {
private:
void getPrimes(int n, vector<bool>& primes) {
    primes[0] = primes[1] = false;
    for(int p = 2; p * p < n; p++) {
        if(primes[p]) {
            for(int i = p * p; i < n; i += p) {
                primes[i] = false;
            }
        }
    }
}
public:
    int countPrimes(int n) {
        if(n < 2) return 0;
        vector<bool> isPrime(n, true);
        getPrimes(n, isPrime);
        return count(isPrime.begin(), isPrime.end(), true);
    }
};
```

> 起一組 bitset<50001> isPrime，執行Sieve of Eratosthenes演算法，一個for loop 2 ~ **(n-1)**，看prime有幾個<br>
