# 1593. Split a String Into the Max Number of Unique Substrings

[在 LeetCode 上查看](https://leetcode.com/problems/split-a-string-into-the-max-number-of-unique-substrings/)

**難度:** 🟡 Medium　**標籤:** Backtracking Combination　**時間:** O(N*2^(N-1)) - 在最壞情況下，字串有 n-1 個可分割的間隙，總共有 2^(n-1) 種分割組合，每次分割與子字串截取需花費 O(N) 時間。　**空間:** O(N) - 遞迴呼叫堆疊的深度最多為 n，且雜湊表 `seen` 在任一時刻最多儲存 n 個子字串。　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1593. Split a String Into the Max Number of Unique Substrings (拆分字串使唯一子字串的數目最大)
 * 難度：中等 (Medium)
 * 描述：給你一個字串 s，請你將其拆分成若干個非空子字串，且這些子字串必須全部都是獨一無二的（Unique）。
 *       返回你可以將字串拆分成的最大子字串數目。
 * 
 * 時間複雜度：O(N*2^(N-1)) - 在最壞情況下，字串有 n-1 個可分割的間隙，總共有 2^(n-1) 種分割組合，每次分割與子字串截取需花費 O(N) 時間。
 * 空間複雜度：O(N) - 遞迴呼叫堆疊的深度最多為 n，且雜湊表 `seen` 在任一時刻最多儲存 n 個子字串。
 * 
 * 解法思路：
 * 1. 回溯法 (Backtracking / DFS)：
 *    - 由於貪婪法無法覆蓋所有組合，我們必須使用 DFS 窮舉所有可能的分割點。
 *    - 從起始位置 `start` 開始，嘗試向後延伸截取每一個子字串 `sub`。
 * 2. 雜湊表與狀態管理 (Hash Set)：
 *    - 利用 `std::unordered_set` 檢查當前截取的子字串是否已經存在過。
 *    - 若不存在，則將其放入 `seen` 中，遞迴處理下一個起點 `i + 1`（數量 `cur + 1`）；回溯時記得從 `seen` 中刪除該子字串以恢復狀態。
 * 3. 遞迴終止條件：
 *    - 當 `start` 等於字串長度 `s.size()` 時，代表已經成功完成一次合法分割，利用 `std::max` 更新最大子字串數目 `ans`。
 */

class Solution {
private:
    void dfs(const std::string& s, int start, std::unordered_set<std::string>& seen, int cur, int& ans) {
        // 終止條件：當掃描到字串結尾時，更新最大數量
        if (start == s.size()) {
            ans = std::max(ans, cur);
            return;
        }
        // 從當前 start 開始窮舉所有可能的子字串長度
        for (int i = start; i < s.size(); ++i) {
            std::string sub = s.substr(start, i - start + 1);
            // 若子字串已存在，跳過此分支
            if (seen.contains(sub)) continue;
            // 做選擇：加入 set 並進入下一層遞迴
            seen.insert(sub);
            dfs(s, i + 1, seen, cur + 1, ans);
            // 撤銷選擇：回溯拔除狀態
            seen.erase(sub);
        }
    }
public:
    int maxUniqueSplit(std::string s) {
        std::unordered_set<std::string> seen;
        int ans = 0;
        dfs(s, 0, seen, 0, ans);
        return ans;
    }
};
```
