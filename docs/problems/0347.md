# 347. Top K Frequent Elements

[在 LeetCode 上查看](https://leetcode.com/problems/top-k-frequent-elements)

## 解法：quick-select

**難度:** 🟡 Medium　**標籤:** Quick Select, Hash Table, QuickSelect　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：347. Top K Frequent Elements (前 K 個高頻元素)
 * 難度：中等 (Medium)
 * 描述：找出陣列中出現頻率最高的前 K 個元素。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * 1. 使用 unordered_map 統計頻率。
 * 2. 使用 nth_element 在線性時間內將頻率前 K 高的元素移至容器後段。
 * 3. 預先 reserve 結果空間，減少 vector 動態擴展次數。
 */

class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> counts;
        for (int num : nums) counts[num]++;

        vector<pair<int, int>> freq_vec(counts.begin(), counts.end());
        nth_element(freq_vec.begin(), freq_vec.end() - k, freq_vec.end(),
            [](const pair<int,int>& a, const pair<int,int>& b) {
                return a.second < b.second;
            });

        vector<int> res;
        res.reserve(k);
        for (auto it = freq_vec.end() - k; it != freq_vec.end(); ++it)
            res.push_back(it->first);
        return res;
    }
};
```

> 題目 You may return the answer in any order.用 QuickSelect<br>
> target 位置的元素是正確的第 k 個元素<br>
> target 左邊的元素都 ≤ target<br>
> target 右邊的元素都 ≥ target<br>
> 如果結果是要有序的就要用sorting<br>

## 解法：priority-queue

**難度:** 🟡 Medium　**標籤:** Priority Queue　**時間:** O(NlogN)　**空間:** O(N)　**熟悉度:** 🟡 練習過

```cpp
/**
 * 題目：347. Top K Frequent Elements
 * 難度：中等 (Medium)
 * 描述：給定一個整數陣列 nums 和整數 k，回傳出現頻率前 k 高的元素。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （Hash Map + Max Heap）：
 * 1. 用 unordered_map 統計每個數字的出現頻率。
 * 2. 將 {頻率, 數字} 的 pair 全部推入 max heap（priority_queue 預設最大堆）。
 *    pair 比較時先比 first（頻率），頻率高的自然排在堆頂。
 * 3. 從堆頂依序 pop k 次，取出頻率最高的 k 個數字。
 *
 * 注意：
 * 此解法把所有元素都推入 heap，時間為 O(N log N)。
 * 若改用 min heap 只保留 k 個元素，可優化到 O(N log K)。
 * 若用 nth_element，可進一步優化到 O(N) 平均。
 */

class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> m;
        priority_queue<pair<int, int>> q;
        vector<int> res;
        for (auto a : nums) ++m[a];
        for (auto it : m) q.push({it.second, it.first});
        for (int i = 0; i < k; ++i) {
            res.push_back(q.top().second); q.pop();
        }
        return res;
    }
};
```
