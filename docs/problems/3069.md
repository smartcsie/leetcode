# 3069. Distribute Elements Into Two Arrays I

[在 LeetCode 上查看](https://leetcode.com/problems/distribute-elements-into-two-arrays-i/)

**難度:** 🟢 Easy　**標籤:** Array, Simulation　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟢 熟練　🏆 **最佳解**

```cpp
/**
 * 題目：3069. Distribute Elements Into Two Arrays I (將元素分配到兩個陣列中 I)
 * 難度：簡單 (Easy)
 * 描述：給定一個包含互異正整數的陣列 nums（1-indexed）。
 *       第一個數字放進 arr1，第二個數字放進 arr2；之後從第三個數字開始，
 *       若 arr1 目前最後一個元素大於 arr2 最後一個元素，就把該數字放進 arr1，
 *       否則放進 arr2。最終回傳 arr1 接上 arr2 的結果。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * 1. 初始化：前兩個元素分別作為兩個陣列的起點 (Initialize with First Two Elements)：
 *    - nums1 一開始只包含 nums[0]，nums2 一開始只包含 nums[1]，
 *      直接對應題目定義中「第一個數字給 arr1、第二個數字給 arr2」的規則。
 * 2. 從第三個元素開始，依規則逐一分配 (Distribute Remaining Elements)：
 *    - 從索引 2 開始走訪剩餘元素，每次比較 nums1 與 nums2 目前的最後一個元素，
 *      誰比較大，新元素就加進誰的陣列，完全照題目定義的規則模擬。
 * 3. 最終結果：把 nums2 接在 nums1 後面：
 *    - 走訪完所有元素後，直接用 insert 把 nums2 的所有內容接到 nums1 尾端，
 *      即為題目要求的最終結果陣列。
 */
class Solution {
public:
    vector<int> resultArray(vector<int>& nums) {
        vector<int> nums1({nums[0]});
        vector<int> nums2({nums[1]});
        for(int i = 2; i < nums.size(); i++) {
            if(nums1.back() > nums2.back()) nums1.push_back(nums[i]);
            else nums2.push_back(nums[i]);
        }
        nums1.insert(nums1.end(), nums2.begin(), nums2.end());
        return nums1;
    }
};
```
