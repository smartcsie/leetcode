# 173. Binary Search Tree Iterator

[在 LeetCode 上查看](https://leetcode.com/problems/binary-search-tree-iterator/)

**難度:** 🟡 Medium　**標籤:** Design, Stack　**時間:** O(1)　**空間:** O(H)　**熟悉度:** 🟣 易忘

```cpp
/**
 * 題目：173. Binary Search Tree Iterator (二元搜尋樹迭代器)
 * 難度：中等 (Medium)
 * 描述：實現一個迭代器，按從小到大的順序遍歷 BST。
 *
 * 時間複雜度：O(1)
 * 空間複雜度：O(H)
 *
 * 解法思路：
 * 1. 惰性遍歷：不需要預先儲存所有節點，僅需維護目前的節點路徑。
 * 2. 空間優化：將空間開銷從 O(N) 降至 O(h)。
 */

class BSTIterator {
private:
    stack<TreeNode*> st;
    void pushLeft(TreeNode* root) {
        while(root) {
            st.push(root);
            root = root->left;
        }
    }
public:
    BSTIterator(TreeNode* root) {
        pushLeft(root);
    }
    int next() {
        TreeNode* node = st.top();
        st.pop();
        pushLeft(node->right);
        return node->val;
    }
    bool hasNext() {
        return !st.empty();
    }
};
```
