# 1140. Stone Game II

[在 LeetCode 上查看](https://leetcode.com/problems/stone-game-ii/)

**難度:** 🟡 Medium　**標籤:** Dp Game Theory　**時間:** O(N³)　**空間:** O(N²)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1140. Stone Game II
 * 難度：中等 (Medium)
 * 描述：給定一列石堆 piles，兩個玩家輪流從陣列「最前面」拿走連續
 * 1 到 2M 堆（M 是一個會隨遊戲進行變動的參數：一開始 M=1，每次拿完
 * X 堆之後，新的 M 變成 max(M, X)）。兩人都用最佳策略遊玩，求先手
 * 玩家最多能拿到多少石頭。
 *
 * 時間複雜度：O(N³)
 * 空間複雜度：O(N²)
 *
 * 解法思路：
 * （記憶化搜尋，狀態是「目前位置 i」+「目前的參數 M」，這題不求
 * 「分數差」，而是直接算「目前玩家能拿到的最大石頭數」）：
 * 1. 先算後綴和 suffix[i]，代表從索引 i 到結尾的石頭總數，方便 O(1)
 *    查詢「剩下所有石頭還有多少」。
 * 2. dp(i, M) 代表「從索引 i 開始，目前參數是 M」時，輪到的這位玩家
 *    最多能拿到多少石頭。
 * 3. 邊界優化（避免真的窮舉到底）：如果剩下的堆數 <= 2M，代表這個
 *    玩家可以一次把剩下的全部拿完（規則允許拿到 2M 堆），直接回傳
 *    suffix[i]，不用繼續遞迴。
 * 4. 一般情況的狀態轉移：枚舉這次要拿的堆數 X（1 到 2M），拿完之後
 *    剩下的部分交給對手，對手在新狀態 (i+X, max(M,X)) 下會盡量拿走
 *    最多的石頭 dp(i+X, max(M,X))，所以「我」在這個選擇下能拿到的
 *    是：suffix[i] - dp(i+X, max(M,X))（剩下的全部總量，扣掉對手
 *    之後能拿走的部分，就是「我」在這次選擇下最終能拿到的量，因為
 *    整個遊戲拿完的堆數加總起來就是 suffix[i]）。
 * 5. 取所有 X 選擇中最大的，就是 dp(i, M)。用 memo 陣列快取避免重複
 *    計算（同一組 i, M 只要算過一次）。
 * 6. 答案是 dp(0, 1)（一開始從頭開始，M = 1）。
 */
class Solution {
public:
    int stoneGameII(vector<int>& piles) {
        int n = piles.size();
        vector<int> suffix(n + 1, 0);
        for (int i = n - 1; i >= 0; --i) suffix[i] = suffix[i + 1] + piles[i];

        vector<vector<int>> memo(n, vector<int>(n + 1, -1));
        function<int(int,int)> dp = [&](int i, int M) -> int {
            if (i >= n) return 0;
            if (2 * M >= n - i) return suffix[i];
            if (memo[i][M] != -1) return memo[i][M];
            int best = 0;
            for (int X = 1; X <= 2 * M; ++X) {
                int take = suffix[i] - dp(i + X, max(M, X));
                best = max(best, take);
            }
            return memo[i][M] = best;
        };
        return dp(0, 1);
    }
};
```
