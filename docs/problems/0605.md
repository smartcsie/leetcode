**技巧:** 由左到右貪心種花、檢查左右鄰居時注意邊界、種下後直接修改陣列避免重複檢查

```cpp
/**
 * 題目：605. Can Place Flowers
 * 難度：Easy
 * 描述：花圃以 0 / 1 陣列 flowerbed 表示（0 為空地，1 已種花），
 *       花不能種在相鄰的格子。給定整數 n，
 *       判斷能否在不違反規則的情況下，再種下 n 朵花。
 *
 * 分類主題：greedy
 * 技巧：由左到右貪心種花, 檢查左右鄰居時注意邊界, 種下後直接修改陣列避免重複檢查
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)（直接修改輸入陣列）
 *
 * 解法思路：貪心，能種就種
 * 1. 由左到右掃描，只要某格「本身是空地、左邊不是花、右邊不是花」，就在這格種花。
 * 2. 為什麼貪心是對的：越早種（越靠左）對右邊的影響最小，
 *    只會佔掉自己和右邊那一格，不會讓後面能種的數量變少。
 * 3. 種下後把 flowerbed[i] 改成 1，這樣下一格檢查左鄰居時，
 *    就會自動發現這裡有花而跳過，不需要另外記錄。
 * 4. 邊界處理：第一格沒有左鄰居、最後一格沒有右鄰居，
 *    用 i > 0、i < m - 1 的條件避免越界，視為該側沒有花。
 * 5. n 減到 0 就可以提早結束迴圈；最後回傳 n == 0。
 */

class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        int m = flowerbed.size();
        for(int i = 0; i < m && n > 0; i++) {
            if(flowerbed[i] == 1) continue;
            if(i > 0 && flowerbed[i - 1] == 1) continue;
            if(i < m - 1 && flowerbed[i + 1] == 1) continue;
            flowerbed[i] = 1;
            n--;
        }
        return n == 0;
    }
};
```
