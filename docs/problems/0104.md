# 104. Maximum Depth of Binary Tree

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

**難度:** 🟢 Easy　**標籤:** Tree, DFS　**時間:** O(n)　**空間:** O(h)

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(!root) return 0;
        int l = maxDepth(root->left);
        int r = maxDepth(root->right);
        return 1 + max(l , r);
    }
};
```
