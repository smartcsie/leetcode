# 309. Best Time to Buy and Sell Stock with Cooldown

[在 LeetCode 上查看](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/)

**難度:** 🟡 Medium　**標籤:** Dp State Machine　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：309. Best Time to Buy and Sell Stock with Cooldown
 * 難度：中等 (Medium)
 * 描述：給定每天的股價 prices，可以進行無限次交易，但賣出股票後的
 * 隔天必須休息（不能買進），求最大總利潤。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （State Machine DP，三個狀態：hold=持股中、sold=今天剛賣掉
 * （明天強制冷卻）、rest=空手且不是剛賣掉（今天可以自由選擇買或不買））：
 * 1. hold：目前持有股票的最大利潤。
 * 2. sold：今天剛把股票賣掉的最大利潤（明天不能買，只能轉成 rest）。
 * 3. rest：目前空手、而且不處於冷卻狀態的最大利潤（可以選擇今天買進、
 *    或繼續維持空手）。
 * 4. 狀態轉移（要注意 sold 依賴「前一天」的 hold，rest 依賴「前一天」
 *    的 sold，所以要先存一份 prevSold 再更新，不然會用到同一天算出來
 *    的新值，邏輯就錯了）：
 *    - sold（今天賣）= 昨天的 hold + 今天的 price（昨天持股，今天賣掉）
 *    - hold（今天持股）= max(昨天就持股, 昨天是 rest 狀態、今天買進)
 *      = max(hold, rest - price)
 *    - rest（今天空手不冷卻）= max(昨天就是 rest, 前天賣掉、昨天冷卻完
 *      今天轉成 rest) = max(rest, prevSold)
 * 5. 答案是 max(sold, rest)（最後一天不會是 hold 狀態最優，因為手上
 *    還握著股票沒變現）。
 */
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int hold = INT_MIN, sold = 0, rest = 0;
        for (int price : prices) {
            int prevSold = sold;
            sold = hold + price;
            hold = max(hold, rest - price);
            rest = max(rest, prevSold);
        }
        return max(sold, rest);
    }
};
```
