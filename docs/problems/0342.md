# 342. Power of Four

[在 LeetCode 上查看](https://leetcode.com/problems/power-of-four/)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool isPowerOfFour(int n) {
        return n > 0 && (n & (n-1)) == 0 && (n & 0x55555555) != 0;
    }
};
```

> [Power of Four](https://leetcode.com/problems/power-of-four/)<br>
> **(n > 0) && (n & (n-1)) == 0 && (n & 0x55555555) != 0**，Power of Two多加 **(n & 0x55555555) != 0**<br>
> **解法二 迴圈解法** <br>
> **if(n <= 0) return false;**<br>
> **while((n % 4) ==0) n /= 4;**<br>
> **return n == 1;**<br>
> **解法三 bit數量** <br>
> **rreturn n > 0 && __builtin_popcount(n) == 1 && (n - 1) % 3 == 0;**<br>
