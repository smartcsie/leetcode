# 342. Power of Four

[在 LeetCode 上查看](https://leetcode.com/problems/power-of-four/)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool isPowerOfFour(int n) {
        return n > 0 && (n & (n-1)) == 0 && (n & 0x55555555) != 0;
    }
};
```
