# 1374. Generate a String With Characters That Have Odd Counts

[在 LeetCode 上查看](https://leetcode.com/problems/generate-a-string-with-characters-that-have-odd-counts/)

**難度:** 🟢 Easy　**標籤:** Math, Construction　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1374. Generate a String With Characters That Have Odd Counts (生成每種字元都是奇數個的字串)
 * 難度：簡單 (Easy)
 * 描述：給定整數 n，回傳一個長度為 n 的字串，且字串中每種字元出現的次數都必須是奇數。
 *
 * 時間複雜度：O(N) - 建構長度為 N 的字串需要線性時間。
 * 空間複雜度：O(N) - 輸出字串本身需要 O(N) 空間。
 *
 * 解法思路：
 * 1. 分成 n 為奇數、偶數兩種情況討論 (Case Split by Parity)：
 *    - 這題不需要考慮多種字元的複雜組合，只需要用最多兩種字元（'a'、'b'）
 *      就能滿足「每種字元出現次數皆為奇數」的要求。
 * 2. 若 n 為奇數：直接用單一字元填滿 (Odd n: Single Character)：
 *    - 回傳 n 個 'a'，此時 'a' 出現次數就是 n 本身，天然是奇數，符合要求。
 * 3. 若 n 為偶數：拆成 1 個 'a' 加上 (n-1) 個 'b' (Even n: Split into 1 + (n-1))：
 *    - 'a' 出現 1 次（奇數）；由於 n 是偶數，n-1 必為奇數，
 *      所以 'b' 出現 (n-1) 次也同樣是奇數，兩種字元的次數都符合奇數的要求。
 * 4. 為何一定要拆成兩種字元：
 *    - 若 n 為偶數卻只用單一字元，出現次數就會是偶數，違反題目要求；
 *      因此偶數情況下，必須拆成兩個各自為奇數的部分（1 和 n-1，兩者相加仍為 n，且都是奇數）。
 */
class Solution {
public:
    string generateTheString(int n) {
        return (n & 1) ? string(n, 'a') : "a" + string(n - 1, 'b');
    }
};
```
