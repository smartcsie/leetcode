# 1784. Check if Binary String Has at Most One Segment of Ones

[在 LeetCode 上查看](https://leetcode.com/problems/check-if-binary-string-has-at-most-one-segment-of-ones/)

**難度:** 🟢 Easy　**標籤:** String, Two Pointers　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：1784. Check if Binary String Has at Most One Segment of Ones (檢查二進位字串字段一是否至多一個)
 * 難度：簡單 (Easy)
 * 描述：給定只包含 '0' 和 '1' 的字串 s，判斷 s 中連續 1 所組成的區段是否「至多只有一段」。
 *
 * 時間複雜度：O(N) - 只需線性掃描一次（find 與 rfind 各一次，中間掃描一次）。
 * 空間複雜度：O(1) - 只使用常數個變數。
 *
 * 解法思路：
 * 1. 找出第一個與最後一個 '1' 的位置 (Find First and Last '1')：
 *    - 若整個字串完全沒有 '1'，代表沒有任何一段連續的 1，天然符合「至多一段」，直接回傳 true。
 * 2. 檢查「第一個 1」到「最後一個 1」之間，是否夾雜任何 '0' (Check for Gaps)：
 *    - 若整個字串只有一段連續的 1，那麼從第一個 1 到最後一個 1 之間，
 *      理論上應該全部都是 '1'，中間不應該出現任何 '0'。
 *    - 只要在這個範圍內找到任何一個 '0'，就代表中間被切斷過，形成了第二段（甚至更多段）1，直接回傳 false。
 * 3. 為何不能單純用 s.find("01") == npos 判斷 (Common Pitfall)：
 *    - 這是一個常見的誤解陷阱：如果字串是「先出現 0，再出現唯一一段 1」
 *      （例如 "001110000"），"01" 這個子字串**確實會出現一次**
 *      （代表「從開頭的 0 轉進唯一一段 1」的那個轉折點），
 *      但這種情況其實仍然只有一段 1，應該回傳 true。
 *    - 單純檢查「01 是否出現」會把這種合法情況誤判為不合法，因此改用
 *      「第一個 1 到最後一個 1 之間是否連續」的方式判斷才正確。
 */
class Solution {
public:
    bool checkOnesSegment(string s) {
        return s.find("01") == string::npos;
    }
};
```
