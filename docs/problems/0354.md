# 354. Russian Doll Envelopes

[在 LeetCode 上查看](https://leetcode.com/problems/russian-doll-envelopes/)

**難度:** 🔴 Hard　**標籤:** Dp Lis　**時間:** O(N log N)　**空間:** O(N)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：354. Russian Doll Envelopes
 * 難度：困難 (Hard)
 * 描述：給定一組信封 envelopes，每個信封是 [width, height]，一個信封
 * 能塞進另一個信封的條件是寬跟高都嚴格更小。求最多能疊出幾層俄羅斯
 * 娃娃（信封層層相疊）。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(N)
 *
 * 解法思路：
 * （降維成一維 LIS，再用二分搜尋加速到 O(N log N)）：
 * 1. 這題本質是二維的最長遞增子序列（要 width、height 都嚴格遞增），
 *    直接做會變成 O(N²)。技巧是：先照 width 遞增排序，把「寬」這個維度
 *    處理掉，題目就退化成一維：在排序後的序列裡找 height 的 LIS。
 * 2. 排序的關鍵細節：當兩個信封 width 相同時，要讓 height 遞減排序
 *    （而不是遞增）。這是為了避免「同寬」的信封被誤判成可以互相嵌套——
 *    因為題目要求寬跟高都嚴格更小，同寬的信封本來就不能互相塞入，
 *    height 遞減排序可以確保同一組同寬信封裡最多只會被選進 LIS 一個。
 * 3. 排序後，對 height 這個序列做標準的「二分搜尋優化版 LIS」
 *    （patience sorting）：維護一個 lisHeights 陣列，代表「目前長度為
 *    k 的遞增子序列，結尾最小可能的 height 是多少」。
 *    - 如果目前的 height 比 lisHeights 最後一個還大，代表可以直接接在
 *      LIS 後面，長度 +1。
 *    - 否則用二分搜尋找到第一個 >= 目前 height 的位置，把它替換掉
 *      （讓同樣長度的子序列結尾盡量小，保留未來接更多元素的空間）。
 * 4. 答案是 lisHeights 的長度。
 */
class Solution {
public:
    int maxEnvelopes(vector<vector<int>>& envelopes) {
        sort(envelopes.begin(), envelopes.end(), [](const auto& envelope1, const auto& envelope2) {
            return envelope1[0] < envelope2[0] || 
                   (envelope1[0] == envelope2[0] && envelope1[1] > envelope2[1]);
        });
        int numEnvelopes = envelopes.size();
        vector<int> lisHeights{envelopes[0][1]};
        for (int i = 1; i < numEnvelopes; ++i) {
            int currentHeight = envelopes[i][1];
            if (currentHeight > lisHeights.back()) {
                lisHeights.push_back(currentHeight);
            }
            else {
                int replaceIndex = lower_bound(lisHeights.begin(), lisHeights.end(), currentHeight) 
                                   - lisHeights.begin();
                lisHeights[replaceIndex] = currentHeight;
            }
        }
        return lisHeights.size();
    }
};
```
