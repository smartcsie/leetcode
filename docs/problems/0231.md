# 231. Power of Two

[在 LeetCode 上查看](https://leetcode.com/problems/power-of-two/)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(1)　**空間:** O(1)

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool isPowerOfTwo(int n) {
        return n > 0 && (n & (n-1)) == 0;
    }
};
```
