# 231. Power of Two

[在 LeetCode 上查看](https://leetcode.com/problems/power-of-two/)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(1)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool isPowerOfTwo(int n) {
        return n > 0 && (n & (n-1)) == 0;
    }
};
```

> [Power of Two](https://leetcode.com/problems/power-of-two/)<br>
> **(n > 0) && (n & (n-1)) == 0** <br>

> 解法二 迴圈解法<br>
> **if(n <= 0) return false;** <br>
> **while(n % 2 == 0) n /= 2;** <br>
> **return n == 1;** <br>

> 解法三 bit數量<br>
> **return n >= 0 && __builtin_popcount(n) == 1;** <br>
