# 1710. Maximum Units on a Truck

[在 LeetCode 上查看](https://leetcode.com/problems/maximum-units-on-a-truck/)

**難度:** 🟢 Easy　**標籤:** Greedy Sorting Decision　**時間:** O(N log N)　**空間:** O(1)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：1710. Maximum Units on a Truck
 * 難度：簡單 (Easy)
 * 分類主題：greedy-sorting-decision
 * 描述：給定 boxTypes[i] = [numberOfBoxes, unitsPerBox]，卡車最多能
 * 裝 truckSize 個箱子（不限箱子種類），求能裝載的最大單位總數。
 *
 * 時間複雜度：O(N log N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * （Sorting + Greedy Decision 裡最直覺的一種：排序後從「單位密度」
 * 最高的開始拿，是分數/密度型貪心的入門款）：
 * 1. 把箱子種類依照「每箱單位數（unitsPerBox）」由高到低排序。
 * 2. 貪心策略：優先裝「單位密度最高」的箱子——因為卡車空間（箱子數）
 *    有限，同樣佔一個名額，裝單位數越多的箱子越划算。
 * 3. 依序處理排序後的每種箱子：這種箱子最多能裝
 *    min(這種箱子的數量, 卡車剩餘空間) 個，累加對應的單位數，並扣掉
 *    卡車剩餘空間；如果卡車已經滿了（剩餘空間變 0），提早結束。
 * 4. 答案是累計的總單位數。
 */
class Solution {
public:
    int maximumUnits(vector<vector<int>>& boxTypes, int truckSize) {
        sort(boxTypes.begin(), boxTypes.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] > b[1];
        });
        int totalUnits = 0;
        for (auto& box : boxTypes) {
            int numBoxes = min(box[0], truckSize);
            totalUnits += numBoxes * box[1];
            truckSize -= numBoxes;
            if (truckSize == 0) break;
        }
        return totalUnits;
    }
};
```
