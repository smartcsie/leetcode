# 804. Unique Morse Code Words

[在 LeetCode 上查看](https://leetcode.com/problems/unique-morse-code-words/)

**難度:** 🟢 Easy　**標籤:** Hash Set　**時間:** O(S)　**空間:** O(S)　**熟悉度:** 🔴 生疏

```cpp
/**
 * 題目：804. Unique Morse Code Words
 * 難度：簡單 (Easy)
 * 描述：將每個單字轉換為摩斯密碼，計算有多少種唯一的密碼組合。
 * 優化重點：
 * 1. 使用 `std::string::reserve` 預分配摩斯密碼轉換後的空間，避免動態擴充。
 * 2. 使用 `std::vector<string_view>` 或直接存取陣列，提升轉換效率。
 *
 * 時間複雜度：O(S) - S 為所有字串字元總數，轉換後存入 set。
 * 空間複雜度：O(S) - set 最多存 N 個 morse code 字串。
 */

class Solution {
public:
    int uniqueMorseRepresentations(vector<string>& words) {
        static const vector<string> morse = { 
            ".-", "-...", "-.-.", "-..", ".", "..-.", "--.", "....", "..", ".---", 
            "-.-", ".-..", "--", "-.", "---", ".--.", "--.-", ".-.", "...", "-", 
            "..-", "...-", ".--", "-..-", "-.--", "--.."
        };
        unordered_set<string> unique_codes;
        unique_codes.reserve(words.size());
        for(const string& word : words) {
            string str;
            for(char c : word) str += morse[c - 'a'];
            unique_codes.insert(str);
        }
        return unique_codes.size();
    }
};
```

> 用一組 vector<string> morse 定義morse code mapping<br>
> 針對words每個string，轉為morsecode，放入unordered_set<string> unique_codes;<br>
> 因為unordered_set會去重覆，最後unique_codes.size();<br>
