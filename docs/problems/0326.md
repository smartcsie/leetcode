# 326. Power of Three

[在 LeetCode 上查看](https://leetcode.com/problems/power-of-three/)

**難度:** 🟢 Easy　**標籤:** Math　**時間:** O(log₃N)　**空間:** O(1)　**熟悉度:** 🟢 熟練

```cpp
/**
 * 註解：待補充
 */
class Solution {
public:
    bool isPowerOfThree(int n) {
        return (n > 0) && (static_cast<int>(pow(3, 19)) % n == 0);
    }
};
```

> **(n > 0) && static_cast<int>(pow(3, 19)) % n == 0**<br>
> 連除solution
> **if(n <= 0) return false;**<br>
> ** while((n % 3) == 0) n /= 3;**<br>
> **return (n == 1);**<br>
