# 2451. Odd String Difference

[在 LeetCode 上查看](https://leetcode.com/problems/odd-string-difference/)

**難度:** 🟢 Easy　**標籤:** Hash Table Mapping, Hash Map, Difference Array　**時間:** O(N*M)　**空間:** O(N*M)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：2451. Odd String Difference
 * 難度：簡單 (Easy)
 * 描述：找出 words 陣列中唯一的「差異字串」。差異字串是指其差異陣列（相鄰字元之差）與其他字串不同的字串。
 *
 * 時間複雜度：O(N*M)
 * 空間複雜度：O(N*M)
 *
 * 解法思路：
 * 1. 定義輔助函數 getDiff：計算相鄰字元的 ASCII 差值並轉為字串。
 * 2. 使用 unordered_multimap 紀錄 {差異陣列: 原字串} 的映射關係。
 * 3. 遍歷 map，找到計數為 1 的那個差異陣列，即為目標字串。
 */

class Solution {
public:
    string oddString(vector<string>& words) {
        unordered_map<string, int> hashCounts;
        unordered_map<string, string> hashToWord;
        for(int i = 0; i < words.size(); i++) {
            string key;
            for(int j = 1; j < words[i].size(); j++) 
                key.push_back(words[i][j] - words[i][j - 1]+26);
            hashCounts[key]++;
            hashToWord[key] = words[i];
        }
        for(const auto& [hash , count] : hashCounts) {
            if(count == 1) return hashToWord[hash];
        }
        return "";
    }
};
```
