# 697. Degree of an Array

[在 LeetCode 上查看](https://leetcode.com/problems/degree-of-an-array/)

**難度:** 🟢 Easy　**標籤:** Array Continuous Counting, Hash Map, One-pass　**時間:** O(N)　**空間:** O(N)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：697. Degree of an Array
 * 難度：待補充
 * 描述：找出陣列的「度」(最高頻率)，並回傳具有該度數的最短連續子陣列長度。
 *
 * 時間複雜度：O(N) - 單次遍歷記錄每個數字的首末位置與頻率。
 * 空間複雜度：O(N) - hash map 儲存最多 N 個條目。
 *
 * 解法思路：
 * 1. 使用 unordered_map 記錄每個數字的 {出現次數, 第一次出現的索引}。
 * 2. 透過遍歷陣列，同步維護全局的 maxCount (最大度) 與 minDiffIdx (最短長度)。
 * 3. 邏輯判定：
 * - 若出現次數超過 maxCount：更新度數，並重置最短長度。
 * - 若出現次數等於 maxCount：比較當前區間長度與舊的最短長度，保留較小者。
 */

class Solution {
public:
    int findShortestSubArray(std::vector<int>& nums) {
                unordered_map<int, array<int, 2>> maps;
        int maxCount = 0;
        int minDiff = 50001;
        for(int i = 0 ;i < nums.size(); i++) {
            int x = nums[i];
            if(!maps.count(x)) maps[x] = {1 , i};
            else  maps[x][0]++;
            if(maps[x][0] > maxCount) {
                maxCount = maps[x][0];
                minDiff = i - maps[x][1] + 1;
            } else if(maps[x][0] == maxCount) {
                minDiff = min(minDiff, i - maps[x][1] + 1);
            } 
        }
        return minDiff;
    }
};
```
