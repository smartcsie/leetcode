# 1309. Decrypt String from Alphabet to Integer Mapping

[在 LeetCode 上查看](https://leetcode.com/problems/decrypt-string-from-alphabet-to-integer-mapping/)

**難度:** 🟢 Easy　**標籤:** Array Linear Scan, Hash Table, String Parsing　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟠 再練習

```cpp
/**
 * 題目：1309. Decrypt String from Alphabet to Integer Mapping
 * 難度：待補充
 * 描述：給定一個字串 s，由數字（'0'-'9'）和 '#' 組成。映射規則如下：
 * - '1' 到 '9' 分別對應 'a' 到 'i'。
 * - '10#' 到 '26#' 分別對應 'j' 到 'z'。
 * 返回解密後的字串。
 *
 * 時間複雜度：O(N) - 單次遍歷，遇到 '#' 回頭取兩位數。
 * 空間複雜度：O(1) - 僅使用常數空間。
 *
 * 解法思路：
 * 1. 建立一個雜湊表（unordered_map），將所有的加密代碼（如 "1", "2", ..., "10#", "26#"）
 * 與對應的英文字母進行映射。
 * 2. 從左到右走訪字串 s：
 * - 檢查當前字元後面兩位（即 i + 2）是否有 '#'。
 * - 如果有，代表這是 10# 到 26# 的字元，截取 3 個字元（s.substr(i, 3)）進行對應解密，並將 i 向後移動 2 位。
 * - 如果沒有，代表這是 1 到 9 的單位數字元，直接解密當前單一字元。
 * 3. 將解密後的字元拼接到答案字串 ans 中並回傳。
 */

class Solution {
public:
    string freqAlphabets(string s) {
        string ans;
        for(int i = 0; i < s.size(); ) {
            char c;
            if(i + 2 < s.size() && s[i + 2] == '#') {
                c = (s[i] - '0') * 10 + (s[i + 1] - '0') - 1 + 'a';
                i += 3;
            } else {
                c = s[i] - '1' + 'a';
                i += 1;
            }
            ans.push_back(c);
        }
        return ans;
    }
};
```
