# 396. Rotate Function

[在 LeetCode 上查看](https://leetcode.com/problems/rotate-function/)

**難度:** 🟡 Medium　**標籤:** Math, Array　**時間:** O(N)　**空間:** O(1)　**熟悉度:** 🟣 易忘

```cpp
/**
 * 題目：396. Rotate Function (旋轉函數)
 * 難度：中等 (Medium)
 * 描述：計算陣列旋轉後的函數值 F(k) = 0*nums[0] + 1*nums[1] + ... + (n-1)*nums[n-1]，求其中的最大值。
 *
 * 時間複雜度：O(N)
 * 空間複雜度：O(1)
 *
 * 解法思路：
 * 1. 利用前後項關係：F(i) - F(i-1) = sum - n * nums[n-i]。
 * 2. 避免重複運算，使用變數累加更新。
 */

class Solution {
public:
    int maxRotateFunction(std::vector<int>& nums) {
        const long long sum = accumulate(nums.begin(), nums.end(), 0);
        long long f = 0;
        // Calculate F(0) first.
        for (int i = 0; i < nums.size(); ++i) {
            f += i * nums[i];
        }
        long long ans = f;
        for (int i = nums.size() - 1; i > 0; --i) {
            f += sum - nums.size() * nums[i];
            ans = max(ans, f);
        }
        return static_cast<int>(ans);
    }
};
```
